# 경건생활 · 매일 성경 통독과 QT

[갓피아(GODpia) 성경](https://www.godpia.com/)으로 **매일 5장씩 성경을 통독**하고, **오늘의 QT(날마다 솟는 샘물)** 에 바로 들어가는 웹페이지입니다.
서버·빌드 없이 HTML/CSS/JS만으로 동작해서 GitHub Pages에 그대로 배포할 수 있습니다.

## 기능

메뉴는 **통독 → QT → 현황** 순서입니다.

### 1. 통독 (`#today`)
- **계획 만들기**: ① 시작 권·장 ② 끝 권·장("이 권 끝까지", "구약 끝", "요한계시록까지", "성경 전체 1독" 바로 선택 가능) ③ 속도("하루 분량" 또는 "마칠 날짜")를 고르면 Day별 분량과 마치는 날을 미리 보여 줍니다. 끝 장이 시작 장보다 앞이면 요한계시록 다음 창세기로 이어 읽습니다.
- **꽉 찬 읽기 화면**: 갓피아 성경 화면이 헤더 아래 전체를 채우고, 갓피아 웹의 로고 막대(휴대폰은 역본 버튼 줄까지)는 잘라냅니다.
- **위쪽**: 오늘 분량 제목, 장 버튼(읽은 장은 ✓, 지금 장은 테두리), 읽은 수(2/5), **통독표** 버튼, 역본 버튼(누르면 한권/두권·역본을 고르는 보기 설정).
- **아래쪽**: ‹ › 장 이동과 큰 **"N장 읽었어요"** 버튼. 하루 분량을 다 읽으면 **"다음 분량 읽기"** 로 바뀝니다.
- **통독표 패널**: 전체 Day 목록(날짜, 분량, 완료 여부)에서 원하는 Day로 이동합니다.
- **메모·도구 패널**: 몰아서 체크(갓피아 안에서 옆으로 넘기며 읽었을 때), 통독 메모(전체 복사 가능), 분량 복사(투두메이트 등에 붙여넣기), 갓피아 새 창 열기.

### 2. QT (`#qt`)
- 갓피아 "날마다 솟는 샘물"을 꽉 찬 화면으로 보여 줍니다. 위쪽 날짜를 누르면 달력에서 다른 날을 고를 수 있습니다.
- 아래쪽 **🙏 QT 완료하기**, **📝 묵상 노트**(지난 QT 기록 포함), 🔥 연속 일수.
- **`qt.html`**: 열자마자 갓피아 오늘의 QT로 이동하는 바로가기 주소입니다. 휴대폰 홈 화면이나 북마크에 추가해 두세요.

### 3. 현황 (`#stats`)
- **통독 카드**: 진행률 원형 그래프, 오늘 읽은 장, 연속 일수, 계획 대비, 마칠 예정일.
- **QT 카드**: 오늘 QT 완료 여부, 연속 일수, 이번 달, 누적.
- **달력**: 날짜마다 통독(초록 막대: 완료/일부)과 QT(주황 점)를 함께 표시하고, 달마다 넘겨 볼 수 있습니다.
- **최근 기록**: 날짜별 통독 범위·메모와 QT 완료·노트를 한 줄기로 보여 줍니다.
- 권별 진행, 계획 바꾸기, 백업 받기/불러오기, 기록 초기화.

### 4. 저녁 리마인드 알림
- 오늘 통독을 마치지 않았으면 **18시 · 21시 · 23시**에 푸시 알림이 옵니다. 다 읽으면 그날은 오지 않습니다.
- 문구는 시간대마다 8가지씩, 개혁주의·장로교 맥락(소요리문답, 칼뱅, 도르트 총회, 성경 인물·구절)으로 재치 있게 바뀝니다. `sw.js`의 `MESSAGES`에서 고칠 수 있습니다.
- 휴대폰 홈 화면에 추가한 뒤 **현황 → 🔔 저녁 리마인드 → 알림 켜기**. 아이폰은 iOS 16.4 이상, 홈 화면 앱에서만 됩니다.
- 정해진 시간에 보내려면 작은 알림 서버가 필요합니다. [worker/README.md](worker/README.md) 순서대로 Cloudflare에 배포하고 `js/core/config.js`에 주소를 넣으세요.

### 구절 붙여넣기
갓피아 화면에서 구절을 길게 눌러 선택 → 복사한 뒤, **통독·QT 화면 오른쪽 아래의 📋 붙여넣기** 버튼을 누르면 패널을 열지 않고 오늘 통독 메모(QT 화면에서는 묵상 노트) 끝에 바로 붙습니다. 갓피아 화면은 다른 사이트라 복사한 순간을 앱이 알 수 없어서, 이 버튼을 항상 띄워 둡니다.

아래 양식으로 들어갑니다. 첫 줄은 `권 장:절`(여러 절이면 `18:10-11`), 다음 줄부터 `절 번호 + 공백 한 칸 + 구절`입니다. 권·장은 지금 보고 있는 장 기준이고, QT 노트에는 첫 줄 없이 구절만 들어갑니다.

```
민수기 18:10
10 지극히 거룩하게 여김으로 먹으라 이는 네게 성물인즉 남자들이 다 먹을지니라
```

붙여넣은 메모나 노트를 다른 곳으로 옮기고 싶으면, 메모·도구 패널의 **📋 메모 전체 복사**(QT는 **노트 전체 복사**)로 지금까지 쓴 내용을 통째로 복사할 수 있습니다.

**일부만 복사해도 온전한 절로** (통독 화면): 절의 한가운데부터 끝까지, 또는 다음 절 앞부분만 복사해도 걸친 절 전체가 붙습니다. 두권 보기면 두 역본 모두 온전한 절로 붙습니다.

```
복사한 글:  행하지 아니하리라
           13그러면 온 이스라엘 백성이 듣고
붙는 글:   신명기 17:13
           13 그리하면 온 백성이 듣고 두려워하여 다시는 무법하게 행하지 아니하리라
           13 그러면 온 이스라엘 백성이 듣고 두려워하며, 다시는 아무도 재판 결과를 하찮게 여기지 않을 것입니다."
```

갓피아는 다른 사이트에서 본문을 읽지 못하게 막아 두어서, 알림 서버(`worker/`)의 `/bible`이 장 본문을 대신 받아 줍니다. 그래서 **알림 서버를 배포하고 `js/core/config.js`에 주소를 넣어야** 동작합니다. 서버가 없거나, 복사한 글이 너무 짧아 장 안에 여러 번 나오면(예: "여호와") 예전처럼 복사한 그대로 붙습니다. 앞뒤 두 장까지 찾아보므로 갓피아 안에서 옆으로 넘겨 읽는 중이어도 됩니다. QT 묵상 노트는 복사한 그대로 붙습니다.

**절 번호가 빠진 첫 줄**: 휴대폰에서 길게 눌러 선택하면 첫 절의 번호 칸이 빠지고 본문부터 복사됩니다. 이때는 다음 줄 번호를 보고 채웁니다(두권 보기면 같은 절의 첫 번째 역본, 한권 보기면 앞 절). 한 절의 일부만 번호 없이 복사하면 절을 알 수 없어 첫 줄이 `민수기 28장`이 됩니다.

**절을 묶어 보여주는 역본**: 현대인의성경처럼 짧은 절 두 개를 `10-11`처럼 한 번호로 묶어 보여주는 역본도 그대로 인식해서, 묶인 절은 `10-11 ...`로 한 줄에, 나머지 역본은 절마다 따로 붙습니다.

**오늘의 통독 메모**는 처음 열면 `[민수기 12–16장]`처럼 오늘 읽는 범위가 맨 앞에 자동으로 들어가 있어서, 나중에 메모만 봐도 어느 날짜·어느 범위인지 알 수 있습니다.

**두권 보기에서 여러 절을 복사한 경우**: 갓피아는 절마다 두 역본을 번갈아 보여 주지만(1 개역 → 1 새번역 → 2 개역 …), 붙여넣을 때는 **역본별로 절을 이어서** 씁니다. 같은 절 번호가 n번째로 나온 줄을 n번째 역본으로 봅니다.

```
민수기 18:1-3
1 (개역개정 1절)
2 (개역개정 2절)
3 (개역개정 3절)
1 (새번역 1절)
2 (새번역 2절)
3 (새번역 3절)
```

### 기록 내보내기
**현황 → 📥 기록 내보내기**에서 기간(전체 / 이번 달 / 최근 7일 / 최근 30일 / 직접 선택)을 고르고 받습니다.
- **엑셀(.xlsx)**: 요약 · 날짜별 기록(통독 범위, 메모, QT, 묵상 노트) · 메모 모아보기 · 읽은 장 시트
- **텍스트(.txt)**: 날짜별로 읽기 좋게 정리한 기록
- 아이폰 홈 화면 앱에서는 공유 시트가 열리니 "파일에 저장"을 고르세요.

### 메모는 어디에 저장되나요?
- **앱의 통독 메모 · QT 묵상 노트**: 이 기기의 브라우저(또는 홈 화면 앱) 저장소에만 저장됩니다. 서버나 갓피아로 보내지 않습니다. 기기를 바꿀 땐 백업 파일로 옮기세요.
- **갓피아의 형광펜 · 메모 · 좋아요**: 갓피아 계정에 저장되는 기능이라 로그인이 필요합니다. 다른 사이트 안에 넣은 갓피아 화면에서는 브라우저 보안상 갓피아 로그인이 유지되지 않아 눌러도 반응이 없습니다. 통독 → 메모·도구의 **갓피아에서 열기**로 새 창에서 로그인해 사용하세요.

## 갓피아 연동 방식

| 용도 | 주소 |
| --- | --- |
| 한권보기 | `https://www.godpia.com/read/reading.asp?ver=gae&vol=gen&chap=1` |
| 두권보기 | `https://www.godpia.com/read/reading.asp?ver=gae&ver2=niv&vol=gen&chap=1` |
| 오늘의 QT | `https://www.godpia.com/qt/qt.asp` |
| 날짜별 QT | `https://www.godpia.com/qt/qt.asp?D=2026-09-16` |

역본 코드: `gae` 개역개정4판 · `niv` NIV · `han` 개역한글 · `hyun` 현대인의성경 · `saenew` 새번역 · `hebrew` 히브리어(구약) · `greek` 헬라어(신약)
권 코드는 [js/core/bible.js](js/core/bible.js)에 있습니다.

갓피아 화면은 로그인 버튼이 이 앱 탭 전체를 이동시키지 않도록 `sandbox`로 띄웁니다. 갓피아 로그인이 필요한 기능은 "새 창으로 열기"로 이용하세요.

성경 본문은 복사해 오지 않고 갓피아 페이지를 그대로 띄웁니다(저작권은 갓피아와 각 출판사에 있습니다). 갓피아가 사이트 구조를 바꾸면 위 주소를 수정해야 할 수 있습니다.

## 기록 저장에 대해
계획과 기록은 **이 브라우저의 localStorage**에만 저장됩니다. 서버나 로그인이 없어서 간단하지만,
- 다른 기기와 자동으로 동기화되지 않고
- 브라우저 데이터를 지우면 사라집니다.

기기를 옮길 때는 **현황 → 백업 파일 받기**로 JSON 파일을 받아 새 기기에서 불러오세요.

## 배포 (GitHub Pages)
1. 이 저장소의 **Settings → Pages**로 이동
2. **Build and deployment → Source**: `Deploy from a branch`
3. **Branch**: `main` / `/ (root)` 선택 후 Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

수정 후 `main`에 push하면 자동으로 다시 배포됩니다.

## 로컬에서 실행
```bash
python -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다.

## 파일 구조
기능(화면)별로 나눠 두었습니다. 고치고 싶은 기능이 있으면 아래 표에서 해당 파일만 열면 됩니다.

```
index.html              화면 틀·메뉴, 스크립트 불러오는 순서
qt.html                 갓피아 오늘의 QT 바로가기
sw.js                   서비스 워커: 푸시를 받아 시간대별 문구로 알림 (알림 문구 MESSAGES)
manifest.webmanifest    홈 화면 추가용 (앱 이름·아이콘)
icons/                  홈 화면·알림 아이콘

css/
  base.css              공통: 색(라이트/다크), 글꼴, 상단 메뉴, 카드, 버튼
  setup.css             통독 계획 만들기 화면
  reader.css            통독·QT 읽기 화면(갓피아 꽉 채우기), 아래/옆 패널
  stats.css             현황 화면, 리마인드 알림 카드, 기록 내보내기 카드

js/
  core/                 화면과 상관없는 바탕
    bible.js            66권·장 수, 역본 목록, 갓피아 주소 만들기
    store.js            기록 저장(localStorage), 통독 계획 계산
    config.js           알림 서버 주소
  shared/               여러 화면이 함께 쓰는 것
    state.js            앱 상태, 날짜·이름 도우미, 진행률·연속 일수 계산
    godpia.js           갓피아 화면 띄우기 설정(로그인 이탈 방지), 읽기 주소
    ui.js               아래/옆에서 열리는 패널, 토스트 알림
  features/             기능별 화면
    setup.js            통독 계획 만들기·바꾸기
    reader.js           통독 화면: 장 이동, 읽음 체크, 통독표, 보기 설정, 메모·도구
    verses.js           복사한 구절 붙여넣기 양식, 일부만 복사해도 온전한 절로
    qt.js               QT 화면: 날짜 이동, QT 완료, 묵상 노트
    stats.js            현황 화면: 요약 카드, 달력, 최근 기록, 권별 진행, 백업
    export.js           기록 내보내기 (엑셀·텍스트)
    reminder.js         저녁 리마인드 알림 켜기/끄기, 완료 여부 서버 동기화
  main.js               시작점: #today / #qt / #stats 에 맞는 화면 그리기

worker/                 리마인드 알림 서버 (Cloudflare Worker)
```

| 이런 걸 바꾸고 싶다면 | 열어 볼 파일 |
| --- | --- |
| 역본 목록 | `js/core/bible.js` |
| 통독 화면의 버튼·동작 | `js/features/reader.js`, `css/reader.css` |
| 구절 붙여넣기 양식 | `js/features/verses.js` |
| QT 화면 | `js/features/qt.js` |
| 현황·달력 | `js/features/stats.js`, `css/stats.css` |
| 엑셀·텍스트 내보내기 | `js/features/export.js` |
| 알림 시간 | `worker/wrangler.toml` |
| 알림 문구 | `sw.js` |
| 색·글꼴 | `css/base.css` |

스크립트는 빌드 도구 없이 `index.html`에서 순서대로 불러옵니다(core → shared → features → main). 새 파일을 추가하면 `index.html`의 목록에도 넣어 주세요.
