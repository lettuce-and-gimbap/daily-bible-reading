# 매일 5장 통독 · 오늘의 QT

[갓피아(GODpia) 성경](https://www.godpia.com/)으로 **매일 5장씩 성경을 통독**하고, **오늘의 QT(날마다 솟는 샘물)** 에 바로 들어가는 웹페이지입니다.
서버·빌드 없이 HTML/CSS/JS만으로 동작해서 GitHub Pages에 그대로 배포할 수 있습니다.

## 기능

### 1. 오늘 통독 (`#today`)
- **꽉 찬 읽기 화면**: 갓피아 성경 화면이 헤더 아래 전체를 채웁니다. 위쪽 **📖 통독표**, 아래쪽 **📊 현황** 버튼(또는 가운데 오늘 분량 제목)을 누르면 옆/아래에서 패널이 열리고, 패널을 열고 닫아도 갓피아 화면은 그대로 유지됩니다.
- **통독표**: 전체 Day 목록(계획일, 분량, 완료 여부)을 보고 원하는 Day로 바로 이동합니다.
- **계획 만들기**: 시작 권·장, 하루 분량(기본 5장), 시작일, 통독 범위(요한계시록까지 / 성경 전체 1독)를 고르면 Day별 분량을 자동으로 나눕니다.
- **오늘 읽을 분량**: 아직 다 읽지 않은 첫 Day를 보여 주고, 각 장을 눌러 본문을 엽니다. ‹ › 로 다른 Day도 볼 수 있습니다.
- **갓피아 본문 보기**: 개역개정 4판 / 쉬운성경 / 새번역 / NIV 중에서 고르고, **한권보기 ↔ 두권보기**를 버튼 하나로 전환합니다.
- **읽음 체크**: "읽었어요 · 다음 장으로"를 누르면 날짜와 함께 기록되고 다음 장으로 넘어갑니다.
- **몰아서 체크**: 갓피아 화면 안에서 옆으로 넘기며 읽었다면, 마지막으로 읽은 장을 골라 그 앞의 안 읽은 장을 한 번에 체크합니다. (갓피아는 다른 사이트라 브라우저 보안상 그 안에서 장을 넘긴 것을 이 앱이 직접 알 수 없습니다.)
- **오늘 분량 복사**: 투두메이트 같은 할 일 앱에 붙여넣을 수 있게 오늘 분량을 복사합니다.
- **통독 메모**: 날짜별로 짧은 묵상 메모를 남길 수 있습니다.

### 2. 현황·기록 (`#stats`)
- 진행률, 읽은 장 수, 완료한 Day, 연속 통독 일수, 계획 대비 앞섬/밀림, 예상 완료일
- 최근 20주 통독 달력, 권별 진행 막대, 날짜별 읽은 범위와 메모
- 백업 파일 받기/불러오기, 계획 변경, 기록 초기화

### 3. 오늘의 QT (`#qt`)
- 갓피아 QT 화면을 꽉 채워 보여 주고, 위쪽에서 날짜 이동, 아래쪽에서 **📝 묵상 노트**와 **QT 완료**를 체크합니다.
- 갓피아 "날마다 솟는 샘물" 오늘 본문을 페이지 안에서 바로 보여 주고, 전날/다음날·날짜 선택으로 이동합니다.
- "갓피아 QT 바로 열기" 버튼으로 갓피아 원래 페이지를 새 창에서 엽니다.
- 묵상 노트와 QT 완료 체크, 최근 QT 기록
- **`qt.html`**: 열자마자 갓피아 오늘의 QT로 이동하는 바로가기 주소입니다. 휴대폰 홈 화면이나 북마크에 추가해 두세요.

## 갓피아 연동 방식

| 용도 | 주소 |
| --- | --- |
| 한권보기 | `https://www.godpia.com/read/reading.asp?ver=gae&vol=gen&chap=1` |
| 두권보기 | `https://www.godpia.com/read/reading.asp?ver=gae&ver2=niv&vol=gen&chap=1` |
| 오늘의 QT | `https://www.godpia.com/qt/qt.asp` |
| 날짜별 QT | `https://www.godpia.com/qt/qt.asp?D=2026-09-16` |

역본 코드: `gae` 개역개정 4판 · `easy` 쉬운성경 · `saenew` 새번역 · `niv` NIV
권 코드는 [js/bible.js](js/bible.js)에 있습니다.

갓피아 화면은 로그인 버튼이 이 앱 탭 전체를 이동시키지 않도록 `sandbox`로 띄웁니다. 갓피아 로그인이 필요한 기능은 "새 창으로 열기"로 이용하세요.

성경 본문은 복사해 오지 않고 갓피아 페이지를 그대로 띄웁니다(저작권은 갓피아와 각 출판사에 있습니다). 갓피아가 사이트 구조를 바꾸면 위 주소를 수정해야 할 수 있습니다.

## 기록 저장에 대해
계획과 기록은 **이 브라우저의 localStorage**에만 저장됩니다. 서버나 로그인이 없어서 간단하지만,
- 다른 기기와 자동으로 동기화되지 않고
- 브라우저 데이터를 지우면 사라집니다.

기기를 옮길 때는 **현황·기록 → 백업 파일 받기**로 JSON 파일을 받아 새 기기에서 불러오세요.

## 배포 (GitHub Pages)
1. 이 저장소의 **Settings → Pages**로 이동
2. **Build and deployment → Source**: `Deploy from a branch`
3. **Branch**: `main` / `/ (root)` 선택 후 Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.

수정 후 `main`에 push하면 자동으로 다시 배포됩니다.

## 로컬에서 실행
```bash
python -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다.

