# 역대상·하: 계보, 왕의 변화, 발화자, UI 설계

## 범위와 읽는 원칙

이 문서는 역대상 1–29장과 역대하 1–36장을 대상으로 한다. 계보는 역대상 1–9장의 전체 구성을 아홉 축으로 정리하고, 다윗 왕실·왕위 계승·제사장 계열의 주요 연결을 풀었다. 모든 이름을 개별 노드로 전사한 완성 가계도는 아니다. 사울·다윗과 역대하의 솔로몬 이후 통치자, 아달랴를 포함한 23명은 각각 평가와 변화 근거를 정리했다. 북이스라엘·외국·에돔의 왕은 역대서에 등장하는 범위와 평가 한계를 따로 적었다.

현재 앱의 역사서 창작 발화 DB에서 역대상·하에 속한 109행과 59개 발화자 표시를 모두 목록화했다. 이는 두 권에 나오는 모든 실제 발언을 앱에 이미 수록했다는 뜻도, 109행의 창작 문장 모두를 직접 인용으로 인증했다는 뜻도 아니다. 이 문서의 발화 목록은 역할·출처를 구분하는 검토 목록이다.

- 기준 자료: 보관된 개역개정 4판·쉬운성경 Markdown. 주요 계보와 아래 왕별 평가·전환 구절을 두 역본으로 대조했다. 비공개 SQLite는 이 환경에 없어 사용하지 않았다.
- 외부 권의 정보를 채워 넣어 판단하지 않는다. 열왕기서의 솔로몬 말년 배교, 아비야·여호아하스의 평가를 자동 수입하지 않는다.
- '선한 왕'이라는 총평, 특정 행동의 선악, 겸비·회개, 백성의 상태, 결과를 각각 구별한다.
- 경건한 발언 한 번으로 왕의 생애를 선하다고 판정하지 않는다. 발화자의 주장과 본문의 평가가 다를 수 있다.
- '회개 기록 없음'은 회개하지 않았음을 모두 입증한다는 뜻이 아니다. 아몬·시드기야처럼 겸비나 돌이킴의 거부가 명시된 경우와 구별한다.
- 징계·질병·전쟁 패배를 현대 독자의 모든 질병·실패에 적용하는 인과 공식으로 만들지 않는다.
- 성경 원문은 이 문서나 JSON에 복사하지 않고 직접 작성한 요약과 근거만 보관한다.

## 1. 전체 계보를 읽는 아홉 축

### 역대상 1장 — 전체 인류·족장·에돔

아담에서 노아의 세 아들로 분기하고 셈–아브라함–이삭–이스라엘로 초점을 좁힌다. 에돔 왕위 계승 목록은 부자 계보와 구별한다.

### 역대상 2장 — 유다·다윗의 조상

유다–베레스–헤스론–람–암미나답–나손–살마–보아스–오벳–이새–다윗이 중심 줄기다. 여라므엘·갈렙 등 방계가 함께 나온다.

### 역대상 3장 — 다윗의 자녀·왕조·포로 이후

헤브론의 여섯 아들, 예루살렘 자녀와 솔로몬 왕조, 요시야의 여러 아들, 여고냐 및 포로 이후 후손을 구분한다.

### 역대상 4장 — 유다의 방계·시므온

여러 유다 집안과 지역 공동체, 야베스 이야기, 시므온 자손과 정착을 함께 보여준다. 모든 지명·족속명은 개인이 아니다.

### 역대상 5장 — 르우벤·갓·므낫세 반 지파

장자권·통치권·족보의 나열 순서가 다르다. 르우벤의 장자권 상실, 요셉 집의 장자권, 유다의 통치자 배출을 구분한다.

### 역대상 6장 — 레위·제사장·성전 봉사

레위의 게르손·그핫·므라리 갈래, 아론의 제사장 후손, 찬양 담당 헤만·아삽·에단 계열과 성읍을 구분한다.

### 역대상 7장 — 북부 지파 계보

잇사갈·베냐민·납달리·므낫세·에브라임·아셀의 집안과 군사·지역 목록이 섞인다. 딸·성읍 건설자도 개인 카드에 보존한다.

### 역대상 8장 — 베냐민·사울 가문

베냐민의 여러 집안에서 사울–요나단–므립바알–미가의 후손으로 좁혀진다. 왕권 상실과 가족 계보의 지속은 별개다.

### 역대상 9장 — 귀환 공동체·직무·사울 가문 반복

귀환 공동체의 일반 백성·제사장·레위인·문지기를 보여주고 사울 집안을 다시 연결하여 10장의 왕권 이전으로 넘어간다.

### 세 줄기를 따로 보기

1. **온 인류에서 이스라엘까지**: 아담 → 셋 → 에노스 → 게난 → 마할랄렐 → 야렛 → 에녹 → 므두셀라 → 라멕 → 노아 → 셈 → 아르박삿 → 셀라 → 에벨 → 벨렉 → 르우 → 스룩 → 나홀 → 데라 → 아브라함 → 이삭 → 이스라엘. 근거: 대상 1:1–4, 24–28, 34. 노아의 함·야벳과 아브라함의 이스마엘·그두라 자손, 이삭의 에서도 방계로 남긴다.
2. **유다에서 다윗까지**: 유다 → 베레스 → 헤스론 → 람 → 암미나답 → 나손 → 살마 → 보아스 → 오벳 → 이새 → 다윗. 근거: 대상 2:4–15. 족장 시대의 왕권 약속과 이후 실제 왕위를 혼동하지 않는다.
3. **레위에서 제사장 계열까지**: 레위 → 그핫 → 아므람 → 아론 → 엘르아살 → 비느하스 → 아비수아 → 북기 → 웃시 → 스라히야 → 므라욧 → 아마랴 → 아히둡 → 사독 → 아히마아스. 근거: 대상 6:1–3, 50–53. 게르손·므라리 계열, 아론의 다른 아들들, 찬양 봉사자의 계열은 별도 갈래다. 다윗 왕조의 혈통에 합치지 않는다.

### 다윗의 자녀와 포로 이후

- 헤브론에서 낳은 여섯 아들: 암논·다니엘·압살롬·아도니야·스바댜·이드르암. 어머니는 각각 아히노암·아비가일·마아가·학깃·아비달·에글라로 기록된다(대상 3:1–4).
- 예루살렘에서 밧수아에게서 낳은 시므아·소밥·나단·솔로몬과 다른 아홉 아들, 딸 다말, 별도로 언급한 소실의 아들들을 구분한다(3:5–9). 다윗의 아들 나단과 선지자 나단은 다른 노드다.
- 솔로몬으로 왕위가 이어졌다고 다른 아들들의 혈통이 사라진 것은 아니다. UI에서는 혈통 갈래와 선택된 왕위 계승선을 함께 보인다.
- 포로 뒤에도 여고냐 집안, 스알디엘·브다야, 스룹바벨과 이후 후손을 적는다(3:17–24). 왕실의 후손이 계속된다는 기록과 각 인물이 실제 왕위에 올랐다는 주장은 다르다.
- 대상 3:19는 스룹바벨을 **브다야의 아들**로 연결한다. 다른 권의 스알디엘 호칭을 가져와 이 연결을 덮어쓰지 않는다.
- 대상 3:21의 후손 배열과 3:22의 '여섯'이 묶는 범위에는 두 역본의 표현 차이가 있다. 연속된 아들 간선을 임의로 확정하지 않고 출처별 구조를 보존한다.

### 사울의 가문과 왕권 이전

대상 8장과 9장의 반복 계보는 베냐민 지파와 사울 가문을 소개하고, 10장의 사울 사망·다윗으로의 왕권 이전으로 연결한다. 대상 9:39–44에서 넬 → 기스 → 사울 → 요나단 → 므립바알 → 미가의 계열과 후손들이 이어진다. 사울의 왕권이 끝나도 가문의 후손 명단은 남는다. 다윗을 사울의 친아들로 그리면 안 된다.

## 2. 혈통과 왕위 계승은 다른 선이다

**통치 순서**: 사울 → 다윗 → 솔로몬 → 르호보암 → 아비야 → 아사 → 여호사밧 → 여호람 → 아하시야 → 아달랴 → 요아스 → 아마샤 → 웃시야 → 요담 → 아하스 → 히스기야 → 므낫세 → 아몬 → 요시야 → 여호아하스 → 여호야김 → 여호야긴 → 시드기야.

이 줄은 **왕위 계승선**이다. 사울–다윗, 아하시야–아달랴–요아스, 마지막 네 왕을 모두 부자선으로 바꾸면 안 된다.

- 아달랴는 아하시야의 어머니이며 오므리의 손녀로 소개된다(대하 22:2). 아하시야의 아들 요아스를 숨긴 사람은 아하시야의 누이이자 여호야다의 아내인 여호사브앗이다(22:11). 아달랴가 요아스의 어머니인 것처럼 그리지 않는다.
- 요시야의 아들 명단에는 요하난·여호야김·시드기야·살룸이 있다(대상 3:15). 대하 36장의 여호아하스·여호야김은 요시야의 아들들, 여호야긴은 여호야김의 아들, 마지막 시드기야는 대상 3:15와 연결되는 요시야의 아들로 읽는다.
- 대하 36:10은 여호야긴에 대한 시드기야의 관계를 개역개정은 숙부, 쉬운성경은 친척으로 옮긴다. 앞 왕의 아들로 연결하지 않는다.
- 대상 3:16은 개역개정의 아들 표현과 쉬운성경의 왕위 계승 표현이 다르다. 3:15의 시드기야와 같은 인물인지 여부를 이름만으로 처리하지 않고, **계보 표현 주의** 표식을 둔다.
- 여호야김=엘리아김은 대하 36:4가 직접 개명을 설명한다. 웃시야/아사랴(대상 3:12; 대하 26:1), 여고냐/여호야긴(대상 3:16–17; 대하 36:9–10)은 출처별 표기를 함께 보인다. 살룸과 여호아하스의 동일시는 두 권 안에서 직접 개명으로 설명되지 않으므로 자동 확정하지 않는다.
- 르호보암의 아내 마아가(대하 11:20), 아비야의 어머니 미가야(13:2), 아사 왕의 어머니로 지칭된 마아가(15:16)의 관계는 세대 생략·호칭·표기 문제가 있다. 전통적 동일시를 설명할 수는 있어도 이름을 강제로 합친 뒤 생물학적 간선을 생성하지 않는다.

### 특히 단순 색칠을 피할 왕

- **아사**: 대하 15:17의 평생 온전한 마음이라는 긍정과 16장의 불순종을 모두 보존한다. 후반 사건을 삭제하거나 전체 생애를 악 하나로 덮지 않는다.
- **여호사밧**: 정직한 통치 평가와 반복된 잘못된 동맹이 병존한다. 17:6과 20:33의 산당 표현도 한 구절로만 평준화하지 않는다.
- **요아스**: 여호야다 생전/사후가 명시적 전환점이다. 선지자 스가랴를 살해한 명령이 말보다 중요한 평가 근거다.
- **아마샤**: 처음부터 온전하지 않은 마음이라는 제한이 있다. 승리 뒤의 우상숭배는 추가 전환이다.
- **웃시야**: 강성해짐 → 교만 → 분향 직무 침범 → 책망 거부의 순서를 보인다. 병에서 나온 행동을 자동으로 회개라 이름 붙이지 않는다.
- **히스기야**: 예배 회복 → 교만 → 겸비. 회개가 명시되어 있으므로 실패만 남기지 않는다.
- **므낫세**: 악행 → 환난 → 겸비·기도 → 회복·개혁. 회개 뒤에도 백성의 산당 관행은 남았다(33:17). 왕의 회개와 공동체 전체의 관행이 같은 속도로 바뀐 것은 아니다.
- **요시야**: 정직·율법 앞의 겸비와 마지막 전쟁의 불순종을 함께 표시한다. 느고의 발언을 이방 왕의 허세로만 처리할 수 없는 이유는 35:22의 서술자 평가다.
- **여호아하스**: 역대서에 정형적 선악 총평이 없다는 사실 자체가 데이터다. 빈 값을 악으로 자동 변환하지 않는다.

### 에돔 왕 목록

대상 1:43–50의 벨라 → 요밥 → 후삼 → 하닷(브닷의 아들) → 사믈라 → 사울 → 바알하난 → 하닷은 왕위 계승 목록이다. 각 왕의 부친·도시가 따로 적혀 있으므로 이를 부자 직계로 그리지 않는다. 이 사울은 베냐민 지파의 사울 왕과 다르다. 두 하닷도 구별한다. 이 목록에는 각 인물에 대한 여호와 보시기에 선/악이라는 총평이 없다.

### 외국 통치자

후람(두로 왕, 대하 2장), 스바 여왕(9장), 시삭(12장), 벤하닷(16장), 아람 왕(18장), 산헤립(32장), 앗수르 왕 불·디글랏빌레셀(대상 5:26; 대하 28:20), 바벨론 왕과 군대(33장·36장), 느고(35–36장), 고레스(36:22–23)는 유다 왕 계보 바깥의 인물이다. 사건 속 행동·발언을 보여주되 유다 왕과 같은 선악 총평 칸을 억지로 채우지 않는다. 스바 여왕의 찬사·고레스의 명령·느고의 경고가 있다고 그들의 전체 생애나 회심을 역대서가 확정한다고 하지 않는다. 하닷에셀·나하스·하눈 등 대상 18–19장의 주변국 왕들은 다윗의 전쟁·외교 관계로 연결한다.

## 5. 발화자를 기준으로 읽는 방법

발화마다 네 항목을 구별한다: **표시 인물 / 말의 근원 / 전달 형식 / 본문의 평가**. 선지자가 하나님의 말씀을 전할 때 발화자는 선지자, 근원은 여호와, 형식은 대언이 될 수 있다. 반대로 거짓 선지자의 '여호와께서 말씀하셨다'는 주장을 하나님의 승인된 말씀으로 분류하면 안 된다.

## 6. 추천 UI

첫 화면은 거대한 계보 전체보다 **왕의 흐름**을 기본으로 한다. 위에 `왕의 흐름 · 계보 · 말씀과 응답` 탭을 둔다. 어느 탭에서든 같은 인물 카드를 연다.

### 왕의 흐름 — 기본 화면

모바일에서는 왕을 세로 카드로 연결한다. 카드에 이름·통치 순서·혈통 관계·한 줄 평가와 변화 화살표를 보인다. 예: `히스기야 / 선·정직 → 교만 → 겸비`, `므낫세 / 악행 → 환난 → 회개·개혁`.

- 카드의 색 하나로 생애 전체를 판정하지 않는다. 텍스트 배지와 사건 순서를 함께 표시한다.
- 평가 종류는 `긍정 평가`, `악행·불순종`, `겸비·회개`, `평가 기록 없음`, `자료 주의`로 분리한다. 좋은/나쁜 정도를 수치로 계산하지 않는다.
- 사건을 누르면 **무슨 일이 있었나 → 누구의 말이 있었나 → 왕이 어떻게 응답했나 → 근거 절** 순서로 펼친다.
- 아사·여호사밧·요시야처럼 긍정 총평과 실패가 병존하면 둘 다 남긴다. 뒤의 사건으로 앞의 총평을 지우지 않는다.
- 필터는 `전체`, `회개·겸비`, `후반 이탈`, `정직 평가`, `평가 없음`. 예를 들어 므낫세와 히스기야가 회개·겸비 필터에 함께 나타나되 이전 상태는 다르게 보인다.

### 계보 — 혈통과 계승을 선택

맨 위에 `혈통 / 왕위 계승` 전환을 둔다. 혈통에서는 다윗–솔로몬의 줄과 아달랴의 혼인·모계 연결을 표시하고, 왕위 계승에서는 아달랴의 통치 삽입과 마지막 네 왕의 교체를 표시한다.

- 모바일은 선택한 인물의 `부모 · 본인 · 자녀` 세대만 먼저 펼친다. 형제·배우자·방계는 버튼으로 확장한다. PC는 가로 계보를 추가할 수 있다.
- 줄을 생략하면 `중간 여러 세대`라고 표시한다. 아담→다윗을 바로 친자 간선으로 그리지 않는다.
- 실제 친자 관계는 실선, 혼인은 별도 연결, 왕위 계승은 화살표, 불확실·번역차이는 점선과 근거 배지로 구분한다.
- 어머니·왕대비·여성 보호자도 정보 패널에서 빠지지 않게 한다. 아달랴·여호사브앗·마아가의 역할을 왕의 부속 메모로만 숨기지 않는다.
- 계보의 이름·도시·족속·직무 집단을 다른 노드 유형으로 저장한다. 모든 이름을 발화 가능한 개인으로 만들지 않는다.

### 말씀과 응답 — 발화에서 사건으로

`다윗 → 솔로몬에게 당부`, `하나니 → 아사에게 경고 → 거부`, `훌다 → 요시야의 사자들에게 말씀 → 겸비`처럼 메시지와 응답을 연결한다. 이 탭에서는 혈통선보다 영향선을 강조한다.

- `본문의 직접 발언`, `서술된 행동·기도`, `편지`, `찬송`, `앱의 본문 기반 재구성`을 표시한다.
- 나단의 대상 17:2 개인 판단과 17:4–15의 하나님 말씀 전달을 다른 사건으로 구분한다.
- 므낫세 기도는 `기도한 사실이 기록됨 / 기도문 내용 없음`으로 보인다. 앱 창작 기도를 원문처럼 인용부호로 보여주지 않는다.
- 그나아나의 아들 시드기야의 말에는 `거짓 예언으로 드러남`, 산헤립의 말에는 `적국의 주장`을 붙인다.
- 현재 발화 DB에 없더라도 본문 사건에는 등장하는 인물·말씀을 `발화 미수록`으로 구분한다. 본문과 앱 수록 범위를 같은 것으로 보이지 않게 한다.

### 공통 데이터 구조와 구현 순서

1. 이번 `data/chronicles-guide.json`은 검토용 자료다. 곧바로 검증 완료된 혈통 간선 DB로 사용하지 않는다. `parentageLabel`은 표시 설명이며 친자 ID가 아니다.
2. 기존 통독·PIXEL BIBLE이 함께 사용하는 인물 ID에 왕실 인물을 대응하고, 동명이인·불확실 간선을 먼저 검토한다.
3. 계보 관계(`부모`, `혼인`, `친족`)와 역사 관계(`왕위 계승`, `말씀 전달`, `조언`, `보호`)를 별도 필드로 저장한다.
4. 평가는 `인물 + 시기/사건 + 평가 종류 + 평가 주체 + 직접 근거 절 + 요약`으로 저장한다. 왕의 카드에 boolean `good` 하나만 두지 않는다.
5. 통독의 역대서 요약 탭과 PIXEL BIBLE의 인물 상세가 같은 관계·평가 데이터를 읽게 한다. UI별 선악 문구를 복제하지 않는다.
6. 처음에는 왕 23명의 변화 카드와 근거 열기부터 구현한다. 개별 이름까지 완성한 전체 계보 트리는 동명이인·지명·세대 생략의 검토를 마친 뒤 확장한다.

실제 탐색 화면을 앱에 연결했다. 관리 화면의 `역대상·하 왕과 계보` 버튼 또는 역대서 통독 요약 위쪽의 같은 버튼으로 연다. 왕의 흐름·계보·말씀과 응답을 검색하고, 인물을 눌러 연결된 관계와 근거를 확인할 수 있다. 거대한 전체 계보를 한 번에 그리는 대신 선택 인물 중심의 탐색 목록을 제공한다.
