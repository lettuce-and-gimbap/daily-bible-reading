# 인물 대사 전수 보강 작업안

## 시작 조건

이 작업은 구약 사건 장면 전수 보강이 끝난 뒤 시작한다. 현재 진행 중인 사건 검토를 대사 변경과 섞지 않는다. 시작 전 사건 데이터와 구절 범위의 검수·테스트를 마치고, 신약 27권에 같은 사건 장면 검토를 완료한 다음 본 작업으로 전환한다.

## 권별 검토 순서

창세기부터 요한계시록까지 66권을 정경 순서대로 처리한다. 각 권에서 장별 인물·관계도·사건 후보와 대사 레코드를 대조한다. 인물 이름이 함께 등장한다는 이유만으로 실제 대면이나 친밀한 관계를 지어내지 않는다. 혈육·지인·갈등·협력 관계와 해당 사건에 함께 연루된 근거를 구분하고, 만남이 본문에서 확인되지 않으면 대사를 실제 만남인 것처럼 연출하지 않는다.

## 대사 교정 기준

- 관계 대화는 두 발화가 같은 상황을 이어받고 앞말에 답하도록 작성한다. 두 인물이 서로 다른 독백을 연달아 말하는 형태를 통과시키지 않는다.
- 관계, 사건, 당시의 선택과 감정이 본문·장별 자료에 연결되는지 살핀다. 근거가 없는 사적 감정, 만남, 발언을 사실처럼 단정하지 않는다. 대사는 창작 재구성임을 유지한다.
- 독백은 해당 인물의 1인칭으로 작성한다. 해당 장면의 이해관계·감정·지식 범위를 확인하고, 이후 사건을 미리 아는 표현이나 서술자 시점 문장을 걸러낸다.
- 특수 대화는 해당 사건에 연루된 인물 조합과 장에서만 활성화한다. 자료 근거가 약한 관계는 일반 인사말로 대체하거나 특수 대화 후보에서 제외한다.
- 말풍선의 `자세히 보기` 진입은 관계 대화에서도 항상 유지한다. 말풍선에는 별도의 성경 구절 보기 버튼을 두지 않고, 자세히 보기 화면 안에 관련 본문 보기 링크를 둔다.

## 권별 완료 검수

각 권은 관계 근거, 사건별 대화 쌍, 독백의 시점·감정, 장·절 연결, 자세히 보기·본문 링크 동작을 점검한다. 대화 쌍은 공통 상황·참조 구절·대화 변형 번호를 공유하고 양쪽 발화가 모두 존재하는지 자동 검사한다. 독백은 문장 자체가 인물 발화로 읽히고 해당 장의 근거와 연결되는지 검토한다. 수정 전후 테스트와 원문 비공개 검사를 실행한 뒤 권별로 `main`에 커밋·푸시한다.

## 확인할 코드와 데이터

- 대사 원본: `js/features/pixel-bible/pair-dialogue.js`, `solo-dialogue.js`, `major-dialogue.js`, 장별 대사 파일
- 후보 연결·관계 근거: `js/features/pixel-bible/dialogue.js`, `relationship-lines.js`, 장별 요약·관계 데이터
- 독백 시점 교정: `personal-lines.js`, `role-monologues.js`
- 말풍선·자세히 보기·본문 링크: `js/features/pixel-bible/world.js`의 일반 발화 및 조우 말풍선 처리
- 전 권 대조와 회귀 테스트: `tools/pixel-bible/dialogue-coverage.mjs`, `tests/new-testament-dialogue.test.mjs` 및 대사·월드 테스트

대사 자료는 공개 성경 원문을 복제하지 않고 새로 작성한 짧은 발화와 근거 참조만 저장한다. 비공개 원문이나 주석 전문은 생성물·테스트 fixture·문서에 넣지 않는다.
