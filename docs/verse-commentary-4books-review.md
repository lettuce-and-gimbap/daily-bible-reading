# 사무엘상·하와 열왕기상·하 절별 주석 진행 기록

## 표시 방식

`본문`의 해당 절에서 주석 버튼을 누르면 구절 해설과 원어 설명, 관련 실제 사진을 연다. `data/verse-study/<권>.json`은 새로 작성한 설명이고 `<권>-existing.json`은 기존 장별 심화 해설 중 절 번호가 명시된 문단과 사진 자료를 해당 절에 연결한 것이다. 기존 해설을 절에 연결한 것과 새로 원문·주석을 감수한 것은 다르므로, 각 주석의 출처 안내를 구분했다. 사진이 사건의 직접 기록인지 후대 풍경·비교 유물인지 구분하며, 원본과 이용 조건의 확인 범위는 항목별로 다르다.

## 이전 작업 당시 확인된 범위와 남은 검토

- 사무엘상: 1–17장의 새 구간 주석은 개역개정과 쉬운성경 및 개인 주석을 대조한 보고가 있다. 18–20장은 작업이 중단되어 개별 출처 기록의 추가 확인이 필요하다. 21장은 두 역본을 직접 확인해 4개 해설을 추가했다. 22–31장은 기존 심화 해설을 근거 절에 연결했으나 새 절별 주석과 전 범위 대조는 완료되지 않았다.
- 사무엘하: 1–24장의 새 구간 주석은 두 역본을 확인한 보고가 있다. 10–24장의 개인 주석과 신학적 내용은 전 범위 대조가 남았다.
- 열왕기상: 22개 장 모두 기존 심화 해설의 근거 절을 연결했고 새 구간 주석도 보강했다. 14장을 제외한 장 전체의 두 역본·주석 대조와 빠진 절의 상세 설명은 완료되지 않았다. 작업 중단 시 추가된 항목은 별도 확인이 필요하다.
- 열왕기하: 새 구간 주석이 1–25장의 모든 절을 포괄한다. 1–13장은 두 역본 대조 보고가 있고, 14–25장은 작업 중단으로 출처·주석 및 신학적 내용의 전 범위 검증이 완료되지 않았다.

1,189장 전체의 교리 감수나 네 권 모든 절의 신학 감수가 완료됐다고 주장하지 않는다. 개인 소장 성경 원문과 주석 텍스트는 저장소에 포함하지 않는다. 검토 기준은 성경 본문과 예장합동 개혁주의 관점이며, 판본별 표현이나 동일성이 불확실한 역사 자료는 구분한다.

## 테스트 한계

절 범위·출처 형식·사진 경로·비동기 부착을 자동 검사했다. 브라우저에서 사무엘상 17장 1절의 주석 버튼과 사진 주석창을 모의 데이터 로딩으로 확인했으나 실제 서버에서 이미지가 표시되는 과정은 검증하지 못했다. 기존 `tests/scripture-notes.test.mjs`의 문맥 주석 수 검사 기대값 9,326과 기존 데이터 9,296의 차이는 이번 변경 전부터 재현된다.

## 추가 감수 기록 (2026-11-26)

- 사무엘상 21:2, 6–7과 22:9–10을 원문과 호크마에 대조해 히브리어 본문의 절 번호 차이 때문에 잘못 연결된 설명을 바로잡았다. 22–31장의 기존 절별 설명 35개는 개역개정·쉬운성경과 이용 가능한 호크마 정리에 대조해 일부 설명을 고쳤다. 이는 그 범위의 모든 절에 주석이 있다는 뜻은 아니다.
- 사무엘상 11–14·17–20장에 등록된 해설 71개도 두 역본과 이용 가능한 호크마 정리에 대조했다. 1–31장 기존 원어 해설의 표제어와 본문 어형은 히브리어 본문·사전으로 별도 확인했다. 이는 모든 히브리어 낱말이나 사본 이문을 검토했다는 뜻이 아니다. 호크마 14장에는 원문 주석이 없고 일부 다른 구절도 손상됐다.
- 사무엘하 1·3·4·8–10장의 등록 해설 45개, 2·5–7·20장의 기존 해설 41개와 11–19·22–23장의 등록 해설 97개는 개역개정·쉬운성경과 이용 가능한 호크마 정리에 대조했다. 21·24장도 두 파일의 등록 해설을 대조했다. 20:8–9 및 11–26, 13:13, 17:17의 호크마 원 주석에는 누락이 있다. 사진 세 건의 소장기관 권리 안내는 검색 색인으로 확인했으며, 기관 원본 페이지는 직접 접속이 차단됐다. 자료의 역사적 동일성은 별도 문제다.
- 열왕기상 12–22장의 기존 및 신규 절별 해설 73개는 개역개정·쉬운성경과 이용 가능한 호크마 정리에 대조했다. 13:2와 20:38–43의 주석은 누락 또는 제한적이다. 4–22장의 기존 원어 해설은 히브리어 본문과 사전 등을 참고했으나 일부 별도 사전 확인이 남았다. 사진 자료는 실제 사건의 직접 기록과 비교 자료를 구분했으며 접근이 차단된 원본 자료도 있다.
- 열왕기하 4–13장의 해설 74개는 두 역본과 이용 가능한 호크마 정리에 대조했고, 14–25장의 해설 91개는 두 역본과 대조했다. 13:14–21의 주석은 누락되었거나 불충분하다. 1–3장은 개역개정과 호크마 정리에 대조했다. 히브리어가 포함된 45개 항목의 핵심 표기·어휘는 본문과 BDB 사전에 대조했다. 이는 모든 형태론과 신학 해석이나 그리스어 사본 이문 검토를 뜻하지 않는다.
- 사진 데이터에 있던 기관 참고 링크가 절별 주석에 빠지지 않도록 복구했다. 링크 복구는 모든 사진과 이용 조건에 대한 재검증을 뜻하지 않는다. 히브리어 본문 표기 확인과 별도 사전에 의한 뜻·형태 분석 검증은 구분한다.
- 사무엘하의 원어 해설은 주요 26개 구절의 표기와 어휘를 히브리어 본문·사전으로 대조했다. 15:7 등의 사본 이문은 별도 검증이 남아 있다. 열왕기하 사진은 직접 기록과 비교 자료를 구분해 수정했으며, 박물관 개별 소장기록에 접근하지 못한 항목은 그 사실을 표시했다.
- 기존 설명을 다시 생성할 때 수동 감수 결과를 덮어쓰지 않도록 도구를 수정했다. 합쳐진 절 표기를 제대로 읽도록 원문 범위 검사도 고쳤으며, 수정 후 별도의 절 수로 범위만 대조하는 불완전한 개역개정 장은 9개다.

위 범위 외의 원어 설명·사진 권리·교리 해석을 모두 독립적으로 검증한 것은 아니다. 호크마 정리가 손상되거나 빠진 구절은 해당 사실을 유지하고, 확인되지 않은 내용은 완료로 처리하지 않는다.
