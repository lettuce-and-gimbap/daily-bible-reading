# 사무엘상·하와 열왕기상·하 절별 주석 진행 기록

## 표시 방식

`본문`의 해당 절에서 주석 버튼을 누르면 구절 해설과 원어 설명, 관련 실제 사진을 연다. `data/verse-study/<권>.json`은 새로 작성한 설명이고 `<권>-existing.json`은 기존 장별 심화 해설 중 절 번호가 명시된 문단과 이미 출처·권리를 확인한 실물 사진을 해당 절에 연결한 것이다. 기존 해설을 절에 연결한 것과 새로 원문·주석을 감수한 것은 다르므로, 각 주석의 출처 안내를 구분했다. 사진이 사건의 직접 기록인지 후대 풍경·비교 유물인지 함께 밝힌다.

## 확인된 범위와 남은 검토

- 사무엘상: 1–17장의 새 구간 주석은 개역개정과 쉬운성경 및 개인 주석을 대조한 보고가 있다. 18–20장은 작업이 중단되어 개별 출처 기록의 추가 확인이 필요하다. 21장은 두 역본을 직접 확인해 4개 해설을 추가했다. 22–31장은 기존 심화 해설을 근거 절에 연결했으나 새 절별 주석과 전 범위 대조는 완료되지 않았다.
- 사무엘하: 1–24장의 새 구간 주석은 두 역본을 확인한 보고가 있다. 10–24장의 개인 주석과 신학적 내용은 전 범위 대조가 남았다.
- 열왕기상: 22개 장 모두 기존 심화 해설의 근거 절을 연결했고 새 구간 주석도 보강했다. 14장을 제외한 장 전체의 두 역본·주석 대조와 빠진 절의 상세 설명은 완료되지 않았다. 작업 중단 시 추가된 항목은 별도 확인이 필요하다.
- 열왕기하: 새 구간 주석이 1–25장의 모든 절을 포괄한다. 1–13장은 두 역본 대조 보고가 있고, 14–25장은 작업 중단으로 출처·주석 및 신학적 내용의 전 범위 검증이 완료되지 않았다.

1,189장 전체의 교리 감수나 네 권 모든 절의 신학 감수가 완료됐다고 주장하지 않는다. 개인 소장 성경 원문과 주석 텍스트는 저장소에 포함하지 않는다. 검토 기준은 성경 본문과 예장합동 개혁주의 관점이며, 판본별 표현이나 동일성이 불확실한 역사 자료는 구분한다.

## 테스트 한계

절 범위·출처 형식·사진 경로·비동기 부착을 자동 검사했다. 브라우저에서 사무엘상 17장 1절의 주석 버튼과 사진 주석창을 모의 데이터 로딩으로 확인했으나 실제 서버에서 이미지가 표시되는 과정은 검증하지 못했다. 기존 `tests/scripture-notes.test.mjs`의 문맥 주석 수 검사 기대값 9,326과 기존 데이터 9,296의 차이는 이번 변경 전부터 재현된다.
