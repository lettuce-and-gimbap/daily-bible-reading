# 공개 성경 본문 DB

사용자가 여섯 업로드 역본의 공개를 요청한 뒤, `data/scripture/{book}.json`에 권별 본문을 생성했다. 각 파일은 `editions` 아래 `gae`, `easy`, `niv`, `han`, `hyun`, `saenew` 여섯 배열을 담고, 배열 인덱스가 장 번호이며 각 행은 `[절 번호, 본문]`이다. 통독·QT 본문 선택 화면은 이 정적 DB를 직접 읽는다. 갓피아 새 창 링크는 별도 기능으로 남아 있다.

원본 Markdown과 작업용 SQLite DB는 `/workspace/private-reference/bible`에 별도로 보관한다. 공개 DB 재생성은 `python tools/commentary/export-public-scripture.py`로 한다. 새로 제공받은 세 역본은 `python tools/commentary/import-added-editions.py`로 작업용 DB에 등록했다.

여섯 역본 모두 66권, 1,189장이다. 절 번호는 역본별 표기와 업로드 원문의 병합 상태를 따른다. 현재 절 행 수는 개역개정 31,078, 쉬운성경 31,097, NIV 30,220, 개역한글 31,101, 현대인의성경 31,092, 새번역 31,092이다. 절 행 수가 적은 경우 원문에 절이 합쳐진 사례가 있으므로 해당 절을 임의로 채우지 않았다. 특히 NIV는 개별 절 번호가 없는 행이 많아 절별 선택 시 원문의 병합 상태를 추가 교정해야 한다.

현대인의성경 원본의 세 중복 표기는 별도 기록했다. 룻기 2장 끝의 두 번째 22절은 색인에서 23절로 등록했다. 레위기 20장과 예레미야 49장의 반복된 번호 행은 원본 사본에는 남고 절 색인에서는 중복 행만 제외했다. 공개 본문을 장·절 단위로 사용하기 전에는 본문 전체의 오탈자와 병합 절을 별도로 교정할 수 있다.
