# 발견 도감과 말씀 친구

도감 미리보기는 `bindPersonPreview`를 명시적으로 불러와 연결한다. 네 방향 버튼과 밀기 조작을 지원하고, 걷기·뛰기·헤롱헤롱·물에 빠지기를 무작위 순서로 순환한다. 랜덤 목록을 소진하기 전에 동작을 중복 선택하지 않는다. 패널이 사라지면 렌더링 루프도 종료한다.

발견 경로는 `node tools/pixel-bible/build-discovery-routes.mjs`로 재생성한다. 66권 1,189장 각각을 실제 월드 모델로 변환해 캐스트에 포함된 신원만 기록한다. 이름만 언급되거나 과거를 회상하는 인물은 월드의 출연 제외 규칙을 따른다. 발견 경로와 기존 알아가기 4단계는 별도 정보다.

말씀의 양식은 앱에 출석하면 1개, 오늘 통독 분량을 완료하면 1개, 오늘 QT를 완료하면 1개씩 지급한다. 날짜는 기존 앱의 기기 날짜를 사용하며 통독 완료는 앱의 마감 시각 계산을 따른다. 같은 날 같은 보상은 한 번만 지급한다. 잔여 양식은 이월된다. 오늘 받을 인물은 첫 선물 전까지 변경할 수 있고, 선물 후에는 그날 고정된다. 호감도와 양식은 앱 상태의 `foodBond`에 저장한다.

레벨은 1에서 시작하며 다음 레벨 비용은 현재 레벨 × 2개다. 2, 4, 6, …, 18개로 증가하고, 총 90개를 선물하면 최대 10레벨이 된다. 최고 레벨에는 양식을 소비하지 않는다. 감사·레벨별 인사·레벨업 대사는 성경 원문이 아닌 창작으로 표시한다.

검증: 도감·월드·저장 보상 관련 196개 테스트 통과. 실제 Chromium에서 캐릭터의 불투명 픽셀, 네 방향 버튼과 네 가지 모션 전환을 확인했다. 휴대폰 실기기에서는 별도 확인이 필요하다.
