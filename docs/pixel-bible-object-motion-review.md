# 오브젝트별 상호작용 검토

156종의 기본 쓰임새에 맞춰 동작을 선택한다. 준비·사용·사용·복귀 4단계를 재사용하며, 같은 계열의 몸짓을 공유한다. 모든 동작을 별도 손그림 원화로 만든 것은 아니다. 캐릭터별·본문별 전용 동작은 기본 동작보다 우선한다.

침상/자리는 수평으로 눕고 베개 쪽에 머리를 둔다. 밧줄은 쇠사슬과 구별해 그리며 감기·매듭·당기기·내리기를 사용한다. 활/화살의 여섯 변형은 모두 시위 당기기와 발사 단계를 포함한다. 겉옷은 바닥과 손에서 캐릭터 몸통 크기로 표시하고 착용 단계에는 캐릭터 의복에 반영한다. 표정은 피부 안쪽에서만 눈과 입을 바꾼다.
