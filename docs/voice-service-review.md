# 한국어 음성 후보 검토

2026-10-24 공식 문서 확인. 현재 음성 기능은 사용자 요청에 따라 버튼을 숨긴 상태로 유지한다. 이번 작업은 서비스 검토이며 앱에 새 음성 서비스를 연결하지 않는다.

| 항목 | OpenAI TTS | Azure Speech |
|---|---|---|
| 한국어 | 공식 지원 언어에 Korean 기재 | ko-KR 지원 및 한국어 음성 목록 제공 |
| 비교할 장점 | 대사 분위기를 지시하는 음성 생성 | 이름 발음·말하기 속도를 세밀하게 조절하는 SSML |
| 앱 적용 방식 | 서버에서 짧은 대사 생성 후 음성 파일 캐시 | 서버에서 짧은 대사 생성 후 음성 파일 캐시 |
| 확인이 필요한 부분 | 인명 발음, 한국어 감정 표현, 대사별 지연 | 선택 음성의 SSML·표현 지원 범위, 인명 발음 |

추천: 감정 전달을 우선하면 OpenAI부터, 인명 발음과 속도 조절을 우선하면 Azure부터 동일 문장으로 비교한다. 실제 비교 전에는 우열을 확정하지 않는다. 사용량에 따른 가격은 생성 시점의 공식 가격표에서 확인한다.

짧은 자체 작성 샘플(성경 원문 인용 아님):
1. 엘리야: “더는 걸을 힘이 없어요. 잠시 여기서 쉬어야겠어요.” — 지침·탈진, 발음과 작은 감정 변화.
2. 룻: “남은 이삭을 주워 어머니께 가져가야겠어요.” — 온화함·의지, 문장 끝 억양.
3. 나봇: “조상에게 물려받은 포도원을 넘길 수는 없습니다.” — 단호함, 지나치게 화난 연기인지 확인.
4. “여호사밧, 아하시야, 엘르아살.” — 인명 오독 여부.

선정 기준: 각 문장 인명·받침 오독 0건, 불필요한 비명·웃음·숨소리 없음, 1~2문장 안에서 감정 구분, 음량 일관성. 동일 설정 3회 결과의 길이·발음 변동도 비교한다. iOS Safari와 Android에서 사용자 터치 이후 오디오 재생을 검증하고, 동시에 한 음성만 재생한다.

실행 제한: 현재 환경에 OpenAI/Azure 음성 API 인증 정보가 없고 연결된 음성 전용 플러그인·스킬도 없어, 유료 생성 요청·음질 청취·실측 비용 비교는 수행하지 않았다. API 키를 프런트엔드에 저장하지 않는다. 서비스 연결과 실제 음성 생성은 후속 음성 기능 결정 때 진행한다.
