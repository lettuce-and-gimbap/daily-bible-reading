# 절별 픽셀 애니메이션 제작 기록

2026-10-25. 앱 버전은 10.7.0을 유지한다. **신약 전 구절 제작은 아직 완료되지 않았다.**

## 완료/미완료의 기준

기존 1,018개 사건·가르침 장면과 절별 제작은 별도 집계한다. 기존 장면에 절 번호를 붙인 것만으로 개별 제작 완료로 계산하지 않는다. `verse-events/progress.json`은 신약의 개역개정 절 번호 기준 7,957절 가운데 직접 작성한 273절, 미작성 7,684절을 기록한다. 쉬운성경 계 12:18 같은 역본별 별도 번호는 추가 대응 대상이다.

현재 직접 작성 범위는 마태복음 1–9장이다. 절마다 새로 쓴 짧은 뜻풀이, 동작 순서, 배우, 중심 대상, 결과 효과 또는 상징 연출을 지정했다. 물리 동작과 기존 픽셀 도안은 재사용한다. 273개의 완전히 새로운 도트 스프라이트 시트를 그린 작업은 아니다.

족보는 이름과 관계를 이어 그리며, 마 1:16에서는 혼인과 탄생의 연결을 구분한다. 비유·가르침은 실제로 일어난 인물 행동으로 꾸미지 않고 상징 연출이라고 표시한다. 산상수훈의 집·등불·문·나무·포도주 부대 등의 대상은 순차적으로 결과를 보여 준다. 일부 추상 개념은 연결·비교 도식으로 나타낸다.

## 동작 작성

- 요셉의 망설임, 꿈속 지시와 잠에서 깨어 순종하는 행동을 구별했다.
- 박사들의 이동·질문·별을 보고 기뻐함·경배·피하는 길을 나눴다. 본문에 없는 박사의 인원은 정하지 않는다.
- 요한의 설교, 세례 받는 이, 세례를 주저하는 요한, 물에서 올라오는 예수를 구별했다. 성령을 인간 NPC로 그리지 않는다.
- 돌을 떡으로 만들라는 유혹에서는 실제로 돌을 떡으로 바꾸지 않는다.
- 그물 던지기·수선·그물을 놓고 따르기는 서로 다른 순서로 작성했다.
- 백부장의 종은 다른 방으로 구분해 보여 주고 예수가 그 방에서 직접 손을 대는 것으로 표현하지 않는다.
- 나병환자에게 손 대기, 장모가 일어나 섬김, 풍랑 속 잠과 제자들의 깨움, 바다가 잠잠해지는 결과를 나눴다.
- 소녀의 손을 잡아 일으키기, 뒤에서 옷자락을 만지는 여인, 두 맹인과 말하게 된 사람을 각각 해당 절에 맞췄다. 본문에 두 사람이라고 명시된 집단은 두 원래 픽셀 인물로 표시한다.
- 새로 확인한 익명의 인물은 역할 이름과 출처만 추가한다. 원문 자체는 내보내지 않는다.

검증 결과: 단위 테스트 140개 통과. 작성한 273절과 기존 구약 715개·신약 1,018개 장면의 Chromium 렌더링 예외는 0건이다. 실제 월드의 절 선택·정지·닫기와 기존 다중 설명 페이지의 캔버스 유지 검사도 통과했다.

다음 미작성 구간은 마태복음 10장 1절부터다.

## 실제 사용

사건을 사용자가 연 뒤 재생 범위에서 `전체 장면` 또는 작성된 절을 선택한다. 현재 통독/QT의 선택 절과 사건 범위에 해당하는 절만 목록에 나온다. 아직 작성하지 않은 절은 선택지로 생성하지 않는다.

절 선택 후에는 자동으로 다음 절을 틀거나 원래 사건을 닫지 않는다. 이전/다음으로 옮기고 직접 닫는다. 새 절을 고를 때 이전 캔버스의 재생을 해제하며, 일시정지 중 절을 바꾸어도 정지 상태를 유지한다. 설명 페이지를 넘길 때 기존 플레이어를 유지한다. 모바일에서 닫기/정지 버튼이 가려지지 않도록 하단 동작 버튼을 고정했다.

## 검수와 한계

두 비공개 역본을 대조하고 해당 장의 업로드 주석을 보조로 참고했다. 원문·DB·원문 해시는 저장소 밖에 보관한다. 공개 데이터에는 직접 작성한 짧은 설명과 구절 번호, 연출 지시만 들어간다.

브라우저 검수는 모든 작성된 절을 7개 시점, 시작/동작/종료/대화 확대/동작 줄이기 모드에서 그려 예외와 좌표를 확인한다. 대표 장면은 스크린샷으로 수동 확인한다. 전체 프레임을 사람이 연속 시청했다는 뜻은 아니다. Chromium 가로 모바일 화면 검사이며 실제 iPhone/Android 실기기 검사는 아니다.

`review.json`의 검수 수와 해시를 작성 수와 구별한다. 나머지 신약 7,684절과 역본별 번호 차이의 개별 작성·검수는 미완료다. 구약 개별 절 제작도 이 집계에 포함되지 않는다.
