# 절별 픽셀 애니메이션 제작 기록

2026-10-25. 앱 버전은 10.7.0을 유지한다. **신약 전 구절 제작은 아직 완료되지 않았다.**

## 완료/미완료의 기준

기존 1,018개 사건·가르침 장면과 절별 제작은 별도 집계한다. 기존 장면에 절 번호를 붙인 것만으로 개별 제작 완료로 계산하지 않는다. `verse-events/progress.json`은 신약의 개역개정 절 번호 기준 7,957절 가운데 직접 작성한 1,573개 절 번호, 미작성 6,384개 절 번호를 기록한다. 쉬운성경 계 12:18 같은 역본별 별도 번호는 추가 대응 대상이다.

이 가운데 마 17:21, 18:11, 23:14와 막 9:44, 9:46, 11:26은 두 역본의 `(없음)` 표기를 설명하는 안내 6개다. 실제 내용 연출은 1,567개이며, 안내를 새로운 사건 제작으로 세지 않는다.

현재 직접 작성 범위는 마태복음 1–28장과 마가복음 1–12장이다. 절마다 새로 쓴 짧은 뜻풀이, 동작 순서, 배우, 중심 대상, 결과 효과 또는 상징 연출을 지정했다. 물리 동작과 기존 픽셀 도안은 재사용한다. 1,573개의 완전히 새로운 도트 스프라이트 시트를 그린 작업은 아니다.

족보는 이름과 관계를 이어 그리며, 마 1:16에서는 혼인과 탄생의 연결을 구분한다. 비유·가르침은 실제로 일어난 인물 행동으로 꾸미지 않고 상징 연출이라고 표시한다. 산상수훈의 집·등불·문·나무·포도주 부대 등의 대상은 순차적으로 결과를 보여 준다. 일부 추상 개념은 연결·비교 도식으로 나타낸다.

## 동작 작성

- 요셉의 망설임, 꿈속 지시와 잠에서 깨어 순종하는 행동을 구별했다.
- 박사들의 이동·질문·별을 보고 기뻐함·경배·피하는 길을 나눴다. 본문에 없는 박사의 인원은 정하지 않는다.
- 요한의 설교, 세례 받는 이, 세례를 주저하는 요한, 물에서 올라오는 예수를 구별했다. 성령을 인간 NPC로 그리지 않는다.
- 돌을 떡으로 만들라는 유혹에서는 실제로 돌을 떡으로 바꾸지 않는다.
- 그물 던지기·수선·그물을 놓고 따르기는 서로 다른 순서로 작성했다.
- 백부장의 종은 다른 방으로 구분해 보여 주고 예수가 그 방에서 직접 손을 대는 것으로 표현하지 않는다.
- 나병환자에게 손 대기, 장모가 일어나 섬김, 풍랑 속 잠과 제자들의 깨움, 바다가 잠잠해지는 결과를 나눴다.
- 소녀의 손을 잡아 일으키기, 뒤에서 옷자락을 만지는 여인, 두 맹인과 말하게 된 사람을 각각 해당 절에 맞췄다. 본문에 두 사람이라고 명시된 집단은 두 원래 픽셀 인물로 표시한다.
- 새로 확인한 익명의 인물은 역할 이름과 출처만 추가한다. 원문 자체는 내보내지 않는다.

작성 절 수와 실제 화면 검수 수는 따로 기록한다. 두 역본의 본문과 장별 주석을 대조한 뒤 절별 공개용 짧은 설명과 동작을 작성한다. 절별 원문은 저장소 밖의 로컬 비공개 DB에서만 읽는다.

다음 미작성 구간은 마가복음 13장 1절부터다.

## 이번 확장

- 물 위를 걷기·빠짐·붙잡힘·배에 오름은 인물별 좌표 경로로 분리했다. 나귀와 탄 사람은 같은 경로로 움직이고 성전의 상은 회전한다.
- 씨와 토양·누룩·진주·그물·열 처녀·달란트·양과 염소·빈 무덤에 별도 상징 그림을 추가했다. 비유 속 인물은 실제 사건과 구분하되 동작을 수행한다.
- 마 21:29–31은 업로드한 두 역본에서 두 아들 순서가 달라 나란히 비교하고, 아들의 번호를 공통 정답으로 단정하지 않는다.
- 물고기 동전은 지시와 실제 실행을 구별한다. 경비병의 도난 주장은 거짓 주장으로 설명하고 실제 도난 영상으로 만들지 않는다.
- 부활 뒤 성도들의 등장 시점, 익명 인물, 장 끝에 기록되지 않은 승천을 구분한다. 폭력·자살은 구체적 재현을 피하고 짧은 설명으로 표현한다.

마가복음은 마태복음 데이터를 복제하지 않고 1–12장의 502절을 직접 작성했다. 4장의 배와 풍랑, 5장의 쇠사슬·돼지 떼·두 치유 사건, 6장의 파송·헤롯의 잔치·떡 나눔, 7장의 정결 논쟁·수로보니게 여인의 딸·귀먹은 사람, 8–10장의 두 번째 떡 나눔·벳새다의 두 단계 치유·베드로의 고백·변화산·귀신 들린 아이·어린아이 축복·부자와 바디매오, 11–12장의 예루살렘 입성·성전 정화·무화과나무 표징·포도원 농부 비유·세금과 부활 논쟁·과부의 두 렙돈을 각 절의 동작과 도식으로 구성했다. 역본의 장절 배치가 다른 곳은 차이를 표시하고 실제 결락 안내와 구분했다.

## 실제 사용

사건을 사용자가 연 뒤 재생 범위에서 `전체 장면` 또는 작성된 절을 선택한다. 현재 통독/QT의 선택 절과 사건 범위에 해당하는 절만 목록에 나온다. 아직 작성하지 않은 절은 선택지로 생성하지 않는다.

절 선택 후에는 자동으로 다음 절을 틀거나 원래 사건을 닫지 않는다. 이전/다음으로 옮기고 직접 닫는다. 새 절을 고를 때 이전 캔버스의 재생을 해제하며, 일시정지 중 절을 바꾸어도 정지 상태를 유지한다. 설명 페이지를 넘길 때 기존 플레이어를 유지한다. 모바일에서 닫기/정지 버튼이 가려지지 않도록 하단 동작 버튼을 고정했다.

## 검수와 한계

두 비공개 역본을 대조하고 해당 장의 업로드 주석을 보조로 참고했다. 원문·DB·원문 해시는 저장소 밖에 보관한다. 공개 데이터에는 직접 작성한 짧은 설명과 구절 번호, 연출 지시만 들어간다.

브라우저 검수는 모든 작성된 절을 7개 시점, 시작/동작/종료/대화 확대/동작 줄이기 모드에서 그려 예외와 좌표를 확인한다. 대표 장면은 스크린샷으로 수동 확인한다. 전체 프레임을 사람이 연속 시청했다는 뜻은 아니다. Chromium 가로 모바일 화면 검사이며 실제 iPhone/Android 실기기 검사는 아니다.

`review.json`의 검수 수와 해시를 작성 수와 구별한다. 나머지 신약 6,384절과 역본별 번호 차이의 개별 작성·검수는 미완료다. 구약 개별 절 제작도 이 집계에 포함되지 않는다.
