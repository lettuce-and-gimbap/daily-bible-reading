# 구약 권별 순차 전수 검수

한 권을 본문 대조, 누락 사건 확인, 장면·배우·동작 교정, 테스트와 화면 검수까지 진행한 뒤 다음 권으로 이동한다. 절별 대조와 화면 검수는 별도 단계로 기록하며, 테스트 통과만으로 권 완료를 선언하지 않는다. 절별 누계의 기준 자료는 [ot-verse-review-progress.json](./ot-verse-review-progress.json)이다.

- 완료: 2/39권 — 창세기 1,533/1,533절, 출애굽기 1,213/1,213절.
- 이번 권: 출애굽기 1–40장 전 절을 두 기준 역본과 대조했다. 누락·부정확 장면을 보완해 전체 100개 장면으로 정리했다. 기존 장면 16개를 교정하고 30개 장면을 추가했다. 법 조항과 폭력 사건은 비그래픽한 설명·상징 동작으로 구성했다.
- 이번 작업 검수량: 1,213절. 구약 누계 2,746/23,145절, 남은 절 20,399절.
- 화면 검수: 출애굽기 100개 장면 브라우저 렌더 오류 0건. 출처 범위 검사에서 등록 장면의 본문 참조가 모두 확인됐고, 비공개 원문은 정적 산출물로 내보내지 않았다.
- 검증: 전체 테스트 314개 통과. 구약 출처 범위 검사 1,475건, 절별 원문 행 검사 993단위·260장 통과.
- 다음 권: 레위기. 출애굽기 작업 결과는 권별 커밋으로 기록한다.

업로드된 두 역본은 사실 확인에, 비공개 주석은 해석 보조에 사용한다. 장면의 몸짓·시간·화면 배치는 연출이며 원문에 없는 세부를 사실처럼 단정하지 않는다. 원문이나 비공개 DB는 이 문서에 넣지 않는다.
