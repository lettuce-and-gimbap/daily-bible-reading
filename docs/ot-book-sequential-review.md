# 구약 권별 순차 전수 검수

한 권을 본문 대조, 누락 사건 확인, 장면·배우·동작 교정, 테스트와 화면 검수까지 진행한 뒤 다음 권으로 이동한다. 절별 대조와 화면 검수는 별도 단계로 기록하며, 테스트 통과만으로 권 완료를 선언하지 않는다. 절별 누계의 기준 자료는 [ot-verse-review-progress.json](./ot-verse-review-progress.json)이다.

- 완료: 3/39권 — 창세기 1,533/1,533절, 출애굽기 1,213/1,213절, 레위기 859/859절.
- 이번 권: 레위기 1–27장 전 절을 두 기준 역본과 대조했다. 두 역본의 장별 절 번호가 모두 일치했고, 장면이 비어 있거나 부분만 있던 본문을 보완해 총 94개 장면으로 구성했다. 기존 16개를 확인하고 78개를 추가했다.
- 이번 작업 검수량: 859절. 구약 누계 3,605/23,145절, 남은 절 19,540절.
- 보강 범위: 제사 규례뿐 아니라 음식·정결 규정, 제사장 위임, 속죄일, 절기, 이삭을 남기는 규례, 희년, 공동체 윤리, 서원 규정을 구간별로 나눴다. 질병·성 규정·형벌은 직접 재현하지 않고 상징적 설명 장면으로 처리했다.
- 화면 검수: 레위기 94개 장면 브라우저 렌더 오류 0건. 제사장 씻김이 물웅덩이에 들어간 것처럼 보이던 배치를 대야와 회막 뜰로 교정했다. 출처 범위 검사에서 등록 장면 1,553건의 본문 참조가 확인됐으며, 비공개 원문은 정적 산출물로 내보내지 않았다.
- 검증: 전체 테스트 315개 통과.
- 다음 권: 민수기. 권별 커밋 후 순서대로 진행한다.

업로드된 두 역본은 사실 확인에, 비공개 주석은 해석 보조에 사용한다. 장면의 몸짓·시간·화면 배치는 연출이며 원문에 없는 세부를 사실처럼 단정하지 않는다. 원문이나 비공개 DB는 이 문서에 넣지 않는다.
