# 구약 권별 순차 전수 검수

한 권을 두 기준 역본 본문 대조, 누락 사건 보강, 장면·배우·동작 교정, 테스트와 화면 검수까지 마친 뒤 다음 권으로 이동한다. 절별 대조와 화면 검수는 별도 단계로 기록하며, 테스트 통과만으로 권 완료를 선언하지 않는다. 절별 누계의 기준 자료는 [ot-verse-review-progress.json](./ot-verse-review-progress.json)이다.

- 완료: 4/39권 — 창세기 1,533절, 출애굽기 1,213절, 레위기 859절, 민수기 1,288절.
- 이번 권: 민수기 1–36장 1,288절을 두 기준 역본과 대조했다. 누락 범위에 78개 장면을 추가해 기존 46개에서 총 124개로 보강했다.
- 이번 작업 검수량: 1,288절. 구약 누계 4,893/23,145절, 남은 절 18,252절.
- 보강 범위: 진영과 인구 계수, 레위인의 임무, 광야 이동과 불평, 정탐과 반역, 놋뱀, 발람·발락, 절기, 서원, 요단 동편 정착, 땅 분배와 도피성을 구간별로 나눴다. 전투·죽음·형벌은 직접 묘사하지 않고 상징적으로 표현했다.
- 화면 검수: 민수기 124개 장면 렌더 오류 0건. 출처 범위 검사에서 등록 장면 1,631건의 본문 참조를 확인했고, 비공개 원문은 정적 산출물로 내보내지 않았다.
- 검증: 전체 테스트 316개 통과. 구약 출처 범위 검사 1,631건, 절별 원문 행 검사 993단위·260장 통과.
- 다음 권: 신명기. 각 권 검수와 커밋을 순서대로 진행한다.

업로드된 두 역본은 사실 확인에, 비공개 주석은 해석 보조에 사용한다. 장면의 몸짓·시간·화면 배치는 연출이며 원문에 없는 세부를 사실처럼 단정하지 않는다. 원문이나 비공개 DB는 이 문서에 넣지 않는다.
