## 자료 이용 기준

- 박물관 공개 컬렉션은 개별 페이지의 CC0/Open Access 표시를 확인한 자료에 한해 사용한다. 사이트 전체 자료가 일괄 공개 라이선스라는 뜻은 아니다.
- itch.io, OpenGameArt, Sketchfab 검색 결과는 제작자별 권리가 다르다. 검색 결과 전체를 자유 이용 에셋으로 취급하지 않는다.
- 픽셀 아트 튜토리얼과 갤러리는 기법을 공부하는 출처다. 완성된 그림이나 스프라이트를 복사해 앱에 넣는 출처로 사용하지 않는다.
- 성경 시대 의복은 성경 본문, 고고학 자료, 후대 미술을 분리해서 검토한다. 근거가 불충분하면 단정적 고증 대신 설계상 선택으로 기록한다.
