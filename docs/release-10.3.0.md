# 10.3.0 — 부분 형광펜·인물 외형·KST 색감

## 부분 형광펜

통독/QT의 역본별 본문 span에 실제 글자 오프셋을 저장한다. 같은 단어가 반복되어도 선택 위치를 구분하고, 두 역본의 오프셋을 섞지 않는다. 선택/복사 후 작은 도구를 표시하며 모달을 띄우지 않는다. 선택 부분만 지울 때에는 기존 표시의 양옆을 보존한다. 원문이 달라지면 지문(hash)이 다른 과거 오프셋을 잘못 적용하지 않는다. 원문 사본을 따로 저장하지 않는다.

기존 절 전체 색칠은 범위 표시로 이전한다. 구절 메모는 기존 키를 유지한다. 사용자 표시는 이전과 같이 이 브라우저 localStorage에 저장되며 계정 동기화에는 포함되지 않는다. 색상은 관리 탭의 색상 선택기·HEX·RGB로 변경한다. EyeDropper는 해당 API를 지원하는 브라우저에서만 제공하고 비지원 브라우저에는 숨긴다. 색상 선택은 이후 표시부터 적용하며 이미 칠한 색은 유지한다. 어두운 색에서는 글자색을 밝게 바꾼다.

## 인물 외형 조사

전권 요약과 관계 끝점·생물 목록을 `chapterPeople`과 같은 경로로 순회했다. 2,965개 신원/미해결/집단 항목을 `data/pixel-bible/physical-audit.json`에 기록한다. 이것은 성경의 모든 고유 인물 수가 아니다. 같은 이름의 문맥별 신원과 집단이 포함된다. 원문 키워드 검색은 비공개 DB의 외형 후보 617절을 찾는 보조 과정이며, 이름 동시 등장이나 '아름다운 땅' 같은 오탐을 외형 사실로 자동 적용하지 않았다.

확인된 특징은 27개 문맥 규칙으로 보강했고, 현재 목록에서 규칙이 적용되는 신원 항목은 32개다. 기존 골리앗·삭개오·사울·아낙 체격 규칙 및 100종 고유 의복 DB와 함께 사용한다. 특징이 확인되지 않은 인물은 이름별 창작 차이를 유지한다. 모든 인물에게 기록된 외모가 있다고 주장하거나 임의의 민족 외모를 역사적 사실로 넣지 않는다.

두 비공개 역본에서 직접 대조한 주요 범위:
- 창세기 12:11, 24:16, 25:25, 27:1, 11, 29:17, 39:6
- 사무엘상 4:15–18, 16:12(이전 조사), 25:3
- 사무엘하 9:13, 13:1, 14:25–27, 19:32
- 열왕기상 1:3–6, 14:4; 열왕기하 2:23(이전 조사)
- 사사기 3:15–17, 16:13–17; 에스더 1:11, 2:7
- 다니엘 1:4–6, 4:33; 누가복음 2:36–37
- 역대상 20:6; 사무엘하 21:20(거인 검색에서 확인)

호크마 추가 참고: 사무엘하 14:25–27, 창세기 27:11–13, 누가복음 2:36–38, 사무엘하 19:31–39. 안나의 나이 표현은 주석의 다른 계산 가능성을 단정하지 않고 '고령'으로만 표시한다. 레아의 눈은 번역 차이를 이유로 질환/추함으로 확정하지 않는다. 용모가 아름답다는 기록을 특정 피부색으로 표현하지 않는다. 미리암·나아만·게하시·웃시야 등의 피부 변화도 본문을 대조했으나 치유 전후를 구분할 수 없는 장 단위 화면에 병을 영구 표시하지 않는다. 느부갓네살의 사건 외형 역시 정확한 절 시점이 있을 때만 적용한다.

## KST 색감

클라이언트 시간대와 무관하게 UTC+9로 계산한다. 고정 구간은 새벽 05–08시, 낮 08–18시, 저녁 18–20시, 밤 20–05시다. 실제 일출 시각이나 계절별 천문 계산은 아니다. 월드의 지형·풍경에 같은 색조를 적용하고 관계선과 DOM 말풍선은 가독성을 유지한다. 앱 진입 화면에 기존 십자가 로고와 해/달 및 시간대별 배경색을 표시한다. 운영체제의 고정 PWA 시작 이미지 자체를 동적으로 변경하는 것은 아니다. 진입 화면은 1.1초 후 자동으로 사라지며 화면 입력을 막지 않는다.

외부 팔레트 참고:
- https://lospec.com/palette-list/apollo — 차분한 청색·청록색과 따뜻한 모래·장밋빛 계열
- https://lospec.com/palette-list/sweetie-16 — 남색 그림자와 따뜻한 노랑·주황의 대비

공식 JSON 색상표를 확인하고 자체 혼합 색감으로 구성했다. 이미지를 복제하거나 외부 자료를 모델에 영구 학습한 작업이 아니다. `tools/pixel-bible/daylight-review.html`에서 네 구간을 나란히 확인할 수 있다.

## 검증

- Node 테스트 88개 통과: KST 경계, 인물 신원·연령·시점, 기존 기능 포함.
- Chromium의 데스크톱/iPhone 13/Pixel 7 화면 설정으로 부분 선택·반복 단어·부분 지우기·역본 간 분리·재표시·색 저장 검사 통과.
- 실제 관리 탭에서 RGB 변환과 잘못된 RGB 거부, 설정 저장, 10.3.0 버전 확인. 페이지 오류 0건.
- 인물 100명 사방향·걷기·표정 조합 12,800회 렌더링: 빈 출력·경계 잘림 0건. 새 특징 비교 도안과 KST 네 구간 비교 이미지 확인.
- 실제 iOS/Android 기기에서 OS의 복사 선택 핸들과 EyeDropper를 직접 조작한 검사는 포함하지 않는다.
