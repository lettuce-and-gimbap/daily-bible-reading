# 구약 픽셀 사건 애니메이션 작업·검수 기록

작업일: 2026-10-25 (KST)

## 범위

현재 앱에 등록된 구약 39권 715개 장면을 대상으로 한다. 구약에서 가능한 모든 사건을 망라했다는 의미는 아니다. 기존 711개에 오바댜·나훔·하박국·스바냐 장면을 하나씩 추가했다. 별도로 기존 정적 조합 77개도 브라우저 렌더링 검사를 통과했다.

인물과 오브젝트는 기존 픽셀 도안을 사용한다. 새로 고해상도 인물 원화를 그리는 작업은 포함하지 않는다. 사건별로 행동 주체·대상·소품·배경·감정·6단계 행동 순서를 지정했으며, 같은 물리 동작의 도트 골격은 재사용한다. 시·비유·예언은 상징 설명, 제사 규례는 동작 예시로 표시하여 실제 발생 사건과 구분한다.

## 적용 구조

- 데이터: `data/pixel-bible/events/<권>.json`의 `animation` 필드.
- 권별 편집: `tools/pixel-bible/animation/book-plans.json`, `corrections.json`.
- 제작: `node tools/pixel-bible/animation/build.mjs`. 입력이 바뀌면 해당 권의 브라우저 검수 상태를 다시 미검수로 표시한다.
- 모션: `event-animation/timeline.js`가 배우마다 팔·손·몸·걷기·표정을 계산한다. `rig.js`는 원본 캐릭터의 팔을 소스 도트로 그린다.
- 연출: `stage.js`와 `effects.js`, 실제 재생: `pixel-event.js`.
- 이전 사람 비율 연출은 보관만 하고 월드 실행 경로에서 불러오지 않는다.

## 재생 흐름

1. 일반 독백·대화·일상 사용은 월드의 기존 작은 동작으로 진행한다.
2. 특수 조합은 필요한 인물·중심 물건·보조 물건과 거리를 확인한다. 인물이 떨어져 있으면 먼저 조합 주변으로 이동시킨다.
3. `사건 보기` 안내를 사용자가 눌러야 전용 픽셀 연출을 시작한다. 발견 안내를 닫으면 같은 입장 중 자동으로 반복 안내하지 않는다.
4. 재생 중 월드 이동과 다른 발화를 멈춘다. 일시정지·계속·다음 설명·닫기를 제공한다.
5. 다음 설명은 같은 캔버스를 유지한다. 애니메이션은 한 번 진행한 뒤 최종 자세를 유지한다. 설명이 넘어가도 동작을 처음부터 반복하지 않는다.
6. 종료하면 이전 시점으로 돌아가 자유 이동을 재개한다. 일반 오브젝트는 이동 예약부터 1인 사용을 적용하고, 명시된 사건의 다인 조합은 예외다.

## 검사 범위와 한계

- 비공개 개역개정·쉬운성경 DB에서 715개 참조 범위가 조회됨을 확인하고 주석 장 연결을 검사했다. 이는 모든 구절에 대한 새로운 수동 신학 검토를 뜻하지 않는다. 원문·DB·비공개 조회 해시는 공개 저장소에 포함하지 않았다.
- 단위 테스트 122개 통과. 모든 사건의 행동·배우·구절 연결, 도트 좌표, 단계 전환, 최종 상태 고정, 상징 모드를 검사했다.
- Chromium에서 39권 715개 장면을 7개 시점으로 렌더링하고 시작·행동·결과·대화 확대 모드를 검사했다. 렌더링 예외 0건. 대표 프레임은 권별 스크린샷으로 수동 확인했다. 모든 프레임을 사람이 하나씩 시청했다는 의미는 아니다.
- 실제 월드에서 선택 재생, 정지 중 프레임 고정, 설명 전환 시 캔버스 유지, 닫은 뒤 화면 제거와 자동 재시작 방지를 확인했다.
- 데스크톱 1280×720 및 가로 모바일 844×390에서 닫기 버튼이 다른 UI에 가려지지 않는지 실제 히트 테스트로 확인했다. 실제 iPhone/Android 기기에서 실행한 검사는 아니다.

## 수정한 대표 문제

- 야곱의 슬픔 장면에 요셉·보디발이 들어 있던 배우 연결, 베냐민의 은잔 장면의 겉옷 연결을 수정했다.
- 예후에게 기름을 붓는 인물, 화살을 쏘는 인물과 이를 돕는 인물을 분리했다.
- 노아의 물 위 배치 대신 방주를 배치하고, 치료받는 사람은 침상에서 쉬게 했다.
- 가마·턱뼈의 빠진 도안을 추가했다. 칼·못 등이 잘못 연결된 중심 물건을 교정했다.
- 물건 내려놓기의 순간 이동, 시위를 놓기 전 화살이 날아가는 순서, 대화 확대의 얼굴 잘림을 수정했다.
- 닫아도 CSS 때문에 설명판이 보이던 오류, 사건 제어 버튼 위에 월드 카메라 버튼이 겹치던 오류를 수정했다.

## 재현 방법

저장소 루트에서 정적 서버와 별도의 Chromium 테스트 프로필을 준비한다. Python 브라우저 검수 도구는 `websockets` 모듈이 필요하다.

```sh
python -m http.server 8765
chromium --headless --no-sandbox --remote-debugging-port=9222 --user-data-dir=/tmp/pixel-animation-review-profile about:blank
python tools/pixel-bible/animation/browser-audit.py
python tools/pixel-bible/animation/world-smoke.py
node --test tests/*.test.mjs
```

`browser-audit.py --books gen`처럼 바뀐 권만 다시 검사할 수 있다. 검수 도구는 별도의 로컬 테스트 탭을 열며, 실제 서비스 계정에 접속하지 않는다. 정적 검수 페이지는 `tools/pixel-bible/animation-review.html`이다.
