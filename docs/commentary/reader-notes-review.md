# 통독·QT 주석 확장 검토 (2026-10-24)

## 적용 범위

기존 용어 6개에서 71개로 확장했다. 제사·성막·절기·당시 집단·언약·구원·성례·종말 관련 용어를 본문에서 누르거나 검색할 수 있다. 어려운 본문 해설은 열왕기상 19:4–8, 21:1–13, 로마서 3:23–26, 에베소서 2:8–10, 야고보서 2:18–24의 5개 범위부터 추가했다. 66권 전체 구절의 주석을 완성한 것이 아니다. 등록된 용어는 통독·QT 어느 본문에서든 연결되며, 범위 해설은 해당 절에만 나온다.

짧은 뜻 → 배경 → 오해 주의 → 선택해서 펼치는 개혁주의 관점 순서다. 단어의 의미와 교리적 해석을 구분한다. 장로교의 세례·성찬 이해, 칭의와 성화, 은혜와 선행, 선택과 사람의 책임을 함께 설명한다. 원뜻이 불확실한 셀라·우림과 둠밈·아사셀 등은 확정적인 재현이나 어원을 단정하지 않는다. 일반적인 입양과 구원의 양자 됨, 시편의 인자하심과 복음서의 인자, 절기 마지막 날과 말세를 섞지 않도록 제한했다.

앱 작성 설명이며 **교단 발행 공식 주석이 아니다**. 개혁주의 안에서도 합의되지 않은 세부 해석을 합동측의 단일 확정 입장으로 제시하지 않는다. 신규 개별 종말론 해설은 이번 범위에 넣지 않았다.

## 자료 확인

- 제공받은 두 역본: 용어 항목의 참조 118개 범위를 로컬에서 조회해 양쪽 역본의 참조 존재 여부를 확인했다. 자동 참조 확인과 모든 문장의 신학적 정밀 검토를 동일시하지 않는다.
- 추가 대조: 레위기 16:20–22, 로마서 3:23–26, 에베소서 2:8–10, 요한복음 3:3–8, 야고보서 2:18–24, 열왕기상 19:4–8, 21:1–13을 두 역본과 업로드 호크마 참고 정리의 해당 범위로 확인했다.
- 보조 자료의 장별 도입·발췌 확인: 레위기 25장, 출애굽기 28장, 로마서 8장, 에베소서 1장, 요한복음 6장, 고린도전서 11장, 로마서 9장, 야고보서 2장, 요한계시록 20장, 열왕기상 19·21장. 장 전체를 정밀 교감했다고 주장하지 않는다. 업로드 자료 자체가 참고 정리이며 출판 원문과 동일하다고 가정하지 않는다.
- [예장합동 공식 교단 소개](https://www.gapck.org/history?cat=ideology): 공개 사이트의 교단 소개 문구에서 칼빈주의·개혁파 신학 및 웨스트민스터 신앙고백과 대소요리문답을 교리적 표준으로 삼는다는 진술을 확인했다.
- [OPC 공개 웨스트민스터 신앙고백](https://www.opc.org/wcf.html): 특히 3장, 10–11장, 13–14장, 16–17장, 27–29장의 선택·부르심·칭의·성화·선행·견인·성례 관련 진술을 대조했다. OPC는 이 신앙고백의 공개 열람 출처이며 합동측 공식 번역본이라는 뜻이 아니다.
- CRC 도르트 신조 페이지는 접근이 차단되어 본문 확인 자료로 쓰지 않았다. 외부 검색·열람에는 공개 자료만 사용했다.

## 공개 및 저장

신규 공개 데이터에는 직접 작성한 짧은 설명, 성경 참조, 공개 교리 자료 링크만 있다. 제공 원문·주석 사본·DB·업로드 목록을 복사하거나 외부로 전송하지 않았다. 관련 구절 열람은 기존 앱의 공개 본문 조회 경로를 사용하며 비공개 DB를 브라우저에 연결하지 않는다. 한 번에 최대 6절을 보여 주고 장 전체를 덤프하지 않는다.

하이라이트는 기존 방식대로 기기의 위치·색·메모만 저장한다. 용어 일부에 형광펜을 칠해도 용어 링크가 쪼개지지 않게 보완했다. 통독 하단 하이라이트 버튼 위치와 QT 기존 사용 방식은 유지한다.

## 검증

- Node 테스트 96개 통과: 주석 ID·참조·권 범위·교리 장 번호·문맥 제한·스크립트 순서·비공개 자료 경로 배제 포함.
- Chromium 모바일 터치 환경: 용어 검색/팝업, 본문 해설, 구절 조회(범위 제한·HTML 안전 처리), 부분 형광펜과 용어 링크 병용 확인.
- 기존 하단 형광펜 선택·메모 저장/조회·절 선택·지우기 회귀 확인.
- 실제 iOS Safari 기기 검증은 수행하지 않았다.

앱 버전은 10.3.0을 유지한다.
