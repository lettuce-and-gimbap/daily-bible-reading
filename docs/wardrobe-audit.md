# 의복 검토 완료 기록 — 2026-10-24

고유 외형 100개 각각의 대표 근거 구절을 비공개 두 역본에서 조회했다. 아래의 확인은 대표 구절의 인물·역할 또는 복식 사실을 확인한 것이며, 해당 인물의 모든 생애 시점 복장을 고증했다는 뜻이 아니다. 복장이 기록되지 않은 인물의 재단·색·주름은 창작이다. 외형의 원래 출처와 창작 설명을 유지한다.

추가 대조: 출애굽기 28:15–21, 에스더 8:15, 다니엘 5:29 및 호크마의 해당 범위. 보석은 3열 × 4행으로 단순화했다. 실제 보석 색과 현대 광물 분류를 확정하지 않는다. 모르드개의 속옷·겉옷 색과 다니엘의 금 사슬을 보강했다. 아론의 의복을 계승한 엘르아살도 흉패를 표시한다.

이집트·페르시아 의복은 개별 인물이 실제 착용했다는 주장 대신 시대 복식에서 착안한 디자인으로만 사용한다. 본문에 없는 색·재단을 역사적 사실로 표시하지 않는다.

검증: Chromium에서 100명 × 사방향 × 걷기 4프레임 × 표정 5종 = 8,000회 렌더링. 빈 출력·바깥 캔버스 경계 잘림 0건. 20명씩 5장의 사방향 비교 이미지를 직접 확인했다. 복식 장식의 몸통 영역 제한과 후면 흉패 비노출은 별도 검사한다. 실제 기기 검증은 이 기록에 포함하지 않는다.
