# 다니엘·말라기 도감 검토

검토 범위는 다니엘부터 말라기까지 앱에 등장하는 첫 등장 도감 신원과 일부 기존 신원의 해당 책 재등장이다. 항목의 reviewedRefs 및 note 범위만 확인했으며 전체 도감 검증 완료를 뜻하지 않는다.

- 새 첫 등장 항목 83개: 다니엘 24개, 호세아 4개, 요엘 1개, 아모스 14개, 나훔 1개, 하박국 6개, 스바냐 9개, 학개 1개, 스가랴 18개, 말라기 7개. 오바댜·요나·미가에는 기존 검토 신원 외 새 첫 등장 항목이 없었다.
- 말라기까지 검토 누계: 1,455 / 도감 신원 1,929. 다음 첫 등장 신원은 요나 1장에 있다.
- 인용 절이 개역개정 4판과 쉬운성경 Markdown의 해당 장에 있는지 확인했다. 이 환경에는 비공개 성경 SQLite와 호크마 SQLite가 없어 DB 기반 대조·주석 확인은 하지 않았다. 요나서 본문 Markdown도 업로드 자료에서 누락되어 요나서 항목의 본문 대조는 미완료다.
- 다니엘서의 바벨론식 이름과 유다 이름을 연결하고, 풀무불의 넷째 인물·순찰자·바사/헬라 군주는 환상 속 묘사로 두어 정체를 임의 확정하지 않았다.
- 호세아 자녀의 이름은 표징으로 소개하고 개인의 가치 평가와 구분했다. 아모스·하박국·말라기의 불의와 억압 서술은 피해자를 비난하지 않도록 정리했다. 스가랴의 양 떼·에바 속 여인 등은 환상/상징으로 구분했다.
- PIXEL BIBLE과 통독 관계도는 공유 요약 DB(`data/summary/{code}.json`)를 사용한다. 이번 작업은 요약의 관계 끝점을 바꾸지 않았다.
