# UI 컬러 팔레트 — Quiet Chapters

참고: [도토리, UI 디자인 가이드: 쉬운 컬러 팔레트 만들기 8단계](https://brunch.co.kr/@august9/263), 2022-06-15. 소개한 HSL 명도 확장·색상환 이동·기본/보조 변형·중립색 분리를 적용했다. 참고 글의 예시 색상을 그대로 사용하지 않고 앱의 읽기·묵상·기록 용도에 맞게 구성했다.

## 색상 구성

| 역할 | 색상 | HSL | 사용 |
|---|---|---|---|
| 통독 주조색 | #2F6674 | 192° / 42% / 32% | 주요 행동, 통독 선택, 링크 |
| QT 보조색 | #87671D | 42° / 65% / 32% | QT 선택, 묵상 행동 |
| 관리 보조색 | #673C5E | 312° / 26% / 32% | 관리 선택, 관리 화면 주요 버튼 |
| 주의색 | HSL(12 50% 42%) | 12° / 50% / 42% | 삭제·주의 |
| 바탕 | #F3F6F5 | 별도 중립색 | 화면 바탕 |
| 종이 표면 | #FFFEFA | 별도 중립색 | 카드·읽기 표면 |
| 본문 | #21383D | 별도 중립색 | 일반 텍스트 |
| 보조 글자 | #596D70 | 별도 중립색 | 도움말·설명 |

메인 H192°에 +210°를 더해 QT H42°, +120°를 더해 관리 H312°, +180°를 더해 주의 H12°를 구성했다. 각 계열의 명도는 97, 93, 86, 75, 61, 45, 32, 24, 17, 11%의 10단계다. 50~200은 표면과 선택 배경, 600~800은 밝은 화면의 텍스트·버튼, 300은 어두운 화면의 강조색으로 쓴다. 주의색은 연한 주의 배경 위 텍스트 대비를 확보하기 위해 L42% 변형을 사용한다.

넓은 읽기 공간은 중립색으로 유지하고, 탭·버튼·상단 막대·카드 가장자리·선택 상태에 역할별 색을 사용한다. 성공은 녹색, 안내는 청색, 주의는 코랄로 구분한다. 색에만 의존하지 않고 기존 텍스트·체크·테두리 상태를 함께 유지한다.

## 적용과 사용

- `css/palette.css`가 기존 의미 토큰을 덮어쓴다. `--accent`, `--qt` 등 기존 사용처를 유지하며 `--admin`, `--qt-ink` 등을 추가했다.
- 통독·QT·관리 탭과 카드, 본문 선택, 형광펜 메모 편집기 및 도움말 팝업에 적용한다.
- 시스템 설정 자동 모드와 사용자가 고른 밝게/어둡게 설정을 모두 지원한다.
- 픽셀 월드의 지형·캐릭터 그림과 KST 시간 색감, 사용자가 이미 고른 형광펜 색은 이 팔레트로 덮어쓰지 않는다.
- 별도 팔레트 미리보기: `tools/ui/palette.html`. 밝기 전환과 HEX 복사가 가능하다. 앱 메뉴를 추가한 것은 아니다.
- 앱 버전은 10.3.0으로 유지한다.

## 검증

Chromium에서 실제 계산된 색을 기준으로 다음 텍스트 조합의 대비를 확인했다. 이 수치는 앱의 모든 화면이 접근성 기준을 충족한다는 인증이 아니다.

| 조합 | 밝게 | 어둡게 |
|---|---:|---:|
| 통독 버튼 글자/배경 | 6.41:1 | 9.68:1 |
| QT 버튼 글자/배경 | 5.27:1 | 10.23:1 |
| 관리 버튼 글자/배경 | 8.81:1 | 8.88:1 |
| 보조 글자/표면 | 5.41:1 | 7.64:1 |
| 주의 글자/주의 표면 | 4.92:1 | 5.86:1 |
| 성공 글자/성공 표면 | 5.39:1 | 6.89:1 |
| 안내 글자/안내 표면 | 5.38:1 | 6.48:1 |

색상표의 실제 버튼·모드 전환 버튼도 별도로 검사한다. 실제 관리 화면 로딩의 JavaScript 오류 0건을 확인했다. 색상 전환 중 글자색과 이전 배경색이 잠깐 섞이지 않게 버튼의 배경 전환 애니메이션을 제거했다.
