# 신약 픽셀 사건 애니메이션 작업·검수 기록

작업일: 2026-10-25 (KST)

## 범위

신약 27권의 현재 등록 장면 196개가 대상이다. 기존 187개에 장면이 없던 아홉 서신의 가르침 설명 장면을 하나씩 추가했다. 신약에서 가능한 모든 사건을 망라한 목록이라는 뜻은 아니다.

기존 픽셀 인물·오브젝트 도안을 유지한다. 장면마다 배우·대상·중심 물건·동작 순서·결과 효과를 지정하고, 같은 물리 행동의 도트 골격은 재사용한다. 서신과 비유는 상징 설명, 요한계시록은 환상 이미지 연출로 표시하여 실제 역사적 사건의 재현과 구분한다.

## 데이터 교정과 연출

- 배우·중심 물건 교정을 69개 장면에 적용했다.
- 향유를 붓는 여인, 은 삼십을 받는 가룟 유다, 기도하는 예수, 장사하는 아리마대 요셉, 손을 잡아 일으키는 베드로 등을 실제 행동 주체로 연결했다.
- 마태복음·마가복음의 머리에 향유 붓기와 요한복음의 발에 향유 붓기를 별도 동작으로 나눴다.
- 발 씻기, 그물 던져 끌어올리기, 떡 떼어 나누기, 풍랑 뒤 고요해진 바다, 일어나는 병자, 무덤에서 나오는 나사로, 유두고와 다비다 장면을 구분했다.
- 방문 장면의 아기 예수와 성전의 열두 살 예수는 기존 도안을 바탕으로 해당 장면에서만 크기와 수염 표현을 조절했다.
- 요한계시록은 두루마리 기록·흰옷·열린 문·향·대접·결박·도성 등의 이미지에 맞는 동작을 지정했다. 새 예루살렘의 중심 소품은 성전이 아닌 성벽으로 교정했다.
- 행동 주체가 두 번째 배우일 때 인물들이 등을 돌리던 공통 방향 오류를 수정하고, 손·소품 좌표도 같은 방향을 사용하게 했다. 이 수정은 구약에도 적용된다.

## 재생 흐름

일상 상호작용은 기존 월드에서 진행한다. 특수 조합을 준비해 사용자가 `사건 보기`를 눌렀을 때만 전용 장면을 연다. 일시정지·계속·닫기를 제공하며, 재생이 끝나면 마지막 자세를 유지하고 같은 동작을 계속 반복하지 않는다. 한 페이지짜리 사건은 `장면 마치기`로 종료하며, 여러 설명 페이지가 있는 경우 캔버스를 유지한다.

## 검증과 한계

- 전체 단위 테스트 127개 통과.
- 신약 27권 196개 장면을 Chromium에서 시작·행동·결과·대화 확대 모드, 7개 시점으로 검사했으며 렌더링 예외는 0건이다. 별도 기존 정적 신약 조합 4개도 검사했다. 대표 프레임은 권별 스크린샷으로 수동 확인했다. 모든 프레임을 사람이 하나씩 시청했다는 의미는 아니다.
- 요한복음 13장의 실제 월드에서 선택 재생·정지 프레임 고정·닫기·자동 반복 방지와 가로 모바일의 닫기 버튼 히트 테스트를 통과했다. 이 장면은 설명이 한 페이지라 페이지 전환 대신 정상 종료를 확인했다. 여러 페이지 캔버스 유지 검증은 구약 월드 검사에 포함된다.
- 공유 재생기 수정 후 구약 39권 715개 장면도 다시 렌더링 검사했다.
- 비공개 두 역본의 참조 범위 존재와 주석 장 연결을 확인했다. 이는 260장 전 구절의 새로운 수동 신학 검토를 뜻하지 않는다. 원문과 DB, 조회 해시는 저장소에 넣지 않았다.
- 데스크톱·가로 모바일 크기의 Chromium 검수이며 실제 iPhone/Android 기기에서 실행한 검사는 아니다.

## 편집·재현

신약 연출표는 `tools/pixel-bible/animation/book-plans-nt.json`, 데이터 교정은 `corrections-nt.json`, 개별 장면의 표시 조절은 `stage-overrides-nt.json`에 있다. 검수 페이지는 `tools/pixel-bible/animation-review.html?testament=nt`이다.

저장소 루트의 로컬 정적 서버(8765)와 별도 Chromium CDP 테스트 프로필(9222)이 준비된 상태에서 실행한다.

```sh
node tools/pixel-bible/animation/build.mjs --nt
python tools/pixel-bible/animation/source-check.py --nt
python tools/pixel-bible/animation/browser-audit.py --nt
python tools/pixel-bible/animation/world-smoke.py --nt
node --test tests/*.test.mjs
```

바뀐 권만 검수할 때는 `browser-audit.py --nt --books jhn`처럼 지정한다.
