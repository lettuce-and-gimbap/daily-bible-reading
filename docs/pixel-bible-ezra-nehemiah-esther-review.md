# 에스라·느헤미야·에스더 도감 검토

검토 범위는 세 권에서 처음 등장하는 도감 신원과, 이미 도감에 있던 인물의 세 권 재등장 일부다. 전체 인물 생애나 도감 전체의 검증 완료를 뜻하지 않는다.

- 첫 등장 항목 91개: 에스라 35개, 느헤미야 30개, 에스더 26개
- 기존 도감 인물·집단의 재등장 사실 23건을 해당 구절 근거와 함께 추가
- 검토 완료 누계 903 / 앱 도감 신원 1,930
- 다음 첫 등장 범위: 욥기 1장
- 신규 항목의 구절은 개역개정 4판·쉬운성경 비공개 본문에서 절 수록을 확인하고, 해당 장면과 앱 인물 역할을 대조했다. 관련 호크마 장도 참고했다. 해석 확정이 아닌 이름·역할 소개에 한정한다. 비공개 원문과 주석은 저장소에 복사하지 않았다.
- 에스라 2장의 느헤미야(귀환자)와 에스더 2장의 모르드개는 후대 책의 동명 인물과 분리했다.
- 에스라·느헤미야·에스더, 그리고 아닥사스다의 장면별 집단/미확인 분류를 인물 신원에 통합했다. summary JSON은 PIXEL BIBLE과 통독 UI가 함께 쓰는 관계도 DB이며, 세 권의 관계 끝점은 같은 장의 인물 목록에 모두 존재한다.
- 와스디의 거절, 에스라 10장의 이방 아내와 자녀, 느헤미야 5장의 가난한 가족, 에스더 9장의 폭력은 본문에서 벗어난 도덕 평가·비난·미화 없이 표현했다.

비공개 참고 자료: 개역개정 4판 및 쉬운성경의 해당 장, 업로드 호크마 정리의 해당 장. 본문 원문과 주석 원문은 공개 데이터에 포함하지 않는다.
