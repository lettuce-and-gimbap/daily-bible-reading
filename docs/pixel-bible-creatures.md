# 동식물 캐릭터

현재 장별 공개 설명에서 언급된 생물을 인물·생물 명단에 함께 추가한다. 정의는 동물 27종·식물 14종, 총 41종이다. 전권 1,189장 자료에서 960건의 종별 언급을 찾았다. 원문 전체의 생물 목록을 완성했다는 뜻은 아니며 비유에서 언급된 생물도 포함할 수 있다. 같은 종은 해당 통독 범위에서 하나의 상징 캐릭터로 모으며 참고 장을 보존한다. 노아의 방주에 등장할 모든 종 등을 추측해서 추가하지 않는다. 계시록의 어린 양은 일반 양 캐릭터로 만들지 않는다.

`creatures.js`는 종·신체 계열·색상·본문 감지·대사 제한·이용 가능한 오브젝트를 관리한다. `creature-art.js`는 네 발, 날개, 지느러미, 뱀의 마디, 곤충 다리와 식물 줄기를 재사용해 그린다. 같은 계열은 도안 일부를 공유하며 낙타 혹, 사자 갈기, 나귀 귀, 사슴 뿔, 개구리 뒷다리 등 차이를 둔다. 이는 창작 도안이며 실제 사건의 외형을 복원했다는 뜻이 아니다.

- 동물만/식물만 표시와 개별 표시 전환을 제공한다. 인물·생물은 함께 표시할 수도 있다.
- 동물은 종별 속도와 보행 리듬을 쓴다. 새는 짧은 보행·날갯짓, 뱀은 마디 이동, 물고기는 작은 수면 표시와 지느러미 움직임을 쓴다. 물고기를 육상 자동 산책 경로에 넣지 않는다.
- 초식동물의 풀 먹기, 새의 곡식 쪼기, 물 마시기, 냄새 맡기, 쉼·관찰 등을 적용한다. 활을 쏘거나 의복을 입는 인간용 동작과 손 소품은 사용하지 않는다.
- 식물은 뿌리내린 위치에서 흔들린다. 가까이 물 오브젝트를 두면 제자리에서 물·잎 반응을 보인다. 사용자가 집어 위치를 옮기는 것은 가능하다.
- 기본 생물 대사는 없다. 클릭 시 설명은 볼 수 있지만 임의 독백·관계 대사·오브젝트 대사를 만들지 않는다. 인간끼리의 조우 대사에 생물을 섞지 않는다.
- 창세기 3:1–5의 뱀, 민수기 22:28–30의 나귀는 해당 장이 통독 범위에 있을 때만 기록된 발화를 짧게 재구성해 사용한다. 두 역본과 호크마 비공개 참고 DB로 이 두 범위를 대조했다. 원문은 공개 DB·앱·Git에 넣지 않았다.

생물 색인은 `node tools/pixel-bible/creatures-catalog.mjs`로 만들고 `--check`로 검증한다. 실행 중에는 현재 장의 설명으로만 명단을 계산하며 전권 생물 JSON을 다운로드하지 않는다.
