# 대사 및 본문 읽기 도구 보강 — 2026-10-24

## 대사

고유 독백·주요 인물 DB에서 추상적인 표현을 검색하고, 같은 인물의 다른 대사가 사물·상황을 설명하는지 검토했다. 바꾼 문장은 30개다. 역할별 범용 독백의 보편적인 기본 문구 3개는 제거했고, 이름이나 가족관계만으로 인물의 속마음을 만들어 넣는 분기를 막았다. 구체적인 역할(추수·재건 등) 기반 대사는 남아 있다. 모든 본문 인물에 대해 새 대사를 3개씩 창작한 작업은 아니다.

두 비공개 역본에서 기존 독백의 근거 198개 범위를 조회했다. 실제 수정에 집중한 범위는 출애굽기 4:10–12, 28:1–4, 35:30–35, 38:21; 룻기 2:19–20; 열왕기상 1:38–40, 19:5–8; 사무엘상 16:23, 25:43; 사무엘하 6:10–12, 23:20–23; 열왕기하 11:4–12; 이사야 6:5–8; 아모스 7:14–15; 미가 6:6–8; 학개 2:4; 여호수아 14:6–12; 사도행전 6:8–10, 16:14–15; 디모데전서 4:12–16; 에베소서 6:21–22; 빌립보서 2:25–30; 디모데후서 1:16–18. 대사는 직접 새로 쓴 창작이며 성경의 직접 인용이 아니다. 기존 대조 기록과 함께 사용한다.

## 강조와 용어

픽셀바이블 자세히 보기의 설명과 관련 구절에서, 대사 맥락에 등장하는 핵심 사물·용어를 최대 5개 골라 굵게·형광색으로 표시한다. 모든 해석적 중요도를 자동 판정하는 기능은 아니다. HTML을 이스케이프하고 텍스트 노드만 감싼다.

통독/QT 본문의 용어 팝업은 앱 자체 설명이다. 갓피아의 주석 원문을 수집하거나 복제하지 않는다. 첫 적용은 기업 무를 자, 우림과 둠밈, 희년, 할례, 에봇, 흉패 6개다. 비공개 두 역본과 호크마에서 레위기 25:25, 25:10; 출애굽기 28:4, 15–21, 30; 창세기 17:10 및 기존 사무엘상 2:18 대조를 참고했다. 풀이와 근거만 짧게 공개하며 비공개 원문·DB는 포함하지 않는다.

## 사용자 표시

통독과 QT에서 절을 선택한 뒤 노랑·초록·분홍 표시, 표시 해제, 구절 메모 저장을 할 수 있다. 같은 장·절·역본 조합이면 두 화면에서 같은 표시를 읽는다. 현재 기능은 절 단위 색칠이며 단어 일부만 칠하는 기능은 포함하지 않는다. 색과 사용자가 쓴 메모를 이 기기 localStorage에 저장하며 성경 본문 사본을 저장하지 않는다. 계정 동기화·다른 기기로 이동은 지원하지 않는다. 표시 해제는 메모를 지우지 않는다.

검증: Node 검사 84개 통과. Chromium에서 데스크톱, iPhone 13, Pixel 7 화면 설정으로 용어 팝업의 체크박스 오작동 방지, 색 저장, 메모 저장·조회, 메모 버튼 중복 방지를 확인했다. 실제 iOS Safari/Android 기기 테스트를 뜻하지 않는다.
