# 열왕기하 사건·인물 1차 전수조사

2026-10-25. 조사 범위는 열왕기하 1–25장이다. 성경 전체 조사 완료를 뜻하지 않는다.

## 추가 내용

- 본문 기반 장면 60개를 25장 전체에 배치했다. 이전 요단 관련 장면 4개는 중복 실행되지 않도록 새 목록으로 대체했다. 기존 다른 조합은 유지했다.
- 열왕기하 인물 이름 표기는 128종에서 139종으로 늘었다. 이는 집단·동명이인 표기가 섞인 명단 수이며 고유 인물 139명을 뜻하지 않는다.
- 새 이름 11종: 시비아, 여호앗단, 여골리야, 여루사, 헵시바, 므술레멧, 여디다, 하무달, 스비다, 요하난, 야아사니야. 훌다의 남편 살룸은 기존 왕 살룸과 별도 신원 규칙으로 처리한다.
- 어머니·배우자는 본문에 언급된 관계를 보강했다. 현장에 실제 동석했다는 뜻은 아니다. 새 인물에게 성경에 없는 특별한 행동은 붙이지 않았다.
- 장면별 화자 대사를 등록해 해당 인물·오브젝트의 자동 상호작용에도 사용한다. 도감에는 현재 선택된 본문 장면의 설명이 모인다. QT 일부 절에 해당하지 않는 사건을 도감에 주입하지 않는다.

## 자료 및 검토 한계

두 역본의 열왕기하 25장과 업로드 호크마 25장 자료를 로컬 비공개 검토 문서로 정렬했다. 공개 파일에는 원문 전문을 넣지 않는다. 사건 60개 범위는 두 역본의 절 존재·범위를 확인하고 해당 본문을 대조했다. 호크마 장별 도입·관련 발췌를 해석 보조로 조회했다. 모든 절의 모든 해석과 인물을 빠짐없이 정밀 교감했다는 뜻은 아니다. 특히 본문에 이름만 언급되는 계보 인물은 계속 확장할 수 있다.

소금·가루·무화과 등을 일반 의학·정수 방법으로 안내하지 않는다. 신적 행동을 인간의 임의 능력으로 만들지 않는다. 성폭력·학살의 구체적 모션이나 보상은 만들지 않았다. 성경 문장을 직접 인용한 대사가 아니라 본문 기반의 짧은 창작·뜻풀이이며 화자와 상세 설명에서 이를 알린다.

## 동작 범위

새 사건의 조합·본문 해설·화자별 발화·도감 수집이 추가됐다. 겉옷·두루마리·기름·화살 등 기존 오브젝트 동작을 재사용한다. 60종 각각의 전용 애니메이션이나 지형 변형을 모두 새로 만든 것은 아니다. 물 가르기는 기존 겉옷 효과를 활용하며 실제 지형에 영구 통로를 만들지는 않는다. 상징 오브젝트인 경우 조합 설명에 그 성격을 표시한다.
