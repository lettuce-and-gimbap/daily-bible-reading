# 양 알림 모션과 관리자 이름

포즈 DB 160종을 모두 장면 중심으로 다시 구성했다. 소파 틈·빨래통·청소기·폭주 쇼핑카트·스케이트·바나나 껍질·로켓·뒤집힌 우산·낙하산·튜브·서핑·햄스터 바퀴·런닝머신·의자·해먹·여행가방·거대 연필·책 더미·피자 상자·도넛·찻잔·알람시계·다리미판·빗자루·낚싯대·스프링·트램펄린·북·훌라후프·택배 상자·풍선·덤벨·양말·회전판·젤리·꼬깔·눈사람·꽃병·카메라의 40개 상황이다. 각 상황마다 널브러짐·허둥대기·공중 뒤집힘·납작 주저앉기의 네 가지 몸 전체 자세를 둔다. 이전 DB 키는 유지하고, 관리자 선택창에는 실제 상황과 자세 이름을 표시한다. 손끝 위치만 바꾸는 프레임 구성은 제거했다.

푸시 알림 이미지는 정지 JPG이므로 연속 애니메이션이 아니라 동작을 크게 표현한 장면이다. 기본 179개 알림은 160개 포즈를 모두 사용한다.

렌더러는 소품을 포함한 SVG 경계를 측정해 왼쪽 312×312 영역에 맞춘다. 말풍선은 별도 오른쪽 영역에서 줄바꿈해 얼굴·몸통·소품과의 겹침을 줄인다. 이미 서버에 저장된 알림도 관리자 화면의 ‘전체 알림에 새 양 모션 배정’을 누른 뒤 ‘수정본 저장’하면 제목·본문·말풍선·이름을 보존한 채 160종 새 도안으로 다시 생성할 수 있다. JPEG 생성은 4장씩 제한 병렬 처리하고 진행 수를 표시한다. 한 묶음의 작업이 모두 종료된 뒤 실패를 반환해 재시도 중 이전 생성 작업이 섞이지 않게 한다. 기본적으로 저장된 사용자 지정 이미지는 유지하며, 관리자 화면에서 모션 또는 말풍선을 바꾸면 새 배치로 렌더링한다.

관리자는 분류 표시 이름과 개별 항목 이름을 편집할 수 있다. 시간대 스케줄에 쓰는 내부 키(morning 등)는 고정한다. 분류명은 서버 DB의 labels, 개별 이름은 메시지 배열 6번 슬롯에 저장한다. 이름이 비어 있으면 기존 시간대·번호 표시로 돌아간다. 기존 알림 배열과 이미지 경로는 호환된다. 서버 검증은 분류명 60자, 항목명 80자까지 허용하며 기존 관리자 권한 검사를 거친다.

이름 편집에는 Worker의 reminderMessagesApiVersion 4가 필요하다. Pages 반영과 별도로 worker 디렉터리에서 Cloudflare 인증 후 `npx wrangler deploy`로 배포해야 한다. 구버전 Worker에서는 편집 내용의 서버 저장을 막고 업데이트 안내를 표시한다.
