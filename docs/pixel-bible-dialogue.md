# PIXEL BIBLE 대사 검토본

총 522문장: 기존 100종 독백 200개, 외형 독립 주요 인물/정체성 100세트 독백 200개, 방향별 관계 61상황 122개. 별칭·동명이인과 시점 변형이 있어 200명의 고유 인물 수로 해석하지 않는다.

성경 본문과 저장소 장별 자료를 바탕으로 새로 쓴 상상 대사다. 실제 발언·직접 인용·당시 내면의 확정이 아니다. **로컬 두 역본과 호크마 정리 MD를 참고해 대사 목록·참조와 명시적 사건을 검토했다.** 원 주석의 출판본 대조나 모든 인물의 내면·회개를 검증했다는 뜻은 아니다. 최신 범위와 수정 내역은 docs/pixel-bible-content-review.md를 참고한다. 검토 범위는 docs/pixel-bible-source-review.md에 기록한다. 저작권 주석 원문은 이 파일/저장소에 넣지 않는다.

이세벨–나봇의 직접 대면과 개인적 혐오는 본문 기록으로 확정하지 않는다. 현재 항목은 열왕기상 21장의 강탈·모함을 바탕으로 쓴 1인칭 창작 발화다. 실제로 서로 대면했다는 뜻은 아니다. 사신을 통해 전해진 사건의 설명은 자세히 보기에 보존한다.

독백은 인물의 상징 대사이며 오늘 본문의 시점을 그대로 재현하지 않는다. 모호한 왕/동명 표기는 정해 둔 본문일 때만 개인 독백을 쓰고 그 외에는 창작 일상 대사를 사용한다. 관계 대사는 지정 장이 오늘 분량에 있고 두 인물이 3타일 안에 있으며 이동 중이 아닐 때만 후보가 된다. 화면에는 대사와 클릭 가능한 참고 구절만 표시하고, 창작 여부와 자료 검토 상태는 이 문서에서 관리한다.
