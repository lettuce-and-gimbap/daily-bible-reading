# 조합 잠금과 신약 확장

2026-10-25. 앱 버전 10.4.0 유지.

## 조합 잠금

- 입장 시 조합식은 잠금 상태다. 제목·화자·물건·참조를 조합 카드에서 감추고 물음표 인물 실루엣과 오브젝트 칸을 보여 준다. 인물들을 물건의 가까운 칸에 놓는다는 공통 규칙을 안내한다. 이것은 비밀 정보를 보호하는 보안 기능이 아니라 화면의 스포일러 방지 기능이다.
- 관리되는 통독 진행의 `progress().dailyDone`을 통해 **오늘 통독 완료** 여부를 확인한다. 완료 후 잠금 토글을 끄면 현재 분량의 조합을 볼 수 있다. QT 완료만으로 통독 조합 잠금이 풀리지는 않는다.
- 인물 전원이 물건에서 1.8타일 이내에 있을 때 캐릭터·오브젝트 드롭 또는 새 배치로 해당 사건을 시작할 수 있다. 물에 빠진 인물은 배치 완성으로 세지 않는다. 특정한 좌우 순서를 강제하지 않고 물건 가까이에 모이는 방식이다.
- 사건이 시작되면 그 조합을 발견 기록에 저장한다. 발견한 조합은 읽기 완료 여부나 잠금 토글과 관계없이 이후에도 볼 수 있다. 저장은 현재 기기의 `pixel-bible-recipe-discoveries:v1`이며 구절·배우·물건·제목을 묶어 잘못된 다른 사건으로 해금이 옮겨가지 않게 한다.
- 잠긴 카드에 실행 버튼을 남기지 않는다. '다음 본문 장면' 버튼도 잠긴 사건을 건너뛰어 정답을 우회 공개하지 않는다. 공개 전용 조합 밖의 일상 동작 안내는 유지한다.
- 이미 발견한 조합만 계속 우선하지 않도록, 직접 배치할 때는 아직 발견하지 않은 일치 조합부터 찾는다. 기존 전용 사건을 일반 설명형 장면보다 우선한다.

## 신약 확장

신약 27권·260장의 기존 사건 후보 991개에 대해 두 업로드 역본의 절 범위·이름·물건을 자동 대조했다. 설명형 171개와 직접 쓴 발화 장면 16개를 권별 파일로 연결했다. 기존 인물의 장별 언급 기록 230개도 추가했다. 이는 새 고유 인물 230명이 아니다. 새 장면에서 필요한 오브젝트를 현재 분량의 인벤토리에 포함한다. 이번에 새 픽셀 오브젝트 그림 종류나 전용 모션을 새로 제작한 것은 아니다.

리디아의 초대, 바울의 장막 만들기·배 위의 식사, 베드로의 그물·세족 반응, 삭개오의 나무, 다비다 사건 등을 발화로 연결했다. 누가복음의 시몬과 요한복음의 시몬 베드로는 해당 장에서만 베드로의 발화로 연결하며 모든 시몬을 같은 사람으로 처리하지 않는다.

구약 상세 수동 검토의 남은 범위는 `ot-event-expansion.md`에 기록된 그대로다. 신약도 전 절의 수동 정밀 주석 교감이나 전 사건의 전용 애니메이션 완성을 뜻하지 않는다. 호크마는 해당 장 자료의 존재를 확인했으며 이번 일괄 생성에서 260장 전체를 수동으로 읽고 검증했다고 주장하지 않는다. 근거가 부족한 장은 조합 수를 억지로 늘리지 않는다. 생성 근거·제외 사유는 `data/pixel-bible/events/review-nt.json`에 남긴다.

재생성: `node tools/pixel-bible/ot-event-candidates.mjs --nt`, `python tools/pixel-bible/build-ot-events.py --nt`. 비공개 원문은 로컬에서만 조회하며 공개 데이터에 복사하지 않는다.

## 확인

자동 테스트는 잠금·완독·영구 발견·실제 배치 조건·손상된 저장과 신약 장면 참조·물건·배우를 확인한다. Chromium 가로 모바일에서 미완독 상태 공개 차단, 완독 후 공개, 다시 잠금을 확인했다. 실제 iOS 기기 검증은 별도로 필요하다.
