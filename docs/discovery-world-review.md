# 동적 관계도와 발견 도감 — 2026-10-24

사용자 승인한 순서에 따라 관계도 강조, 월드 주요 인물, 수집 도감, 만남 반응, 알아가기 단계를 한 기능 흐름으로 연결했다. 앱 버전은 10.3.0으로 유지한다.

## 중요도와 동적 관계

통독·QT 공통 SVG 관계도는 서로 다른 연결 인물 수로 이름 상자의 폭·높이를 제한적으로 늘린다. 같은 두 사람 사이의 중복 관계를 여러 연결 인물로 세지 않는다. 배치·선의 끝점·충돌 계산에도 같은 상자 크기를 적용한다. 계산 결과는 관계 배열별 WeakMap에 캐시하여 드래그/배치 루프에서 관계 전수 검색을 반복하지 않는다.

픽셀 월드는 현재 본문에 한해 직접 연결 인물 수 × 2, 관련 사건 수(최대 4), 기존 인물 가중치 보정(최대 2)을 사용해 최대 세 인물을 고른다. 골리앗·삭개오 등의 기록된 체격은 유지하고 발밑 빛으로 중요도를 보여 준다. 인물 상세에서 연결 수와 관련 사건 수를 확인할 수 있다. 랜덤 말풍선 발생 횟수나 창작 대사 개수는 중요도에 사용하지 않는다. 실제 성경 발화량을 화자별로 집계한 기능은 이번에 포함하지 않는다.

관계 있는 두 인물의 조우 대화 중에는 관계선을 잠시 자동 표시한다. 전체 관계선 토글도 유지한다. 관계선의 머리 연결점은 인물 체격을 반영한다. 구체적인 관계 설명은 기존 말풍선의 자세히 보기와 도감에서 읽는다.

관계가 확인되지 않은 두 인물은 짧은 일상 인사 후 각자의 이동을 재개한다. 이를 실제 역사적 불화나 친분으로 저장하지 않는다. 이 인사에는 성경 참조나 주석 상세 버튼을 붙이지 않는다. 공간 버킷으로 옆 칸을 찾고, 한 번에 한 쌍만 진행하며 동일한 자리에 계속 서 있으면 반복하지 않는다. 새 일상 인사에는 20초 간격을 둔다. 조우의 각 말풍선은 5초, 답변은 0.8초 뒤 시작하며, 기존 자동 말풍선의 5초 표시 후 실제 소멸부터 3초 공백은 유지한다.

## 발견 도감

월드의 인물을 선택하면 발견으로 기록한다. 인물 패널의 '발견 도감 · 알아가기' 또는 인물 상세의 도감 버튼으로 연다. 주요 등장 권(앱 요약에서 확인된 등장 장 수), 지금까지 만난 본문, 인물 소개, 가족/계보 관계, 직접 연결된 주변 인물과 설명을 볼 수 있다. 아직 발견하지 않은 주변 인물도 해당 인물과의 관계 설명은 볼 수 있다.

알려진 동일 신원의 다른 이름 표기는 합치고, 동명이인은 신원 ID로 구분한다. 신원 미해결 인물은 기존 문맥 키를 유지하며 책을 넘어 임의로 합치지 않는다. 동식물·창작 안내 캐릭터는 이번 인물 도감 수집에서 제외한다. 처음부터 월드의 모든 인물을 자동으로 수집하지 않는다.

현재 본문에 확인된 공개 요약·관계 설명을 두 문장 이내, 최대 240자로 정리해 도감에 쌓는다. 비공개 원문·호크마 DB를 브라우저로 보내거나 새 원문 사본을 만들지 않는다. 도감은 모든 성경 인물의 전 생애를 미리 완성한 백과가 아니라, 읽고 발견한 범위에서 자라는 도감이다. 주요 등장 권용 기존 공개 색인은 도감을 처음 열 때에만 불러오므로 월드 진입 때 전권 자료를 추가 로딩하지 않는다.

도감 기록은 localStorage `pixel-bible-discoveries:v1`에 저장한다. 현재 기기의 브라우저에 저장되며 계정 동기화/기존 백업에는 포함되지 않는다. 저장 실패 시 이번 입장 동안만 유지된다고 알린다. 임의의 개수 제한으로 이미 발견한 이야기나 관계를 삭제하지 않는다. 이야기 목록은 최고 단계에서 20개씩 더 펼쳐 볼 수 있다.

## 알아가기

1. 첫 만남: 기본 소개·첫 이야기.
2. 이야기 듣기: 서로 다른 이야기 하나를 읽으면 다음 이야기를 정리해 보여 준다.
3. 관계 알아가기: 직접 연결된 주변 인물도 발견하면 진행한다. 관계 자료가 없는 인물은 이 조건을 생략한다.
4. 깊이 알아가기: 서로 다른 이야기 둘을 읽고 KST 기준 다른 날에 다시 만나면 진행한다.

같은 날 반복 클릭·같은 이야기 재열람은 진행도를 늘리지 않는다. 쉬었다 돌아와도 단계가 내려가지 않는다. 잠기는 것은 도감의 추가 이야기 구성이고, 앱의 성경 본문 읽기는 단계와 무관하게 언제나 가능하다. 이야기 설명이 부족한 인물은 다른 본문에서 다시 만날 때 자료를 추가하며, 임의의 이야기를 만들어 단계를 채우지 않는다.
