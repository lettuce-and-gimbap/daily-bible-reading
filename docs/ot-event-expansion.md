# 구약 사건 확장 통합 기록

작업일: 2026-10-26. 처리 순서: 열왕기하 → 창세기–사무엘하 → 열왕기상 → 역대상–말라기.

## 구현된 범위

구약 39권·929장 모두에 대해 다섯 한국어 역본의 절 범위와 공개 앱 사건 설명을 로컬에서 대조했다. 사건 후보 3,533개 중 667개에서 배우와 소품의 근거를 모두 확인했고, 직접 작성한 화자 대사 43개를 별도로 연결했다. 기존 예언 상징 장면 4개와 사사기·룻기·사무엘상·사무엘하·열왕기상·역대상에서 수동 검토로 보강한 632개 장면을 포함해 권별 파일에는 1,346개가 있다. 열왕기하 전용 60개는 유지한다. 이 숫자는 수동 신학 주석이나 모든 사건의 물리 애니메이션 제작을 뜻하지 않는다.

기존에 확인된 인물 이름이 해당 장의 두 역본에 함께 나타나는 770개의 인물–장 언급 기록을 명단에 추가했다. 이는 새 고유 인물 770명이 아니다. 현장 동석이 아닌 역사적 언급도 있으므로 표시 역할에 그 사실을 알린다. 동명이인 위험이 큰 이름은 자동 추가에서 제외했다.

시·예언·환상은 설명으로 구분한다. 확인된 인물과 물건이 없는 구절에 무조건 NPC나 조합을 만들지 않는다. 일반 해설 장면은 자동 1인칭 대사를 생성하지 않고, 사용자가 조합으로 모아 볼 때만 설명을 보여 준다. 직접 작성한 화자 대사만 자동 상호작용에 연결한다. 도구의 공통 그림이 본문 속 정확한 모양이라는 뜻은 아니다.

## 원문 대조의 정확한 의미와 남은 검토

이 결과는 **전 구절의 수동 정밀 주석 검토 완료를 뜻하지 않는다**. 기존 앱의 사람이 작성한 사건 설명을 재사용하고, 두 역본의 절 존재·이름·물건을 자동 확인한 확장이다. 호크마 929장 자료의 존재와 접근 가능성을 확인했으나 이번 일괄 처리에서 모든 장의 해석을 수동으로 읽어 교감한 것은 아니다. 상세히 판단하지 못한 사건을 해석 검토 완료로 표기하지 않는다.

공개 데이터의 review.json에는 각 장의 후보 수·반영 수·보류 사유가 남는다. 배우만 확인된 1,000개와 소품만 확인된 629개는 짝이 맞지 않아 장면으로 자동 확정하지 않았다. 둘 다 확인되지 않은 1,227개도 시·예언·권면 등일 수 있어 임의로 무대화하지 않았다. 별도 9개 범위는 개역개정 Markdown 원본에 번호가 빠져 있지만 쉬운성경·개역한글·현대인의성경·새번역에는 해당 절이 있어 `source-edition-gap`으로 분리했다. 병합된 절로 단정하거나 나누지 않았다. 따라서 구약 원문 전부의 세밀한 해석·인물 조사·전용 동작 제작은 이 검수만으로 완결되지 않았다.

원문·DB·호크마 사본은 공개 파일에 포함하지 않는다. 생성기는 오프라인 개발 전용이며 앱은 새로 작성된 공개 설명 파일만 읽는다. 위치·이름·절 범위가 맞더라도 해석의 정확성을 자동 보증하지 않는다.

## 사용 방식

현재 분량의 권 파일만 입장할 때 읽는다. 새 명단은 인물 선택과 도감 발견에 연결되고, 새 사건은 도구·조합에서 선택할 수 있다. QT에서는 장면의 정확한 절 목록과 대조한다. 새 대사에는 짧은 직접 작성 문장을 사용하고, 장 전체 해설을 말풍선에 보내지 않는다. 모든 신규 사건에 전용 픽셀 프레임을 제작한 것은 아니다.

- source-confirmed-actor-only: 1,000개 (소품 근거 없음)
- source-confirmed-object-only: 629개 (배우 근거 없음)
- no-source-confirmed-actor-or-object: 1,227개
- source-edition-gap: 9개 (개역개정 원본에서 절 번호가 누락되고 다른 한국어 역본에서는 확인됨)
- referenced-person-not-scene-actor: 1개 (신명기 23장의 발람은 과거에 언급된 인물이므로 현재 장면의 배우에서 제외함)

## 검증

`node --test tests/*.test.mjs`로 구약 전권 이벤트 연결·장면 ID·오브젝트·배우·화자·QT 범위와 역본별 누락 분류를 검증한다. 이 검수는 모바일 실기기에서 장면을 모두 재생한 시각 검수를 대신하지 않는다.

검수표만 갱신: `node tools/pixel-bible/ot-event-candidates.mjs` 후 `python tools/pixel-bible/build-ot-events.py --audit-only`. 사건 파일을 다시 생성하려면 별도로 `python tools/pixel-bible/build-ot-events.py`와 애니메이션 빌더를 실행한다. 원문 본문은 보고서에 쓰지 않고 후보 입력은 저장소 밖 `/tmp`에 생성한다.

### 후속 복합 범위 교정
- 사사기 16:4–20은 들릴라의 압박과 비밀 노출, 21–22절은 삼손의 감옥 생활로 구분했다. 앞 장면의 중심 배우를 들릴라로 교정했다.
- 이사야 22:15–19의 셉나 책망과 20–25절의 엘리아김 임명을 분리했다.
- 아모스 8:1–3의 과일 환상과 4–14절의 착취·말씀 기근 경고, 9:1–6의 제단 환상과 7–10절의 체질 비유를 구분했다.
- 하박국 2:1–3의 기다림·기록과 4–5절의 교만·믿음 대조, 나훔 1:1–6의 심판 권능과 7–8절의 피난처, 예레미야애가 4:11–20의 함락 탄식과 21–22절의 에돔·시온 선언을 나눴다.
- 위 범위는 비공개 두 역본과 업로드 주석을 대조했다. 범위 교정이며 새 장면 수 증가나 전권 수동 검수 완료를 뜻하지 않는다.

### 민수기·역대하 복합 사건 후속 교정
- 두 업로드 역본과 비공개 주석으로 민수기 14:1–25, 역대하 4:1–22 및 20:1–20을 대조했다.
- 민수기의 귀환 요구(14:1–4), 여호수아·갈렙의 호소(5–10), 모세의 중보와 응답(11–25)을 분리했다.
- 역대하 4장의 기구 배치(1–10), 후람의 제작(11–18), 금 기구(19–22)를 나눴다.
- 역대하 20장의 침입·금식(1–4), 왕의 기도(5–13), 야하시엘의 격려와 응답(14–20)을 나눴다.
- 장면 3개를 추가했으며 각 복합 범위의 절이 누락·중복 없이 정확히 한 번씩 연결되는지 검사한다.

### 전도서·스가랴 복합 본문 후속 교정
- 두 업로드 역본과 비공개 주석으로 전도서 5:8–20, 12:1–14, 스가랴 4:1–14을 대조했다.
- 전도서 5장의 억압과 땅의 소산(8–9), 만족 없는 재물(10–17), 자기 몫의 기쁨(18–20)을 구분했다.
- 전도서 12장의 노년 비유(1–8), 지혜의 말(9–12), 경외와 심판의 결론(13–14)을 나눴다.
- 스가랴 4장의 환상 관찰(1–5), 스룹바벨에게 주어진 말씀(6–10), 감람나무 해석 질문(11–14)을 나눴다.
- 장면 3개를 추가하고 각 본문 범위를 중복·누락 없이 보존했는지 검사한다. 지혜 본문과 환상은 각각 설명형·환상형 연출을 유지한다.
