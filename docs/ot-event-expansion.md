# 구약 사건 확장 통합 기록

작업일: 2026-10-25. 처리 순서: 열왕기하 → 창세기–사무엘하 → 열왕기상 → 역대상–말라기.

## 구현된 범위

구약 39권·929장 모두에 대해 비공개 두 역본의 절 범위와 공개 앱 사건 설명을 로컬에서 대조했다. 공개 사건 후보 3,533개 가운데 667개를 설명형 조합 장면으로 만들고, 직접 작성한 화자 대사 43개를 별도로 연결했다. 권별 파일의 총 710개에는 기존 전용 장면과 같은 구절의 중복 후보가 포함되어 있으며 월드에서 동일 참조를 가진 전용 장면을 우선한다. 열왕기하 전용 60개는 유지한다.

기존에 확인된 인물 이름이 해당 장의 두 역본에 함께 나타나는 770개의 인물–장 언급 기록을 명단에 추가했다. 이는 새 고유 인물 770명이 아니다. 현장 동석이 아닌 역사적 언급도 있으므로 표시 역할에 그 사실을 알린다. 동명이인 위험이 큰 이름은 자동 추가에서 제외했다.

시·예언·환상은 설명으로 구분한다. 확인된 인물과 물건이 없는 구절에 무조건 NPC나 조합을 만들지 않는다. 일반 해설 장면은 자동 1인칭 대사를 생성하지 않고, 사용자가 조합으로 모아 볼 때만 설명을 보여 준다. 직접 작성한 화자 대사만 자동 상호작용에 연결한다. 도구의 공통 그림이 본문 속 정확한 모양이라는 뜻은 아니다.

## 원문 대조의 정확한 의미와 남은 검토

이 결과는 **전 구절의 수동 정밀 주석 검토 완료를 뜻하지 않는다**. 기존 앱의 사람이 작성한 사건 설명을 재사용하고, 두 역본의 절 존재·이름·물건을 자동 확인한 확장이다. 호크마 929장 자료의 존재와 접근 가능성을 확인했으나 이번 일괄 처리에서 모든 장의 해석을 수동으로 읽어 교감한 것은 아니다. 상세히 판단하지 못한 사건을 해석 검토 완료로 표기하지 않는다.

공개 데이터의 review.json에는 각 장의 후보 수·반영 수·제외 사유가 남는다. 절 범위에 문제가 있거나 인물·물건이 확인되지 않는 사건은 생성하지 않고 검토 대상으로 남긴다. 부록의 집계는 누락된 검토를 숨기지 않기 위한 것이다. 따라서 사용자가 요청한 구약 원문 전부의 세밀한 해석·인물 조사·전용 동작 제작은 이 일괄 확장만으로 완결되지 않았다.

원문·DB·호크마 사본은 공개 파일에 포함하지 않는다. 생성기는 오프라인 개발 전용이며 앱은 새로 작성된 공개 설명 파일만 읽는다. 위치·이름·절 범위가 맞더라도 해석의 정확성을 자동 보증하지 않는다.

## 사용 방식

현재 분량의 권 파일만 입장할 때 읽는다. 새 명단은 인물 선택과 도감 발견에 연결되고, 새 사건은 도구·조합에서 선택할 수 있다. QT에서는 장면의 정확한 절 목록과 대조한다. 새 대사에는 짧은 직접 작성 문장을 사용하고, 장 전체 해설을 말풍선에 보내지 않는다. 모든 신규 사건에 전용 픽셀 프레임을 제작한 것은 아니다.

## 검증

Node 테스트 101개 통과. 구약 전체 권 파일의 장면 ID·오브젝트·배우·화자 연결, 추가 인물의 장별 언급 근거, QT 범위 밖 장면 배제를 확인했다. Chromium 가로 모바일에서 창세기 24장의 새 조합 로딩과 리브가 도감·가족 관계를 확인했다. 710개 장면 전체를 실제 iOS 기기에서 재생·검수한 것은 아니다.

재생성: `node tools/pixel-bible/ot-event-candidates.mjs` 후 `python tools/pixel-bible/build-ot-events.py`. 두 비공개 원문 DB가 같은 환경에 있어야 한다. 원문은 출력하거나 외부로 전송하지 않는다. 후보 데이터는 저장소 밖 `/tmp`에 생성한다.
