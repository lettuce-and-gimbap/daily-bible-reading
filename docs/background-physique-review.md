외부 원본 이미지는 저장소 밖에서만 검토했다. 이번 변경은 직접 작성한 도트 코드이며 에셋을 복제하지 않았다. 검색 결과 썸네일 검토이지 해당 유료 팩 전체 또는 모든 애니메이션을 열람한 것은 아니다. OpenGameArt의 시도한 타일셋 URL은 페이지가 없어 근거로 사용하지 않았다.

## 배경

20개 배경의 실제 지형 구조와 기본 경관 배치를 보강했다. 도시는 포장 구획과 골목, 자연 지형은 구불구불한 길, 진영은 원형 길을 쓴다. 호수는 만과 부두, 강변은 굽이치는 물길, 산지는 층진 암벽, 광야는 둔덕, 보리밭·포도원은 작물 구획, 초장은 작은 연못과 울타리, 동산은 열매나무 군집으로 구분한다. 모든 배경에 반복되던 같은 북쪽 산 능선과 하단 띠를 줄였다. 기본 경관은 배경마다 종류·좌표가 다르며 중앙 이동 공간은 남긴다. 풍경은 지형 삽화이며 실제 지리 복원이나 새 이동 불가 수면 영역을 뜻하지 않는다.

## 인물

비공개 개역개정4판·쉬운성경과 호크마의 사무엘상 17:4–7, 9:2; 누가복음 19:3; 민수기 13:22, 32–33을 참고했다. 직접 조회한 범위는 사무엘상 17:4와 해당 4–7절 주석, 9:2, 누가복음 19:3, 민수기 13:32–33과 해당 주석이다.

골리앗은 폭 1.38·키 1.58, 삭개오는 폭 .96·키 .82, 구약 왕 사울은 폭 1.08·키 1.20, 아낙 자손은 폭 1.20·키 1.30으로 표현한다. 배율은 화면에서 구분하기 위한 창작 수치다. 민수기의 보고를 모든 가나안 주민의 체격으로 일반화하지 않는다. 바울로 불린 사울에게 왕 사울의 체격을 적용하지 않는다.

일반 인물의 폭·키·눈 간격·눈 색에는 이름별로 고정된 작은 창작 차이를 둔다. 새로운 해부학적 골격 시뮬레이션이 아니라 기존 사방향 도안의 비율 및 얼굴 도트 변형이다. 얼굴 표현은 기존 피부 마스크 안에서만 그린다. 선택 테두리·터치 역변환·말풍선 높이·휴대 물건 위치·손동작 효과도 체격을 반영한다. 손에 드는 기존 오브젝트의 원래 배율은 유지한다.
