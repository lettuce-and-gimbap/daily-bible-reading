# 마태복음–요한복음 도감 보강 기록

- 검토일: 2026-11-02
- 범위: 마태복음, 마가복음, 누가복음, 요한복음
- 1차 대조 자료: 저장소 밖 비공개 자료의 개역개정 4판·쉬운성경 Markdown
- 호크마 주석: 이번 검토에서는 사용하지 않음

## 반영 내용

- 네 복음서에서 처음 등장하는 도감 신원 174개를 추가 검토하고, 인물 설명과 근거 구절을 연결했다. 각 인물 항목은 해당 복음서 안의 역할과 장면에 한정해 서술했다.
- 앞선 성경 책에서 이미 소개된 인물이 복음서에 다시 등장하는 경우에도 복음서 본문을 근거로 보충했다.
- 예수님, 세례 요한, 베드로 항목은 네 복음서의 서로 다른 소개와 장면이 드러나도록 다시 정리했다.
- 헤롯(대왕)과 헤롯 안티파스를 분리했다. 후자는 마태복음 14장, 마가복음 6장, 누가복음 3장·23장의 역할에 연결했다. 사도행전 12장의 헤롯은 별도의 신원으로 남겼다.
- 예수님의 어머니 마리아와 베다니의 마리아, 마리아의 남편 요셉과 아리마대 요셉을 구별했다. 세베대의 아들 야고보와 요한, 사도 요한과 세례 요한도 각각 같은 인물의 다른 호칭이 있는 범위에서만 합쳤다.
- 이름이 본문에 직접 나오지 않는 요한복음의 “예수께서 사랑하신 제자”는 사도 요한이라고 단정해 합치지 않았다.
- 도감 신원 키가 정리되며 기존 기기 내 발견 기록도 새 키로 이동하거나 장·역할에 따라 분리하도록 마이그레이션을 추가했다.

## 범위와 진행 수치

- 누적 검토 항목: 1,633 / 앱 도감 신원 1,917
- 이번 추가: 마태복음 71, 마가복음 25, 누가복음 47, 요한복음 31
- 다음 첫 등장 검토 범위: 사도행전 1장
- 이 기록은 각 항목의 소개와 표시된 근거 구절을 대조한 범위다. 기존 대사, 관계, 외형 전체를 검증 완료했다는 뜻은 아니다.

## 점검 결과

- 복음서 인물 경로를 다시 생성해 모든 검토 항목이 현재 인물 신원에 연결되는지 확인했다.
- 구절 참조의 형식과 비공개 개역개정 4판·쉬운성경 본문 내 장·절 존재 여부를 정적으로 확인했다.
- 자동 테스트는 이번 요청에 포함되지 않아 실행하지 않았다.
