# 전도서·아가·이사야 도감 검토

검토 범위는 전도서·아가·이사야에서 첫 등장하는 도감 신원과, 이미 도감에 있던 인물의 이 세 권 재등장 일부다. 전체 인물 생애나 도감 전체의 검증 완료를 뜻하지 않는다.

- 첫 등장 항목 149개: 전도서 20개, 아가 11개, 이사야 118개
- 기존 도감 인물·집단의 이사야 재등장 사실 17건을 추가
- 검토 완료 누계 1,269 / 앱 도감 신원 1,929
- 다음 첫 등장 범위: 예레미야 3장
- 근거 구절의 수록을 개역개정 4판·쉬운성경 비공개 본문에서 확인하고 관련 호크마 장도 참고했다.
- 전도서의 전도자는 문학적 목소리로 소개하고, 솔로몬과의 동일시는 단정하지 않는다. 관찰을 모든 사람에게 적용되는 공식으로 바꾸지 않는다.
- 아가는 익명 화자와 사랑 노래의 시적 대화를 따른다. 노래 속 연인과 역사적 솔로몬의 동일시, 상징적 해석을 확정하지 않는다.
- 이사야의 예언·환상·시적 이미지와 역사적 인물·국가를 구분한다. 특히 ‘여호와의 종’, ‘이새의 싹’, ‘한 아기’, ‘계명성’의 신원을 본문 이상의 범위로 단정하지 않는다. 이름 없는 이사야의 아내도 그대로 익명으로 둔다.
- 이사야서의 선지자 이사야를 앞선 책의 이사야와 같은 인물 신원으로 연결했다. 기존 이름 통합은 유지하면서 관계도에는 본문 표기인 `여호사밧`과 민수기 10장의 `르우엘`을 표시하도록 정정했다.
- 세 권의 관계도는 PIXEL BIBLE과 통독이 함께 쓰는 `data/summary/{code}.json`을 기준으로 확인했다. 관계 끝점이 해당 장의 인물 목록에 연결된다.

비공개 원문과 주석 원문은 저장소에 복사하지 않았다.
