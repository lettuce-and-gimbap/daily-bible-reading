# 예레미야·예레미야애가·에스겔 도감 검토

검토 범위는 세 권의 첫 등장 도감 신원과 이미 도감에 있던 인물의 재등장 일부다. 전체 생애나 도감 전체의 검증 완료를 뜻하지 않는다.

- 첫 등장 항목 101개: 예레미야 73개, 예레미야애가 7개, 에스겔 21개
- 기존 도감 인물·집단의 세 권 재등장 사실 23건 추가
- 검토 완료 누계 1,370 / 앱 도감 신원 1,929
- 다음 첫 등장 범위: 다니엘 1장
- 근거 구절은 개역개정 4판·쉬운성경 본문에 실제 수록됐는지 확인하고 해당 장면과 앱 인물 역할을 대조했다. 관련 호크마 장도 참고했다.
- 예레미야서의 선지자 예레미야를 역대하의 기존 인물 신원과 통합했다. 서로 다른 바스훌과 야아사냐, 그리고 느헤미야 7장의 성채 관원과 예레미야 28장의 기브온 선지자 하나냐를 구분해 두었다.
- 예레미야애가의 예루살렘은 시적 의인화로, 화자는 특정 인물로 단정하지 않았다. 포위와 기근의 피해를 피해자 탓으로 돌리지 않는다.
- 에스겔의 생물·성전 환상은 환상 묘사로 소개하고, 상징을 현대 집단이나 특정 동물 종으로 단정하지 않는다. 두 야아사냐를 구별하고 에스겔의 아내는 익명으로 둔다.
- 에스겔 34장의 ‘양 떼’를 인물 색인에 추가해 관계 자료와 같은 장의 등장 인물 목록을 맞췄다. 세 권의 관계도 380개 모두 양 끝점이 해당 장의 인물 목록에 있다.
- 두 화면은 같은 `data/summary/{code}.json` 관계 DB를 사용한다. 원문과 주석은 비공개 자료로 저장소에 복사하지 않았다.
