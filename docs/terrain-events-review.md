# 본문 사건 및 지형 반응 추가

2026-10-24. 두 업로드 역본과 호크마 참고 정리에서 열왕기하 2:8–14, 2:19–22, 6:5–7을 대조했다. 원문 사본은 공개 데이터에 넣지 않았다.

- 사건 4개: 엘리야의 요단 도하, 엘리사의 요단 도하, 여리고 물 회복, 떠오른 도끼. 기존 사건 실행 UI와 도감의 사건 수집에 연결한다.
- 엘리야의 열왕기하 2장 겉옷 고유 동작을 추가한다. 기존 엘리사 물 가르기 효과를 재사용한다.
- 배경에 그린 호수·강의 물 영역을 보행 경로에서 제외한다. 사람이 물에 드롭되면 물결 표시 후 5초 뒤 가까운 통행 가능한 땅에 재배치하고 3초 쉰다. 이는 성경 기록이 아닌 놀이 반응이다.
- 현재 탈출은 연속 기어오르기 프레임이 아닌 안전한 땅 재배치다. 모든 지형의 물리 반응이나 도로 전용 이동까지 완성한 것은 아니다. 풀밭은 보행 가능하다.
- 기존 신원 DB를 유지하며 도감에 수집되는 사건을 확장했다. 새로운 성경 인물 신원 레코드는 이번에 추가하지 않았다.
