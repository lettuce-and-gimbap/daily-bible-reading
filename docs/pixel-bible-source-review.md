# 10.0.0 추가 참고 자료 검토

사용자가 제공한 호크마 기반 정리 MD 67파일(시편 2분할)을 클라우드 작업공간의 비공개 SQLite에 보관했다. 66권 1,189장을 색인했다. 자료 자체가 재정리본임을 밝히므로 출판 원본을 독립적으로 검증한 것으로 취급하지 않는다. 원문과 DB는 저장소와 정적 배포에 포함하지 않는다. 환경 재생성 시 보존을 보장하는 외부 DB 서비스는 아니다.

이번 수정에서는 열왕기상 19:4–8, 열왕기상 21:1–3, 열왕기하 2:9–12, 사무엘상 15:22–26의 참고 정리를 대사와 대조했다.

- 엘리야: 회복을 위한 음식과 쉼, 남은 여정에 초점을 맞췄다.
- 나봇: 단순한 고집이나 가격 협상이 아니라 하나님이 주신 가문의 기업이라는 이유를 반영했다.
- 엘리사: 갑절을 두 배의 마법 능력으로 표현하지 않고 사명을 잇는 몫으로 보강했다.
- 사울: 다윗과 같은 온전한 회개로 단정하는 자기 성찰형 문장을, 변명과 사람들 앞의 체면을 붙드는 본문 맥락으로 수정했다.

대사는 새로 쓴 극적 표현이며 실제 발언이나 주석의 직접 인용이 아니다. 전체 506문장의 주석 검토가 완료된 것은 아니다. 이후 변경 시 관련 장을 비공개 조회 도구로 확인하고 이 기록에 검토 범위를 추가한다.
