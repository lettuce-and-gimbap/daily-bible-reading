# 욥기·시편·잠언 도감 검토

검토 범위는 욥기·시편·잠언에서 처음 등장하는 도감 신원과, 이미 도감에 있던 인물의 이 세 권 재등장 일부다. 전체 인물 생애나 도감 전체의 검증 완료를 뜻하지 않는다.

- 첫 등장 항목 217개: 욥기 17개, 시편 133개, 잠언 67개
- 다윗·모세·솔로몬·사탄·아삽·헤만·에단의 세 권 재등장 사실 14건을 추가
- 검토 완료 누계 1,120 / 앱 도감 신원 1,930
- 다음 첫 등장 범위: 전도서 1장
- 구절 근거는 개역개정 4판·쉬운성경 비공개 본문에서 절 수록을 확인하고, 해당 장면과 앱 인물 역할을 대조했다. 호크마 자료의 해당 장도 해석 보조 자료로 참고했다.
- 시편 항목은 노래·기도 속 화자와 시적 표현을 소개하며, 표제가 명시하지 않는 저자나 대상을 단정하지 않는다.
- 잠언의 지혜·미련한 여인 등은 문학적 인격화나 교훈 속 인물 유형으로 구분하고, 성별·형편이 같은 실제 집단 전체로 일반화하지 않는다.
- 욥의 고난을 숨은 죄의 증거로 단정하지 않으며, 욥의 친구들 충고와 책의 결론을 구분한다. 베헤못·리워야단의 현대 생물학적 정체도 단정하지 않는다.
- 세 권 관계도는 PIXEL BIBLE과 통독이 함께 쓰는 `data/summary/{code}.json`을 확인했다. 관계 끝점이 해당 장의 인물 목록에 연결되어 있다.

비공개 원문과 주석 원문은 저장소에 복사하지 않았다.
