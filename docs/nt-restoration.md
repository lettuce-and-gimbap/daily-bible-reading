# 신약 전권 장면 연결·복원

2026-10-25 / 10.7.0

## 실제 작업 범위

신약 27권 260장의 기존 공개 요약에 있던 사건·가르침 단위 991개와 두 경계 구절을 연결했다. 기존 장면 196개는 삭제하지 않고, 빠진 범위를 822개 장면으로 보강해 총 1,018개가 되었다. 예전 장면에는 같은 단위를 세분한 장면과 서신 입문 장면도 있어 단위 수와 장면 수는 다르다.

`data/pixel-bible/events/coverage-nt.json`은 993개 단위의 범위와 장면 ID를 연결한다. 이는 **각 절의 모든 미세 행동을 독립 작화로 제작했다는 뜻은 아니다.** 공개 요약의 단위별 연결 복원이다. 기존 인물·물건 그림과 동작 골격을 재사용하며, 가르침 설명은 설명 카드로 표시한다.

- 요한복음 7:53의 다음 장 연결을 보강했다.
- 쉬운성경 계 12:18 / 개역개정 계 13:1의 절 구분 차이를 기록했다. 서로 다른 역본의 절 번호를 동일하게 가정하지 않는다.
- 설교에 인용된 다윗·요엘 등은 현장 배우로 넣지 않는다. 신적 존재를 임의의 인간 NPC로 추가하지 않는다.
- 배우가 확인되지 않는 설명은 사람이 행동한 것처럼 꾸미지 않고 설명 장면으로 표시한다. 서신은 이 방식을 사용한다.
- 새 장면의 짧은 설명은 인물의 창작 발화가 아니다. 기존 무작위 말풍선 대사 DB에 주입하지 않는다.

## 연출과 월드 연결

세례·떡 나눔·지붕의 침상 내리기·성령 강림·변화산·엠마오·환상의 두루마리·추수·생명수 강에 별도 순서와 결과 그림을 연결했다. 사천 명 장면의 일곱 광주리와 오천 명 장면의 열두 광주리를 구분한다. 구유의 아기는 작은 원래 픽셀 도안으로 눕혀 표현한다.

기존 조합/해금 ID는 유지한다. 통독과 QT에서 현재 구절과 교차하는 장면을 불러온다. 기존 전용 조합이 같은 범위를 대신할 때도 연결 단위 정보를 보존한다. 배우가 없는 설명은 물건 배치만으로 자동 발견되지 않지만, 해금 후 사용자가 직접 열 수 있다.

준비 → `사건 보기` 동의 → 한 번 재생 → 종료 순서다. 일시정지·닫기가 가능하다. 마지막 동작에서 재시작하지 않는다. 설명이 비어 있어 재생 타이머에서 오류가 나는 문제와 배우 없는 설명이 준비 단계로 돌아가는 문제도 실제 월드 검사에서 수정했다.

## 검증

- 단위 테스트 133개: 새 6개 검증은 연결 단위·유효 동작·배우·본문 분량 필터·260장 실제 모델 구성을 검사한다.
- 비공개 개역개정/쉬운성경의 비어 있지 않은 절 행이 연결 범위에 모두 포함되는지 자동 검사했다. 원문/DB/해시는 저장소에 내보내지 않는다. 이는 전체 원문의 새로운 수동 신학 검토와 다르다.
- Chromium 검수는 모든 등록 장면에 대해 시작/동작/종료/대화 확대와 7개 시점을 그려 예외를 확인한다. 화면 전체를 사람이 동영상처럼 모두 감상한 것은 아니다.
- 세례·떡 나눔·변화산·침상 내리기·야이로의 딸·구유·엠마오·오순절·베드로 설교·로마서 설명·계시록의 두루마리/생명수 강은 대표 프레임을 별도로 수동 확인했다.
- 실제 월드에서 새 설명 장면과 기존 장면의 선택 재생/정지/닫기/자동 반복 방지를 확인한다. 가로 모바일은 Chromium의 화면 크기/히트 테스트이며 실제 iOS/Android 실기기 검사는 아니다.
