# PIXEL BIBLE 관리자 개발 체험

정식 공개 전에는 서버가 확인한 `buucksoo` 계정에만 앱 내 월드를 연다. 관리 화면 배너와 통독 탭 옆 작은 입구는 모두에게 표시하고, 일반 사용자는 개발 안내만 본다. 계정 확인에 실패하면 입장을 허용하지 않는다. 공식 앱 버전과 업데이트 기록은 올리지 않는다. 이후 공개 범위 변경은 사용자의 정식 출시 요청이 있을 때만 한다.

## 현재 기능

- 통독 계획의 오늘 분량에서 인물·관계·설명을 가져온다. 계획이 없으면 `체험 본문 · 룻기 2`로 명확히 표시한다.
- 월드/도안 모듈과 필요한 권의 JSON만 입장 시 불러온다. 공통 지형과 캐릭터 그림은 코드로 재사용하며 책 데이터는 입장 사이에도 메모리에 캐시한다. 본문 장을 바꿀 때 월드를 로딩하지 않는다.
- 가로 화면 전용. 전체화면·화면 방향 잠금을 시도하고, 지원하지 않는 브라우저에서는 실제 기기 회전을 안내한다. 세로/백그라운드에서는 애니메이션과 음성을 중지한다.
- 인물이 돌아다니고, 선택한 인물을 땅으로 이동시키거나 오브제에 보내 사용할 수 있다. 가까워진 인물의 관계는 기존 본문 자료로 표시한다.
- 보리밭, 물항아리, 쉬는 자리, 나무를 배치하고 경로를 우회한다. 최대 16개이며 해당 본문 조합의 기기 저장소에만 배치를 저장한다. 읽음 체크·통독 진도에는 영향을 주지 않는다.
- 룻기 2장에는 이삭 줍기(2:2–3), 보아스와 일꾼의 인사(2:4), 물을 마시도록 배려하기(2:8–9) 세 장면을 작성했다. 인물과 오브제가 모이면 확대·동작·본문 해설 자막을 보여 준다. 다음/건너뛰기도 가능하다.
- 음성은 기본 꺼짐. 사용자가 켜면 기기 한국어 TTS로 본문을 풀어 쓴 해설을 읽는다. 기기 음성 설치 상태에 따라 품질과 지원이 다르며, 자막은 항상 제공한다.
- `디자인 도안`에서 실제 그림 코드로 그린 인물 100종, 오브제 4종, 지형 샘플과 걷기 자세를 본다.

## 그림 규격

인물 몸체의 기본 작업 격자는 약 24×38도트, 월드 표시 배율은 2배다. 16도트 머리를 어깨에 붙이고 작은 턱선·옷깃으로 몸과 구분한다. 점눈·볼터치·짙은 외곽선과 옷 옆면 음영을 사용한다. 후광·지팡이 등 소품은 몸체 격자 밖으로 나올 수 있다. 공개 배너는 별도 생성한 픽셀 아트를 WebP로 압축했다.

## 개발 파일

- `js/features/pixel-bible.js`: 공개 배너·안내·로그인 확인·지연 로딩·입구 표시
- `js/features/pixel-bible/world.js`: 오늘 본문 데이터·이동 경로·배치·상호작용·장면·정리
- `js/features/pixel-bible/art.js`: 캐릭터·오브제·지형·실제 도안 렌더러
- `css/pixel-bible.css`: 공개 배너·개발 안내·가로 월드·회전 안내

일반 정적 웹앱과 같은 Python 서버에서 실행한다. 새 패키지·빌드·DB 스키마·서버 배포는 필요하지 않다. 월드 입장은 기존 로그인 서버 `/account/data`가 반환한 신원을 확인한다. UI에서 관리자 입장을 제한하는 개발 기능이며, 공개 GitHub Pages에 놓인 JavaScript/그림 파일 자체를 비공개 파일로 만드는 기능은 아니다.

## 현재 범위와 다음 작업

현재 월드는 본문 인물을 모은 상상 공간이며 실제 지리나 연대를 재현하지 않는다. 언급된 인물이 모두 같은 시점에 살아 있었음을 뜻하지 않는다. 전용 사건 연출은 룻기 2장부터 작성했으며 다른 본문은 인물·관계와 공통 동작을 제공한다. 모든 본문을 자동으로 사건 영상으로 변환하는 기능은 아직 없다. 별도 월드 저장 서버, 녹음 음성, 여러 지역 사이 이동은 후속 범위다.

## 검증

Node.js 24에서 `node --test tests/pixel-bible.test.mjs`로 인물 출처·사건 범위·장애물 우회를 확인한다. 브라우저에서는 일반 사용자 안내, 서버 신원 불일치 시 입장 거부, 가로/세로 전환, 관리자 입장, 오늘 분량, 오브제 배치 저장, 재입장 시 캐시 재사용, 장면 자막, 도안 표시 및 통독 기록/버전 유지까지 확인했다. 자동 검증에서는 운영 서비스에 쓰지 않도록 로그인 서버 응답을 테스트용으로 대체했다. 실제 기기의 화면 방향 잠금과 TTS 음질은 기기별 확인이 필요하다.

## 인물 개성과 조작 개선

`appearance.js`에서 인물별 외형과 근거를 분리해 관리한다. 엘리야의 털겉옷·가죽띠, 엘리사의 이마·겉옷, 이세벨의 눈화장·머리 장식, 왕들의 신분 표시, 나봇의 포도 바구니 등을 구별했다. 본문에 없는 색·장식·역할 소품은 창작이라고 표시하며, 특정 시점의 모습과 인물의 상징 디자인을 혼동하지 않도록 설명한다. 주석 원문 OCR은 현재 환경에 없으므로 직접 대조했다고 주장하지 않는다. 후속 주석 대조 시 해당 프로필의 근거를 보강한다.

캐릭터를 직접 누르고 끌면 머리 근처에 집힌 상태로 몸과 발이 흔들린다. 빈 곳에 놓거나 오브제 옆에 놓아 사용한다. 다른 인물/장애물과 겹치거나 터치가 취소되면 안전하게 원위치로 돌린다. 기존 선택 후 클릭 이동과 방향키도 유지한다.

위아래 도구 줄은 접을 수 있는 좌우 패널로 옮겼다. 오른쪽 조합식은 필요한 인물·오브제, 가능 여부, 해당 본문 출처를 보여 주고 한 번에 인물을 모을 수 있다. 룻기 세 사건에 더해 열왕기상 19:4–8의 엘리야·천사·나무 조합을 추가했다. 나무 그림은 장면의 로뎀나무를 상징하는 공통 오브제이며 식물 형태의 고증 모델은 아니다.

캔버스를 화면의 실제 가로세로 비율·픽셀 밀도에 맞추고 균일 배율로 확대해 검은 여백을 없앴다. 화면 가장자리 일부가 잘릴 수 있지만 캐릭터를 찌그러뜨리지 않는다. 앱의 안내 말풍선은 2초 뒤 사라지며 근거 설명은 왼쪽 패널에서 계속 확인한다. 입장 시 자동 네이티브 전체화면은 요청하지 않는다. 사용자가 확대 버튼을 누를 때만 요청하며, 브라우저 자체의 전체화면 종료 안내는 앱이 표시 시간이나 숨김 여부를 제어할 수 없다.

## 인물 데이터 확장 현황

장별 JSON은 66권·1,189장이다. `people`에 등장하는 서로 다른 문자열은 2,261종이며 집단·신적 존재·동명이인·별칭이 포함된다. 따라서 2,261명의 고유 인물이 구축됐다는 뜻은 아니다. 족보 등을 포함한 성경 모든 개인의 완전한 목록 여부도 검증되지 않았다.

전용 외형 프로필은 현재 100종이다. 기존 표기 중 100개는 전용 외형에 연결되고 나머지 2,161개 표기는 공통 외형에 이름별 옷색·머리·옷깃·옷자락의 작은 차이를 적용한다. 일부 동명이인의 문맥별 ID 분리를 추가했으며 전체 별칭·시대 정규화는 미완성이다. 우선 신약 출처/역할의 요셉에게 창세기의 무늬옷이 적용되는 것을 방지했다. 다른 모호한 이름은 추정으로 전용 프로필에 연결하지 않는다.

`data/pixel-bible/people-catalog.json`은 기존 자료의 이름 표기, 역할, 등장 장과 외형 연결을 모은 정적 색인이다. 별도 서버 DB가 아니며 월드 입장에 전권 색인을 내려받지 않는다. `node tools/pixel-bible/catalog.mjs`로 재생성하고 `--check`로 원자료와 일치하는지 확인한다. 이 색인의 refs는 요약에 등장하는 장이며 외모 근거 절과는 구분한다.

외형 근거는 `appearance.js`에 절과 설명으로 기록했다. 의복/신체 기록(엘리야의 털옷·가죽띠, 세례 요한의 낙타털 옷, 삼손의 머리), 특정 사건의 소품/복식(미리암의 소고, 모르드개의 예복), 역할을 나타내는 창작(바울의 두루마리, 느헤미야의 조끼)을 설명에서 구분한다. 모든 시대의 실제 복식을 확정하거나 원문 주석을 전부 대조한 결과는 아니다. 같은 인물의 유년기·고난·왕위 등 시점별 스킨은 아직 없으며 특정 장면의 특징을 기본 상징에 사용한 경우 그 한계를 표시한다. 기록에 없는 머리·수염·색과 미세 무늬는 창작이다.

외형 100종을 실제 도안에 모두 표시한다. 미리암의 소고와 삼손의 긴 머리 렌더러를 추가했다. 기존 사건 조합식은 룻기 3개·열왕기상 1개로 총 4개이며 이번 변경으로 사건 장면이 자동 확장되지는 않는다. 다음 확장은 집단/개인 분류와 동명이인 ID 정리, 미연결 인물의 근거 검토, 본문별 사건 조합식 추가 순서로 진행한다.

## 두 번째 확장: 100종과 선택 배경

`extra-appearances.js`에 전용 외형 50종을 추가해 총 100종으로 늘렸다. 사울·요나단·압살롬·히스기야·요시야·엘르아살·훌다·아담·하와·라헬·실라·디도·누가·아굴라·브리스길라 등을 포함한다. 근거 구절은 역할/사건 출처이며 의복·색·장식은 본문에 실제 기록된 항목 외에는 창작이라고 명시한다. 사울의 키, 아히야의 찢어진 옷 같은 시점별 신체/동작은 자료에 기록하되 구현된 외형이라고 주장하지 않는다.

`identity.js`는 개인·집단·신적 존재·미해결을 보수적으로 분류한다. 이름 표기는 2,261개 그대로이며, 장별 역할·책 문맥으로 분리한 신원 레코드는 개인 97·집단 244·신적 존재 6·미해결 2,589개다. 이 수치는 고유 인물 수가 아니다. 미해결은 책별 임시 ID이므로 한 실제 인물이 여러 레코드로 남을 수 있다. 바울/사울 별칭을 연결하고 왕 사울을 분리하며, 요셉·마리아·요한·빌립은 명시적 역할과 출처가 있는 경우만 구분한다. 모호한 야고보·유다·스가랴·아하시야·요나단과 여러 왕이 사용하는 바로·다리오·벤하닷 표기는 미해결로 남긴다. 월드도 신원 ID가 다른 동명 인물을 합치지 않는다. 역할 설명과 외형 검토는 신원 확정과 별개다. 집단은 한 캐릭터가 대표하는 상징임을 왼쪽 패널에 표시한다.

`backgrounds.js`는 초록 마을·모래 광야·호숫가·바위 산지·노을 들판·별빛 마을 6개 팔레트와 장식 유형을 제공한다. 오른쪽 도구 패널의 배경 버튼으로 선택하고 `pixel-bible-background`에 기기별로 저장한다. 실제 성경 지리/당시 장소의 복원이 아닌 상상 지형이다. 공통 이동 격자와 오브제 배치는 바뀌지 않으며 산·별·모래언덕 장식은 이동 영역 위쪽에만 놓는다. 선택할 때 배경 캔버스를 다시 그리고 이후 프레임에서는 캐시를 재사용한다. 새 외부 이미지/전권 요청이나 서버 저장은 추가하지 않는다.

검증: Node 테스트 11개, 색인 재현 검사, 100종×2방향 원본 도트의 머리/몸 연결 검사와 4장 확대 도안 검토. 브라우저에서 기존 이동·집기·조합식과 배경 6종 전환·선택 저장·재입장·100종 도안·통독 기록 유지·JavaScript 오류 없음까지 확인했다. 모든 이름의 신원 검토는 남아 있다. 관리자 전용과 공식 버전 유지 정책은 계속 적용한다.

## 선택 실루엣과 네 방향 걷기

큰 사각 선택 표시를 없애고 현재 방향·걷기 프레임의 불투명 도트에 인접한 한 도트 테두리를 표시한다. 그림자 같은 반투명 도트는 테두리 생성에서 제외한다. 몸과 머리·소품을 따라가며 선택 상태는 약하게 밝기가 변한다. 방향/프레임/외형/동작별 64×64 원본 스프라이트와 필요할 때 생성하는 테두리를 최대 4,096개까지 캐시한다. 매 프레임 이미지 분석이나 새 원본 생성을 하지 않는다.

`directions.js`는 별도로 그린 측면·후면 원화를 제공한다. 왼쪽은 오른쪽 원화를 반전하며, 뒷모습에는 눈·입을 그리지 않는다. 각 방향에서 왕관·머리띠·수건·긴 머리·소품을 유지한다. 정면은 기존 승인된 비율을 사용한다. 4프레임 주기는 중립→한쪽 발→중립→반대 발이며 중립 그림은 공유한다. 측면의 팔/발 전후 이동과 몸의 1도트 상하 움직임, 후면의 교대 발걸음을 사용한다. 이동 거리로 프레임을 계산해 일시정지하면 멈추고 정지 시 중립 자세로 돌아간다. 오브제에 도착하면 그쪽을 바라보고 가까운 인물 간 상호작용도 서로의 방향을 향한다.

`language.js`는 마지막 한글 음절의 받침을 확인해 목적격 조사를 붙인다. 동명이인용 괄호 설명은 조사 판단에서 제외한다. 집기·내려놓기·오브제 배치·조합 안내에 적용한다.

검증은 Node 테스트 13개, 기존 관리자 월드 브라우저 검증, 100종×4방향×4프레임의 1,600개 렌더링/실루엣 테두리 검사, 대표 인물 6종의 방향·걷기 도안과 100종 방향별 확대 도안 검토로 진행했다. 4프레임마다 3개 고유 자세가 있는지와 네 방향이 서로 다른지 확인했다. 프레임은 고정 도트로 그리며 정식 버전은 올리지 않는다.

## 독백과 근접 말풍선

100종 전용 독백을 각각 2문장, 200개 작성했고, 지정 본문에서 활성화되는 방향별 관계 상황 53개에 각각 2문장, 106개를 작성했다. 전체 검토본은 [대사 문장 목록](pixel-bible-dialogue.md)에 있다. `solo-dialogue.js`와 `pair-dialogue.js`를 고친 뒤 `node tools/pixel-bible/dialogue-guide.mjs`로 목록을 재생성한다. 상상 대사이며 실제 인물의 발언/내면/당시 직접 대면을 확정하지 않는다. 이세벨의 나봇에 대한 개인적 혐오나 두 사람의 직접 대면은 기록된 사실로 단정하지 않는다.

호크마 주석 원문은 로컬 OCR에 없고 현재 네트워크 정책은 검색/주석 사이트를 허용하지 않아 호크마 대조는 미완료다. `DIALOGUE_SOURCE_STATUS.hokma`는 `not-reviewed-source-unavailable`이다. 현재 문장은 본문·기존 장별 자료에 근거한 초안이며 호크마 검토본으로 표시하지 않는다. 호크마 자료 확보 후 대조/수정할 항목으로 남긴다. 원문이나 복제한 주석 문장은 커밋하지 않는다.

근접 대사는 지정 장이 오늘 분량에 있고, 화자와 대상이 실제 등장하며 3타일 이내이고 둘 다 이동/오브제 접근 중이 아닐 때 후보가 된다. 대상별로 다른 문장과 방향을 가진다. 독백은 기본 인물 상징 대사이며 모호한 바로·다리오·벤하닷·요나단·스가랴·아하시야는 지정 장이 아닌 경우 일반 창작 일상 대사를 사용한다. 미등록 외형에도 특정 인물의 믿음/감정을 단정하지 않는 창작 일상 문장이 있다.

`SpeechDirector` 한 개가 모든 인물의 단일 말풍선 슬롯을 소유한다. 실제 시간으로 5,000ms 표시하고 숨김을 관측한 시점부터 최소 3,000ms 대기한다. 랜덤으로 쉬는 기회도 두어 모든 대기 종료마다 반드시 발화하지는 않는다. 근접 대사를 우선할 확률은 70%이며 즉시 같은 문장과 같은 화자를 반복하지 않도록 후보를 조정한다. 랜덤 무발화와 후보 없음 뒤에도 3초 이상 기다린다. 일시정지·집기·오브제 배치·조합 사건 대기/재생·도안·세로 화면·백그라운드에서는 숨기고 재개 후 대기한다. 독립 음성은 자동 재생하지 않으며 기존 사건 TTS와 겹치지 않는다.

Canvas 위에 DOM 말풍선 하나만 놓고 캐릭터 화면 좌표를 따라가며 가장자리 안으로 제한한다. 대사 아래 화자/대상·상상 대사 표기·참고 구절을 함께 보여 준다. 글은 줄바꿈하고 `textContent`로 넣는다. 기존 관계 라벨용 중앙 Canvas 안내는 제거했다. 창을 닫거나 재입장하면 말풍선 상태도 정리한다. 통독 진도·저장 구조·관리자 입장·공식 버전 정책은 변경하지 않았다.

말풍선 검증: Node 테스트 17개 통과. 브라우저에서는 이세벨→아합 근접 대사, 단일 말풍선, 약 5초 표시/숨김 후 약 3초 간격, 일시정지·세로 전환 후 숨김과 재대기, 화면 경계, 통독 기록 유지, JavaScript 오류 없음을 확인했다. 상단 제목에 가릴 경우 말풍선을 캐릭터 아래로 옮기고 꼬리 방향도 바꾼다. 기존 집기·출처 패널·도구·조합식 브라우저 검증도 통과했다.
