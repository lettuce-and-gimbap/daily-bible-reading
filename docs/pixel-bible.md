# PIXEL BIBLE 10.0.0

2026-10-23 사용자 승인으로 비로그인 사용자를 포함해 모든 사용자에게 공개한다. 통독 탭 왼쪽 배너에서 입장하며 첫 접속 업데이트 안내에 사용설명서를 표시한다. 업로드 주석 참고 자료는 비공개 작업공간 DB에만 보관한다. 자세한 검토 범위는 [자료 검토 기록](pixel-bible-source-review.md)을 참고한다.

아래 개발 이력의 관리자 전용·버전 동결·자료 미확보 기록은 당시 상태이며, 현재 정책은 이 문서 상단과 자료 검토 기록을 따른다.

## 현재 기능

- 통독 계획의 오늘 분량에서 인물·관계·설명을 가져온다. 계획이 없으면 `체험 본문 · 룻기 2`로 명확히 표시한다.
- 월드/도안 모듈과 필요한 권의 JSON만 입장 시 불러온다. 공통 지형과 캐릭터 그림은 코드로 재사용하며 책 데이터는 입장 사이에도 메모리에 캐시한다. 본문 장을 바꿀 때 월드를 로딩하지 않는다.
- 세로 화면에서는 CSS로 월드 캔버스를 가로 방향으로 회전해 보여준다. 전체화면을 자동 요청하지 않으며, 회전 표시와 무관하게 화면이 열려 있으면 애니메이션이 계속되고 백그라운드에서만 정지한다.
- 인물이 돌아다니고, 선택한 인물을 땅으로 이동시키거나 오브젝트에 보내 사용할 수 있다. 가까워진 인물의 관계는 기존 본문 자료로 표시한다.
- 보리밭, 물항아리, 쉬는 자리, 나무 등 오브젝트를 배치하고 경로를 우회한다. 설치 개수 상한 없이 해당 본문 조합의 기기 저장소에만 배치를 저장한다. 읽음 체크·통독 진도에는 영향을 주지 않는다.
- QT 화면의 `이 QT 본문으로 픽셀 월드 보기`를 누르면 해당 날짜의 본문 절과 겹치는 사건·관계 요약으로 인물·생물·오브젝트를 구성한다. 요약이 가진 사건 단위 구절 범위를 기준으로 삼으며 절별 원문 분석으로 가장하지 않는다.
- 룻기 2장에는 이삭 줍기(2:2–3), 보아스와 일꾼의 인사(2:4), 물을 마시도록 배려하기(2:8–9) 세 장면을 작성했다. 인물과 오브젝트가 모이면 확대·동작·본문 해설 자막을 보여 준다. 다음/건너뛰기도 가능하다.
- 음성은 기본 꺼짐. 사용자가 켜면 기기 한국어 TTS로 본문을 풀어 쓴 해설을 읽는다. 기기 음성 설치 상태에 따라 품질과 지원이 다르며, 자막은 항상 제공한다.
- `디자인 도안`에서 실제 그림 코드로 그린 인물 100종, 오브젝트 4종, 지형 샘플과 걷기 자세를 본다.

## 그림 규격

인물 몸체의 기본 작업 격자는 약 24×38도트, 월드 표시 배율은 2배다. 16도트 머리를 어깨에 붙이고 작은 턱선·옷깃으로 몸과 구분한다. 점눈·볼터치·짙은 외곽선과 옷 옆면 음영을 사용한다. 후광·지팡이 등 소품은 몸체 격자 밖으로 나올 수 있다. 공개 배너는 별도 생성한 픽셀 아트를 WebP로 압축했다.

## 개발 파일

- `js/features/pixel-bible.js`: 공개 배너·안내·지연 로딩·입구 표시
- `js/features/pixel-bible/world.js`: 오늘 본문 데이터·이동 경로·배치·상호작용·장면·정리
- `js/features/pixel-bible/art.js`: 캐릭터·오브젝트·지형·실제 도안 렌더러
- `css/pixel-bible.css`: 공개 배너·개발 안내·가로 월드·회전 안내

일반 정적 웹앱과 같은 Python 서버에서 실행한다. 새 패키지·빌드·DB 스키마·서버 배포는 필요하지 않다. 10.0.0 월드는 계정 인증 없이 입장한다. 비공개 주석 DB는 이 정적 서버의 루트 밖에 둔다.

## 현재 범위와 다음 작업

현재 월드는 본문 인물을 모은 상상 공간이며 실제 지리나 연대를 재현하지 않는다. 언급된 인물이 모두 같은 시점에 살아 있었음을 뜻하지 않는다. 전용 사건 연출은 룻기 2장부터 작성했으며 다른 본문은 인물·관계와 공통 동작을 제공한다. 모든 본문을 자동으로 사건 영상으로 변환하는 기능은 아직 없다. 별도 월드 저장 서버, 녹음 음성, 여러 지역 사이 이동은 후속 범위다.

## 검증

Node.js 24에서 `node --test tests/pixel-bible.test.mjs`로 인물 출처·사건 범위·장애물 우회를 확인한다. 브라우저에서는 일반 사용자 안내, 서버 신원 불일치 시 입장 거부, 가로/세로 전환, 관리자 입장, 오늘 분량, 오브젝트 배치 저장, 재입장 시 캐시 재사용, 장면 자막, 도안 표시 및 통독 기록/버전 유지까지 확인했다. 자동 검증에서는 운영 서비스에 쓰지 않도록 로그인 서버 응답을 테스트용으로 대체했다. 실제 기기의 화면 방향 잠금과 TTS 음질은 기기별 확인이 필요하다.

## 인물 개성과 조작 개선

`appearance.js`에서 인물별 외형과 근거를 분리해 관리한다. 엘리야의 털겉옷·가죽띠, 엘리사의 이마·겉옷, 이세벨의 눈화장·머리 장식, 왕들의 신분 표시, 나봇의 포도 바구니 등을 구별했다. 본문에 없는 색·장식·역할 소품은 창작이라고 표시하며, 특정 시점의 모습과 인물의 상징 디자인을 혼동하지 않도록 설명한다. 주석 원문 OCR은 현재 환경에 없으므로 직접 대조했다고 주장하지 않는다. 후속 주석 대조 시 해당 프로필의 근거를 보강한다.

캐릭터를 직접 누르고 끌면 머리 근처에 집힌 상태로 몸과 발이 흔들린다. 빈 곳에 놓거나 오브젝트 옆에 놓아 사용한다. 다른 인물/장애물과 겹치거나 터치가 취소되면 안전하게 원위치로 돌린다. 기존 선택 후 클릭 이동과 방향키도 유지한다.

위아래 도구 줄은 접을 수 있는 좌우 패널로 옮겼다. 오른쪽 조합식은 필요한 인물·오브젝트, 가능 여부, 해당 본문 출처를 보여 주고 한 번에 인물을 모을 수 있다. 룻기 세 사건에 더해 열왕기상 19:4–8의 엘리야·천사·나무 조합을 추가했다. 나무 그림은 장면의 로뎀나무를 상징하는 공통 오브젝트이며 식물 형태의 고증 모델은 아니다.

캔버스를 화면의 실제 가로세로 비율·픽셀 밀도에 맞추고 균일 배율로 확대해 검은 여백을 없앴다. 화면 가장자리 일부가 잘릴 수 있지만 캐릭터를 찌그러뜨리지 않는다. 앱의 안내 말풍선은 2초 뒤 사라지며 근거 설명은 왼쪽 패널에서 계속 확인한다. 입장 시 자동 네이티브 전체화면은 요청하지 않는다. 사용자가 확대 버튼을 누를 때만 요청하며, 브라우저 자체의 전체화면 종료 안내는 앱이 표시 시간이나 숨김 여부를 제어할 수 없다.

## 인물 데이터 확장 현황

장별 JSON은 66권·1,189장이다. `people`에 등장하는 서로 다른 문자열은 2,261종이며 집단·신적 존재·동명이인·별칭이 포함된다. 따라서 2,261명의 고유 인물이 구축됐다는 뜻은 아니다. 족보 등을 포함한 성경 모든 개인의 완전한 목록 여부도 검증되지 않았다.

전용 외형 프로필은 현재 100종이다. 기존 표기 중 100개는 전용 외형에 연결되고 나머지 2,161개 표기는 공통 외형에 이름별 옷색·머리·옷깃·옷자락의 작은 차이를 적용한다. 일부 동명이인의 문맥별 ID 분리를 추가했으며 전체 별칭·시대 정규화는 미완성이다. 우선 신약 출처/역할의 요셉에게 창세기의 무늬옷이 적용되는 것을 방지했다. 다른 모호한 이름은 추정으로 전용 프로필에 연결하지 않는다.

`data/pixel-bible/people-catalog.json`은 기존 자료의 이름 표기, 역할, 등장 장과 외형 연결을 모은 정적 색인이다. 별도 서버 DB가 아니며 월드 입장에 전권 색인을 내려받지 않는다. `node tools/pixel-bible/catalog.mjs`로 재생성하고 `--check`로 원자료와 일치하는지 확인한다. 이 색인의 refs는 요약에 등장하는 장이며 외모 근거 절과는 구분한다.

외형 근거는 `appearance.js`에 절과 설명으로 기록했다. 의복/신체 기록(엘리야의 털옷·가죽띠, 세례 요한의 낙타털 옷, 삼손의 머리), 특정 사건의 소품/복식(미리암의 소고, 모르드개의 예복), 역할을 나타내는 창작(바울의 두루마리, 느헤미야의 조끼)을 설명에서 구분한다. 모든 시대의 실제 복식을 확정하거나 원문 주석을 전부 대조한 결과는 아니다. 같은 인물의 유년기·고난·왕위 등 시점별 스킨은 아직 없으며 특정 장면의 특징을 기본 상징에 사용한 경우 그 한계를 표시한다. 기록에 없는 머리·수염·색과 미세 무늬는 창작이다.

외형 100종을 실제 도안에 모두 표시한다. 미리암의 소고와 삼손의 긴 머리 렌더러를 추가했다. 기존 사건 조합식은 룻기 3개·열왕기상 1개로 총 4개이며 이번 변경으로 사건 장면이 자동 확장되지는 않는다. 다음 확장은 집단/개인 분류와 동명이인 ID 정리, 미연결 인물의 근거 검토, 본문별 사건 조합식 추가 순서로 진행한다.

## 두 번째 확장: 100종과 선택 배경

`extra-appearances.js`에 전용 외형 50종을 추가해 총 100종으로 늘렸다. 사울·요나단·압살롬·히스기야·요시야·엘르아살·훌다·아담·하와·라헬·실라·디도·누가·아굴라·브리스길라 등을 포함한다. 근거 구절은 역할/사건 출처이며 의복·색·장식은 본문에 실제 기록된 항목 외에는 창작이라고 명시한다. 사울의 키, 아히야의 찢어진 옷 같은 시점별 신체/동작은 자료에 기록하되 구현된 외형이라고 주장하지 않는다.

`identity.js`는 개인·집단·신적 존재·미해결을 보수적으로 분류한다. 이름 표기는 2,261개 그대로이며, 장별 역할·책 문맥으로 분리한 신원 레코드는 개인 97·집단 244·신적 존재 6·미해결 2,589개다. 이 수치는 고유 인물 수가 아니다. 미해결은 책별 임시 ID이므로 한 실제 인물이 여러 레코드로 남을 수 있다. 바울/사울 별칭을 연결하고 왕 사울을 분리하며, 요셉·마리아·요한·빌립은 명시적 역할과 출처가 있는 경우만 구분한다. 모호한 야고보·유다·스가랴·아하시야·요나단과 여러 왕이 사용하는 바로·다리오·벤하닷 표기는 미해결로 남긴다. 월드도 신원 ID가 다른 동명 인물을 합치지 않는다. 역할 설명과 외형 검토는 신원 확정과 별개다. 집단은 한 캐릭터가 대표하는 상징임을 왼쪽 패널에 표시한다.

`backgrounds.js`는 초록 마을·모래 광야·호숫가·바위 산지·노을 들판·별빛 마을 6개 팔레트와 장식 유형을 제공한다. 오른쪽 도구 패널의 배경 버튼으로 선택하고 `pixel-bible-background`에 기기별로 저장한다. 실제 성경 지리/당시 장소의 복원이 아닌 상상 지형이다. 공통 이동 격자와 오브젝트 배치는 바뀌지 않으며 산·별·모래언덕 장식은 이동 영역 위쪽에만 놓는다. 선택할 때 배경 캔버스를 다시 그리고 이후 프레임에서는 캐시를 재사용한다. 새 외부 이미지/전권 요청이나 서버 저장은 추가하지 않는다.

검증: Node 테스트 11개, 색인 재현 검사, 100종×2방향 원본 도트의 머리/몸 연결 검사와 4장 확대 도안 검토. 브라우저에서 기존 이동·집기·조합식과 배경 6종 전환·선택 저장·재입장·100종 도안·통독 기록 유지·JavaScript 오류 없음까지 확인했다. 모든 이름의 신원 검토는 남아 있다. 관리자 전용과 공식 버전 유지 정책은 계속 적용한다.

## 선택 실루엣과 네 방향 걷기

큰 사각 선택 표시를 없애고 현재 방향·걷기 프레임의 불투명 도트에 인접한 한 도트 테두리를 표시한다. 그림자 같은 반투명 도트는 테두리 생성에서 제외한다. 몸과 머리·소품을 따라가며 선택 상태는 약하게 밝기가 변한다. 방향/프레임/외형/동작별 64×64 원본 스프라이트와 필요할 때 생성하는 테두리를 최대 4,096개까지 캐시한다. 매 프레임 이미지 분석이나 새 원본 생성을 하지 않는다.

`directions.js`는 별도로 그린 측면·후면 원화를 제공한다. 왼쪽은 오른쪽 원화를 반전하며, 뒷모습에는 눈·입을 그리지 않는다. 각 방향에서 왕관·머리띠·수건·긴 머리·소품을 유지한다. 정면은 기존 승인된 비율을 사용한다. 4프레임 주기는 중립→한쪽 발→중립→반대 발이며 중립 그림은 공유한다. 측면의 팔/발 전후 이동과 몸의 1도트 상하 움직임, 후면의 교대 발걸음을 사용한다. 이동 거리로 프레임을 계산해 일시정지하면 멈추고 정지 시 중립 자세로 돌아간다. 오브젝트에 도착하면 그쪽을 바라보고 가까운 인물 간 상호작용도 서로의 방향을 향한다.

`language.js`는 마지막 한글 음절의 받침을 확인해 목적격 조사를 붙인다. 동명이인용 괄호 설명은 조사 판단에서 제외한다. 집기·내려놓기·오브젝트 배치·조합 안내에 적용한다.

검증은 Node 테스트 13개, 기존 관리자 월드 브라우저 검증, 100종×4방향×4프레임의 1,600개 렌더링/실루엣 테두리 검사, 대표 인물 6종의 방향·걷기 도안과 100종 방향별 확대 도안 검토로 진행했다. 4프레임마다 3개 고유 자세가 있는지와 네 방향이 서로 다른지 확인했다. 프레임은 고정 도트로 그리며 정식 버전은 올리지 않는다.

## 독백과 근접 말풍선

100종 전용 독백을 각각 2문장, 200개 작성했고, 지정 본문에서 활성화되는 방향별 관계 상황 53개에 각각 2문장, 106개를 작성했다. 전체 검토본은 [대사 문장 목록](pixel-bible-dialogue.md)에 있다. `solo-dialogue.js`와 `pair-dialogue.js`를 고친 뒤 `node tools/pixel-bible/dialogue-guide.mjs`로 목록을 재생성한다. 상상 대사이며 실제 인물의 발언/내면/당시 직접 대면을 확정하지 않는다. 이세벨의 나봇에 대한 개인적 혐오나 두 사람의 직접 대면은 기록된 사실로 단정하지 않는다.

호크마 주석 원문은 로컬 OCR에 없고 현재 네트워크 정책은 검색/주석 사이트를 허용하지 않아 호크마 대조는 미완료다. `DIALOGUE_SOURCE_STATUS.hokma`는 `not-reviewed-source-unavailable`이다. 현재 문장은 본문·기존 장별 자료에 근거한 초안이며 호크마 검토본으로 표시하지 않는다. 호크마 자료 확보 후 대조/수정할 항목으로 남긴다. 원문이나 복제한 주석 문장은 커밋하지 않는다.

근접 대사는 지정 장이 오늘 분량에 있고, 화자와 대상이 실제 등장하며 3타일 이내이고 둘 다 이동/오브젝트 접근 중이 아닐 때 후보가 된다. 대상별로 다른 문장과 방향을 가진다. 독백은 기본 인물 상징 대사이며 모호한 바로·다리오·벤하닷·요나단·스가랴·아하시야는 지정 장이 아닌 경우 일반 창작 일상 대사를 사용한다. 미등록 외형에도 특정 인물의 믿음/감정을 단정하지 않는 창작 일상 문장이 있다.

`SpeechDirector` 한 개가 모든 인물의 단일 말풍선 슬롯을 소유한다. 실제 시간으로 5,000ms 표시하고 숨김을 관측한 시점부터 최소 3,000ms 대기한다. 랜덤으로 쉬는 기회도 두어 모든 대기 종료마다 반드시 발화하지는 않는다. 근접 대사를 우선할 확률은 70%이며 즉시 같은 문장과 같은 화자를 반복하지 않도록 후보를 조정한다. 랜덤 무발화와 후보 없음 뒤에도 3초 이상 기다린다. 일시정지·집기·오브젝트 배치·조합 사건 대기/재생·도안·세로 화면·백그라운드에서는 숨기고 재개 후 대기한다. 독립 음성은 자동 재생하지 않으며 기존 사건 TTS와 겹치지 않는다.

Canvas 위에 DOM 말풍선 하나만 놓고 캐릭터 화면 좌표를 따라가며 가장자리 안으로 제한한다. 대사 아래 화자/대상·상상 대사 표기·참고 구절을 함께 보여 준다. 글은 줄바꿈하고 `textContent`로 넣는다. 기존 관계 라벨용 중앙 Canvas 안내는 제거했다. 창을 닫거나 재입장하면 말풍선 상태도 정리한다. 통독 진도·저장 구조·관리자 입장·공식 버전 정책은 변경하지 않았다.

말풍선 검증: Node 테스트 17개 통과. 브라우저에서는 이세벨→아합 근접 대사, 단일 말풍선, 약 5초 표시/숨김 후 약 3초 간격, 일시정지·세로 전환 후 숨김과 재대기, 화면 경계, 통독 기록 유지, JavaScript 오류 없음을 확인했다. 상단 제목에 가릴 경우 말풍선을 캐릭터 아래로 옮기고 꼬리 방향도 바꾼다. 기존 집기·출처 패널·도구·조합식 브라우저 검증도 통과했다.

## 전권 대사 연결 및 대화 정렬

`major-dialogue.js`에 외형과 독립된 주요 인물/정체성 대사 100세트(200문장)를 추가했다. 기존 100세트 독백 200문장과 관계 대사 106문장을 합해 직접 작성한 문장은 506개다. 세트에는 별칭과 동명이인의 분리가 포함되므로 200명의 완전히 별개 인물 목록이라고 주장하지 않는다. 책·장·역할 조건을 확인하며, 마리아(예수의 어머니/베다니/마가의 어머니), 요한·야고보·유다·헤롯·이스마엘·빌립처럼 모호한 이름에 책/역할/장 제한을 둔다. 전용 픽셀 외형이 없어도 고유 대사가 나온다.

`chapter-dialogue.js`는 입장 때 이미 불러온 오늘 본문 자료에서 역할과 관계 맥락을 한 번 구성한다. 전용 대사가 없는 인물은 해당 장의 역할 안내를 사용하고, 미작성 근접 관계는 현재 장의 관계 풀이로 연결한다. 역할/관계의 요약문을 실제 인물의 직접 인용으로 바꾸지는 않는다. 전권 JSON을 매번 내려받거나 실시간 생성 API를 호출하지 않는다. 현재는 표시 인원 10명 제한을 없애고 분량 전체를 기본 배치한다. 주요·전체·개별 표시 설정으로 원하는 인원만 남길 수 있다.

전권 점검 결과는 `data/pixel-bible/dialogue-coverage.json`에 저장했다. 66권·1,189장, 신적 존재 일부를 제외한 이름/집단 표기 2,259종, 등장 기록 5,956건 중 직접 작성 독백 연결 2,038건·현재 장 역할 안내 3,918건, 문맥 관계 3,826건이다. 이 숫자는 고유한 개인 인구가 아니라 현재 요약 자료의 발생 횟수다. 추가 주요 대사 100세트 모두 실제 원자료와 매칭된다. 전체 성경의 누락 없는 인물 사전이나 호크마 검토 완료를 뜻하지 않는다. `node tools/pixel-bible/dialogue-coverage.mjs --check`로 재현 검사한다.

사용자 요청에 따라 말풍선의 화자·대상·상상 독백 등 설명은 화면에서 제거했다. 대사와 참고 구절만 보이며 구절은 버튼이다. 누르면 월드 위에서 기존 `versePairs`와 `versePairsHtml`을 재사용해 개역개정·쉬운성경을 연다. 범위가 없는 장 참조는 해당 장 전체를 보여 준다. 읽기 화면의 현재 장이나 읽음 상태를 바꾸지 않고, 창이 열려 있는 동안 월드/말풍선은 멈춘다. 닫기/Escape로 월드에 복귀한다. 본문 API 응답은 기존 렌더러가 이스케이프하며 주석 원문·성경 본문을 새로 커밋하지 않는다. 창작/해설/호크마 미검토 상태는 대사 검토 문서와 데이터 출처에 남긴다.

`conversation.js`는 근접 대화가 선택되면 한 인물은 기다리고 다른 인물은 같은 x 또는 y 좌표의 안전한 칸까지 실제로 걷게 한다. 다른 인물과 이동 경로·오브젝트는 피한다. 세로 대화는 겹침을 줄이기 위해 3타일 간격을 둔다. 도착 후에만 좌우/앞뒤로 마주보고 5초 말풍선을 시작한다. 대기 중 이동 실패/시간 초과·사용자 이동·집기·배치·다른 장면 진입은 대화를 취소한다. 말하는 두 인물은 대화가 끝날 때까지 자리를 유지한다. 말풍선은 계속 한 개이며 사라진 뒤 최소 3초 간격을 유지한다. 세로로 마주볼 때는 말풍선을 옆에 배치해 상대 캐릭터를 가리지 않는다.

검증: Node 테스트 21개 및 전권 데이터/대사 문서 재현 검사 통과. 브라우저에서 대각선 관계 인물이 걸어서 가로 정렬 후 마주보기, 세로 정렬/앞뒤 방향, 설명 없는 말풍선, 구절 클릭/범위/두 역본(테스트 응답), Escape 복귀, 통독 기록/현재 읽기 장 유지와 JavaScript 오류 없음을 확인했다. 기존 관리자 입장·드래그·조합식·도안·버전 유지 검사도 통과했다. 관리자 전용과 공식 버전 미갱신 정책을 유지한다.


## 전권 관계도 연결 보강

66권 1,189장 전체에서 관계도 인물 명단과 관계를 읽는다. 전체 명단을 동시에 월드에 배치하고 인물 목록에서 선택하면 해당 인물로 카메라를 이동한다. 주요·전체·개별 표시 설정은 분량별로 저장한다. 관계도 끝점만 있고 인물 목록에 빠진 대상도 연결한다. 하나님·성령 등 신적 존재를 무작위 인간 캐릭터로 만들지 않는다.

전용 독백·대화가 없는 경우 해당 장의 역할과 관계 설명을 말풍선과 구절로 연결한다. 모든 인물에게 개별 창작 대사나 고유 도안이 완성되었다는 뜻은 아니다. 전용 도안이 없는 인물은 이름과 역할에 따른 재사용 외형을 쓴다. 전권 주석 검토가 완료된 것도 아니다.

`node tools/pixel-bible/world-coverage.mjs`는 실제 모델의 전권 인물 접근 가능성, 대사 후보, 관계 양 끝점과 근접 상호작용을 검사한다. 자동 검사 결과는 5,956 인물 등장, 3,826 관계(고유 인물 수 아님)이며 10명 초과 장 40개의 명단을 보존한다. 필요한 권만 입장 시 로드하고 재입장 시 캐시를 재사용한다.


## 선택 해제와 관계선

입장 시 선택 인물은 없다. 인물을 선택한 다음 빈 땅을 누르면 선택만 해제해 금빛 외곽선이 사라진다. 땅 클릭으로 이동 명령을 내리지 않는다. 선택 없이 배경이나 방향키를 눌러도 임의의 인물을 움직이지 않는다.

도구 패널의 `관계선` 토글은 현재 화면의 관계도 인물을 머리 위 실선으로 잇는다. 프레임마다 현재 위치를 계산하므로 걷기·집어 옮기기를 따라간다. 본문 출처가 일치하는 인물만 연결하며, 관계명이 겹치면 일부 라벨을 생략한다. 말풍선은 기존과 같이 전역 하나만 5초 노출하고, 실제로 숨긴 시점부터 최소 3초 뒤 새 후보를 선택한다.


## 선택형 조작·인물 대사·동작 보강

선택하지 않아도 인물들은 자유롭게 이동한다. 인물 클릭은 선택과 개인 대사 요청, 빈 땅 클릭은 선택 해제다. 직접 이동은 집어 옮기기 또는 선택 후 방향키로 한다.

`personal-lines.js`는 기존 전용 대사에 현재 장의 역할과 관계에 따른 창작 변형을 더해 각 인물에게 중복 없는 3~5개 후보를 제공한다. 모든 문장이 인물별 수작업 신학 검토를 마친 것은 아니다. 클릭 대사는 같은 인물의 같은 문장이 연속으로 나오는 것도 허용한다. 다른 말풍선이 표시 중이어도 클릭한 인물의 대사로 즉시 교체하고 새로 5초를 센다. 클릭 없이 자동 진행할 때는 말풍선이 겹치지 않는다. 5초 노출이 끝난 뒤 3초를 쉬며, 무작위로 발화를 건너뛰던 동작은 제거했다. 대화 상대가 자리를 맞추는 시간이나 화면 일시정지 등은 별도로 걸릴 수 있다.

`motion.js`는 이름별 매달림 리듬 세 종류를 기본으로 사용한다. 야곱(창 32장 이후), 므비보셋(삼하 4–21장)의 느린 비대칭 걸음, 엘리야의 달리기/지친 걸음(왕상 18/19장), 다윗의 달리기/춤(삼상 17/삼하 6장), 미리암의 춤(출 15장), 삭개오의 나무 동작(눅 19장)을 해당 본문에 한정한다. 고침받아 걷는 인물은 회복 상태를 반영한다. 나머지 동작 차이는 창작 리듬이며 신체 상태를 추정하지 않는다. 동작 근거는 인물 상세에서 확인한다.


## 오브젝트 철거와 자동 상호작용

전체 철거는 오브젝트를 모두 제거하며 인물의 위치·방향·이동 경로를 재설정하지 않는다. 삭제한 물건에 연결된 사용 작업·장면만 해제한다. 빈 배치도 분량별로 저장된다. `개별 철거`를 켜고 물건의 밑부분을 누르면 그 물건만 제거하며, 설치 버튼을 누르면 철거 모드를 종료한다.

물건은 기존 4종에 우물·돌·떨기나무·배·두루마리·기름병을 더해 10종이다. 해당 장에만 열리는 본문 조합 14개를 추가했다. 조합식에는 참고 구절과 필요한 인물을 표시한다. 여유 있는 인물이 약 3초마다 물건 방문을 검토하고, 같은 물건은 약 18초 간격으로 재방문한다. 본문 조합을 일반 휴식보다 우선하며 해당 인물이 대화 중이면 기다린다. 자동 방문은 전체 화면 장면을 강제로 열지 않고 물건 사용 동작과 전역 말풍선 순서의 대사로 연결한다. 클릭한 인물의 즉시 발화와 기존 5초 노출/3초 공백 규칙을 유지한다. 수동 조합은 기존 확대 장면을 사용할 수 있다.

추가 조합: 야곱–돌(창 28), 리브가–우물(창 24), 이삭–우물(창 26), 모세–떨기나무(출 3), 아론–항아리(출 16), 다윗–돌(삼상 17), 사르밧 과부–물(왕상 17), 선지자 제자의 아내–기름병(왕하 4), 요시야–두루마리(왕하 22), 바룩–두루마리(렘 36), 예수님·제자들–배(막 4), 삭개오–나무(눅 19), 예수님·사마리아 여인–우물(요 4), 빌립·에디오피아 내시–두루마리(행 8). 장면 설명은 본문을 풀어 쓴 것이고 자동 대사는 새로 구성한 발화다. 원본 주석을 공개하지 않는다.


## 본문별 오브젝트 DB와 상호작용 모션 확장

`object-catalog.js`에 156종의 물건·건물·동식물·상징 정의를 두었다. `tools/pixel-bible/object-catalog.mjs`로 전권 공개 요약의 사건·관계 설명을 색인해 `data/pixel-bible/objects/`에 권별 DB를 만든다. 현재 66권 1,189장 검사에서 151종이 1,129개 장, 6,022건으로 연결된다. 사건 자료에 구절 범위가 있으면 그대로 보존하고, 장 전체 설명에서만 확인되면 장 단위 참고로 남긴다. 이는 요약 자료에서 추출한 후보이며 성경 원문 모든 절의 모든 물건을 전수 검증한 목록은 아니다. 비공개 주석 파일이나 DB를 이 과정에 넣지 않는다.

월드 입장 시 기존 권별 요약을 재사용해 같은 규칙으로 현재 분량의 오브젝트를 계산한다. 생성한 전권 DB를 한꺼번에 다운로드하지 않는다. 해당 본문 오브젝트에는 참고 구절 범위가 보이고 공통 꾸미기 물건은 별도로 펼칠 수 있다. 이름만 같은 일괄 아이콘에 머물지 않도록 물건 계열과 방주·언약궤·무기·우물·악기·식물 등 주요 형태별 픽셀 도안을 사용한다. 모든 정의가 각각 완전히 독립된 원화인 것은 아니다.

`interaction-motion.js`는 29계열의 175개 재사용 동작 원형과 4단계 시간 흐름을 정의한다. `data/pixel-bible/interaction-motions.json`에는 외형 100종과 전체 156개 물건의 15,600개 동작 연결을 기록한다. 캐릭터별 선택 원형·손 위치·리듬은 창작이며, 바룩의 기록하기·다윗의 돌 고르기 등 명시한 본문 장면에서는 해당 동작을 우선한다.

의자는 무릎을 굽혀 앉고 발을 흔들거나 손을 모은다. 물항아리·우물은 뜨기/마시기/붓기/줄 끌기, 보리밭은 몸을 숙여 이삭 모으기/묶기/살피기, 두루마리는 읽기/펼치기/적기, 배는 앉기/노 젓기 등의 자세로 구분한다. 상하좌우 원화에 손과 다리 자세를 적용하며 얼굴·몸 연결을 유지한다. 동작용 물건을 들 때 기존 장식용 손 소품은 잠시 감춰 서로 겹치지 않게 한다. 사용 중에는 걸음 프레임 대신 상호작용 단계 프레임을 쓴다.

상호작용 성공 시 ‘인물 → 오브젝트’, ‘일상 동작 (창작)’, 모여드는 설명 등의 하단 알림은 표시하지 않는다. 길 막힘·설치·철거와 같은 조작 안내는 유지한다. 선택·자동 이동·단일 말풍선 5초/3초 간격과 수동 클릭 즉시 발화는 그대로 적용한다.

## 2026-10-23 로컬 본문·주석 대조 보강

최신 원격의 10.0.0 공개 범위, 전권 대사·오브젝트·동작·관계선 구현을 보존했다. 기존 독백 100세트·추가 주요 인물 100세트·관계 53세트, 기존 오브젝트 장면 14개와 룻기/엘리야 장면을 검토 대상으로 삼았다. 룻기 장면 두 개를 추가해 전용 장면은 총 20개다. 화자별 자동 오브젝트 발화, 아론·모세 호칭, 사자를 통해 전한 말의 전달 경로, 동작 주체와 참조 범위를 보완했다. 범위·자료·유보 해석은 [검토 기록](pixel-bible-content-review.md)을 참고한다. 공식 버전·공개 범위 변경은 없다.

## 인물 명단 변경 시 월드 상태 유지

화면 밖 인물을 고를 때 월드를 재입장하던 처리를 제거했다. 같은 분량 안에서는 인물의 신원별 실행 객체를 보관해 계속 보이는 인물의 좌표·방향·이동 경로·상호작용·걸음 프레임을 유지한다. 숨겨졌다 다시 등장하는 인물도 이전 상태를 재사용하고 새 인물만 장애물과 이동 경로를 피해 빈 칸에 추가한다. 오브젝트·배경·음성·정지·패널 상태도 명단 변경으로 초기화하지 않는다. 새 분량 또는 명시적인 체험 본문 전환은 별도 월드로 시작한다.

## 오브젝트 크기·접점·상호 반응

물병·기름병·컵·작은 도구는 인물보다 작게, 나무·큰 건축물은 인물보다 크게 그린다. 오브젝트 계열별 배율을 월드와 도안에서 함께 사용한다. 휴대 물건에는 좌우에서 접근하고, 사용 중 그리는 인물 위치를 손과 물건이 닿는 거리로 보정한다. 이 보정은 저장 좌표와 경로를 바꾸지 않는다.

인물과 오브젝트는 같은 상호작용 시계를 사용한다. 기름병의 들림·기울임, 물결·물방울, 우물의 두레박과 줄, 이삭 묶음, 나뭇잎, 두루마리의 펼침·필기, 배의 흔들림과 물결, 악기 진동 등을 동작 단계에 맞춰 표현한다. 의자는 앉는 동안 미세하게 눌리는 표현을 쓴다. 감소된 모션 설정에서는 움직임을 반복하지 않고 한 자세로 유지한다. 변화는 시각 연출이며 원문의 새 사건이나 재고·파괴 기록을 생성하지 않는다.

## 오브젝트 꾹 누르기 이동·구체적인 관계 설명

배치한 물건을 1초간 누르면 이동 모드가 된다. 누른 위치를 기준으로 끌어다 놓으며, 놓을 수 있는 칸을 초록/빨강으로 표시한다. 이동 전 손가락이 크게 움직이면 꾹 누르기를 취소한다. 다른 물건·인물·이동 중인 경로, 화면 밖이나 패널 위에 놓기, 포인터 취소·화면 회전은 원래 위치를 유지한다. 성공한 좌표만 기존 분량별 배치 저장소에 기록한다. 그 물건을 사용하던 작업만 해제하며 다른 인물을 초기 배치하지 않는다.

'서로 얽힌 일을 다시 생각하게 되는구나'라는 범용 문장은 제거했다. 현재 장의 관계 설명을 구체적인 사건 해설로 사용하고 해당 구절을 함께 연결한다. 본문에 없는 개인 심경이나 상대의 말을 새로 추측하지 않는다.


## 10.1.0 넓은 월드·카메라·자유 배치

사용자 승인에 따라 조작과 탐색 기능 추가를 10.1.0으로 배포한다. 월드는 2,880×1,728 픽셀(120×72칸)이며 기존 배치 좌표를 그대로 읽는다. 캐릭터의 자연 이동·경로 탐색은 화면 밖에서도 계속된다. 목록에서 화면 밖 인물을 선택하면 시점을 그 인물로 옮긴다.

두 손가락으로 중심을 유지하며 확대·축소/이동할 수 있다. PC에서는 마우스 휠을 지원한다. 배율 바와 +/− 버튼은 제거했다. 최소 배율은 화면 비율마다 전체 지도가 보이는 배율이고 최대는 250%이며 빈 땅을 끌어 시점을 이동한다. 캐릭터를 잡아 화면 가장자리로 끌면 매 프레임 카메라가 이동하고, 같은 화면 좌표를 새 월드 좌표로 변환해 캐릭터가 손가락 아래에 머무르게 한다. 내려놓을 때 인물이 가장자리에 가려지지 않게 시점을 보정한다. 핀치로 전환한 터치는 설치·캐릭터 클릭으로 중복 처리하지 않는다.

오브젝트 버튼은 다시 누르면 취소한다. 고른 직후 도구 창을 닫으며, 하단 배치 취소 버튼도 제공한다. 도구 탭은 최소 44px 높이의 버튼 전체가 터치 영역이다. 16개 제한은 작은 기존 화면에서 배치를 제한하던 코드였고, 물건별 파일 용량 제한은 아니었다. 현재는 별도의 개수 상한을 두지 않으며 월드 안의 빈 칸에 설치한다. 저장소 용량과 기기 자원은 유한하다. 화면에 보이는 오브젝트만 렌더링하고 장애물 좌표를 Set으로 색인한다.

관련 인물에 대한 우선순위는 유지하되 다른 인물을 제외하지 않는다. 물건별 점유 중에는 다른 인물이 기다리고, 개별 인물은 같은 물건에 40초 재방문 간격을 둬 다른 인물에게도 차례가 돌아간다. 관련 인물의 본문 발화와 다른 인물의 창작 동작을 구분한다. 언약궤는 특정 인물만 사용하도록 잠그지 않고 곁에서 살펴보는 동작으로 연결한다.

## 전체 오브젝트 동작·상호작용 보강 (10.1.0 유지)

156종 전체에 `object-behavior.js`의 의미별 규칙을 적용한다. 재사용 동작 원형은 175개, 정적 검토용 캐릭터/오브젝트 조합은 100×156=15,600개다. 이 JSON은 실행 중 읽지 않으며 월드는 가벼운 규칙으로 자세를 계산한다. 각각을 별도의 손그림 애니메이션으로 제작했다는 뜻은 아니다.

- 책·옷·음식·악기·도구·작은 그릇은 배치한 실제 도안을 손 위치에 옮긴다. 들어 올리는 동안 바닥 사본과 기존 임시 소품은 숨기며 내려놓으면 다시 표시한다. 마시기·먹기는 입 높이, 악기·도구 사용은 팔과 소품의 기울기, 펼치기·접기는 폭/높이로 구분한다.
- 큰 식물·구조물·제단·함·침상에는 뒤쪽 접근을 허용하지 않는다. 그림을 실제 크기에 맞춰 좌우 바깥 또는 앞에서 그리며 저장 좌표는 바꾸지 않는다. 앉기·배 탑승과 삭개오의 명시적인 나무 장면은 별도로 처리한다.
- 상의 차림/닦기, 침상 정리, 함 뚜껑 열기, 심지와 불빛, 동물 먹이/돌보기, 병거의 고삐·바퀴, 그물 펼치기와 악기 반응을 동작 단계에 연결한다. 상·침상·보좌·발판과 주요 등불/그릇의 별도 도안도 보완했다. 언약궤는 열거나 휴대하는 공통 동작에 연결하지 않는다.
- 일반 보행과 인물 드롭에서는 다른 캐릭터를 장애물로 취급하지 않는다. 대화는 서로 다른 좌표의 같은 축에 서서 마주본 뒤 시작한다. 오브젝트에 붙여 그리던 자세도 먼저 해제한다. 말풍선과 관계선의 머리 위치는 실제 상호작용 그림 위치를 따른다.
- 말풍선 감정은 명시된 값 우선이며 나머지는 짧은 문구 분류로 보완한다. 중립·기쁨·슬픔·걱정·분노·놀람·결의·온화함을 얼굴 내부에만 그린다. 뒤통수에는 얼굴을 그리지 않는다. 말풍선이 끝나거나 닫히면 중립으로 돌아온다. 자동 5초 표시 후 실제 사라진 때부터 3초 대기, 수동 클릭 즉시 교체 규칙은 유지한다.


## 중앙 시작·전체 지도·인물 표시 선택

현재 월드는 1920×1080이며 종전 2880×1728보다 면적을 약 58% 줄였다. 시작과 중앙 복귀는 (960, 540), 최대 축소는 전체 지도를 담는 배율이다. 카메라는 지도 밖으로 이동하지 않고 화면보다 작은 축은 중앙에 고정한다. 최대 축소의 화면 비율 차이로 생기는 가장자리 여백은 정상이며 지형을 자르거나 늘리지 않는다. 이전 지도 바깥에 저장된 오브젝트는 버리지 않고 가장 가까운 빈 칸으로 옮겨 읽는다.

`landscape.js`는 전체 지도에 지형을 한 번 구성한다. 960×480 화면을 반복 복사하지 않는다. 길·중앙 광장·외곽 언덕·강변·건물·텐트·나무·밭·조명과 작은 지면 무늬를 도트 단위로 그리며 주요 외곽 경관과 내부 고정 나무·밭·쉼터를 나누어 그린다. 내부 경관은 깊이 정렬과 충돌에 참여하고 기존 사용자 배치와 겹치는 고정 경관은 생략한다. 기본 6종과 본문 모티브 14종으로 총 20종이다. 명시한 76개 장에는 묘사 기반 배경을 선택하고 나머지는 기본 지형을 쓴다. 전체 66권 1,189장 매핑은 `data/pixel-bible/backgrounds.json`에 기록하며 실행 중 한꺼번에 다운로드하지 않는다. 여러 장의 분량은 첫 장의 기본값을 사용하고 사용자가 바꾼 배경은 분량별 저장값을 우선한다.

모든 등장 인물을 기본 배치하고, 인물 패널에서 주요/전체/모두 숨기기와 개인별 표시를 조절한다. 주요 인물은 요약 비중·본문 장면 참여·관계 연결 수로 정하며 표시 설정이 빈약하면 명단 앞 여섯 명을 사용한다. 이름 버튼은 선택과 카메라 이동, 옆 표시 버튼은 노출만 변경한다. 새로 표시한 인물 아래에는 현재 분량/신원이 일치하는 관계 상대를 추천한다. 추천은 자동 추가하지 않고 사용자가 눌러 함께 표시한다. 숨김/표시 때 실행 객체를 재사용하므로 남은 인물의 위치·경로·동작은 초기화하지 않는다. 숨긴 인물의 자동 이동은 정지하고 다시 표시하면 이어간다. 모두 숨겨도 빈 월드를 꾸밀 수 있다.

## 집은 지점 고정·여섯 가지 이상 결과·입장 시 자유 이동

드래그 좌표는 처음 집은 월드 좌표와 실제 그림 원점의 차이를 보존한다. 인물의 강제 96px 이동/드롭 시 3셀 이동을 제거했다. 인물의 움직임·자세·오브젝트 접근 보정·올라간 높이를 집기 판정에 반영하고, 빈 사각형 대신 실제 불투명 도트를 검사한다. 대롱이는 회전 중심은 커서가 집은 픽셀이다. 오브젝트도 집은 위치를 유지한 채 연속 좌표로 따라오고, 놓을 때만 셀에 맞춘다. 카메라 가장자리 이동·핀치·DPR에서도 같은 월드 좌표 변환을 사용한다.

175개 재사용 동작 원형과 물건별 선택 규칙을 사용한다. 156종 모두 최소 6가지 일상 결과가 있고, 동일 인물의 같은 종류 물건 방문 횟수를 이어 다음 결과를 선택한다. 전부 개별 수작업 원화라는 뜻은 아니다. 옷은 바닥 소품을 감추고 같은 색·종류의 의복/망토/머리 장식으로 착용했다가 벗긴다. 활과 화살은 당기기·겨냥·실제 발사체를 표현하고 임시 화살 소품이 중복되지 않게 한다. 나무 흔들기·차기·열매 낙하·콩 맞기와 표정 반응을 표현한다. 전용 동작 23개는 인물 신원과 해당 장이 일치할 때만 우선하며 참조 범위는 검토 기록에 남긴다.

입장 위치에는 불규칙한 편차를 주고 첫 프레임 전에 보행 경로를 준비한다. 처음부터 다양한 방향으로 걸으며 인물별 대기 시간을 줄 세우듯 늘리지 않는다. 운영체제의 동작 줄이기 설정에서는 자동 첫 보행을 생략한다. 배경·인물 표시 설정·말풍선 5초/3초 규칙과 공식 버전은 유지한다.
