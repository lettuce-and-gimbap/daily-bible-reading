# PIXEL BIBLE 관리자 개발 체험

정식 공개 전에는 서버가 확인한 `buucksoo` 계정에만 앱 내 월드를 연다. 관리 화면 배너와 통독 탭 옆 작은 입구는 모두에게 표시하고, 일반 사용자는 개발 안내만 본다. 계정 확인에 실패하면 입장을 허용하지 않는다. 공식 앱 버전과 업데이트 기록은 올리지 않는다. 이후 공개 범위 변경은 사용자의 정식 출시 요청이 있을 때만 한다.

## 현재 기능

- 통독 계획의 오늘 분량에서 인물·관계·설명을 가져온다. 계획이 없으면 `체험 본문 · 룻기 2`로 명확히 표시한다.
- 월드/도안 모듈과 필요한 권의 JSON만 입장 시 불러온다. 공통 지형과 캐릭터 그림은 코드로 재사용하며 책 데이터는 입장 사이에도 메모리에 캐시한다. 본문 장을 바꿀 때 월드를 로딩하지 않는다.
- 가로 화면 전용. 전체화면·화면 방향 잠금을 시도하고, 지원하지 않는 브라우저에서는 실제 기기 회전을 안내한다. 세로/백그라운드에서는 애니메이션과 음성을 중지한다.
- 인물이 돌아다니고, 선택한 인물을 땅으로 이동시키거나 오브제에 보내 사용할 수 있다. 가까워진 인물의 관계는 기존 본문 자료로 표시한다.
- 보리밭, 물항아리, 쉬는 자리, 나무를 배치하고 경로를 우회한다. 최대 16개이며 해당 본문 조합의 기기 저장소에만 배치를 저장한다. 읽음 체크·통독 진도에는 영향을 주지 않는다.
- 룻기 2장에는 이삭 줍기(2:2–3), 보아스와 일꾼의 인사(2:4), 물을 마시도록 배려하기(2:8–9) 세 장면을 작성했다. 인물과 오브제가 모이면 확대·동작·본문 해설 자막을 보여 준다. 다음/건너뛰기도 가능하다.
- 음성은 기본 꺼짐. 사용자가 켜면 기기 한국어 TTS로 본문을 풀어 쓴 해설을 읽는다. 기기 음성 설치 상태에 따라 품질과 지원이 다르며, 자막은 항상 제공한다.
- `디자인 도안`에서 실제 그림 코드로 그린 인물 50종, 오브제 4종, 지형 샘플과 걷기 자세를 본다.

## 그림 규격

인물 몸체의 기본 작업 격자는 약 24×38도트, 월드 표시 배율은 2배다. 16도트 머리를 어깨에 붙이고 작은 턱선·옷깃으로 몸과 구분한다. 점눈·볼터치·짙은 외곽선과 옷 옆면 음영을 사용한다. 후광·지팡이 등 소품은 몸체 격자 밖으로 나올 수 있다. 공개 배너는 별도 생성한 픽셀 아트를 WebP로 압축했다.

## 개발 파일

- `js/features/pixel-bible.js`: 공개 배너·안내·로그인 확인·지연 로딩·입구 표시
- `js/features/pixel-bible/world.js`: 오늘 본문 데이터·이동 경로·배치·상호작용·장면·정리
- `js/features/pixel-bible/art.js`: 캐릭터·오브제·지형·실제 도안 렌더러
- `css/pixel-bible.css`: 공개 배너·개발 안내·가로 월드·회전 안내

일반 정적 웹앱과 같은 Python 서버에서 실행한다. 새 패키지·빌드·DB 스키마·서버 배포는 필요하지 않다. 월드 입장은 기존 로그인 서버 `/account/data`가 반환한 신원을 확인한다. UI에서 관리자 입장을 제한하는 개발 기능이며, 공개 GitHub Pages에 놓인 JavaScript/그림 파일 자체를 비공개 파일로 만드는 기능은 아니다.

## 현재 범위와 다음 작업

현재 월드는 본문 인물을 모은 상상 공간이며 실제 지리나 연대를 재현하지 않는다. 언급된 인물이 모두 같은 시점에 살아 있었음을 뜻하지 않는다. 전용 사건 연출은 룻기 2장부터 작성했으며 다른 본문은 인물·관계와 공통 동작을 제공한다. 모든 본문을 자동으로 사건 영상으로 변환하는 기능은 아직 없다. 별도 월드 저장 서버, 녹음 음성, 인물별 전 방향 걷기 스프라이트, 여러 지역 사이 이동은 후속 범위다.

## 검증

Node.js 24에서 `node --test tests/pixel-bible.test.mjs`로 인물 출처·사건 범위·장애물 우회를 확인한다. 브라우저에서는 일반 사용자 안내, 서버 신원 불일치 시 입장 거부, 가로/세로 전환, 관리자 입장, 오늘 분량, 오브제 배치 저장, 재입장 시 캐시 재사용, 장면 자막, 도안 표시 및 통독 기록/버전 유지까지 확인했다. 자동 검증에서는 운영 서비스에 쓰지 않도록 로그인 서버 응답을 테스트용으로 대체했다. 실제 기기의 화면 방향 잠금과 TTS 음질은 기기별 확인이 필요하다.

## 인물 개성과 조작 개선

`appearance.js`에서 인물별 외형과 근거를 분리해 관리한다. 엘리야의 털겉옷·가죽띠, 엘리사의 이마·겉옷, 이세벨의 눈화장·머리 장식, 왕들의 신분 표시, 나봇의 포도 바구니 등을 구별했다. 본문에 없는 색·장식·역할 소품은 창작이라고 표시하며, 특정 시점의 모습과 인물의 상징 디자인을 혼동하지 않도록 설명한다. 주석 원문 OCR은 현재 환경에 없으므로 직접 대조했다고 주장하지 않는다. 후속 주석 대조 시 해당 프로필의 근거를 보강한다.

캐릭터를 직접 누르고 끌면 머리 근처에 집힌 상태로 몸과 발이 흔들린다. 빈 곳에 놓거나 오브제 옆에 놓아 사용한다. 다른 인물/장애물과 겹치거나 터치가 취소되면 안전하게 원위치로 돌린다. 기존 선택 후 클릭 이동과 방향키도 유지한다.

위아래 도구 줄은 접을 수 있는 좌우 패널로 옮겼다. 오른쪽 조합식은 필요한 인물·오브제, 가능 여부, 해당 본문 출처를 보여 주고 한 번에 인물을 모을 수 있다. 룻기 세 사건에 더해 열왕기상 19:4–8의 엘리야·천사·나무 조합을 추가했다. 나무 그림은 장면의 로뎀나무를 상징하는 공통 오브제이며 식물 형태의 고증 모델은 아니다.

캔버스를 화면의 실제 가로세로 비율·픽셀 밀도에 맞추고 균일 배율로 확대해 검은 여백을 없앴다. 화면 가장자리 일부가 잘릴 수 있지만 캐릭터를 찌그러뜨리지 않는다. 앱의 안내 말풍선은 2초 뒤 사라지며 근거 설명은 왼쪽 패널에서 계속 확인한다. 입장 시 자동 네이티브 전체화면은 요청하지 않는다. 사용자가 확대 버튼을 누를 때만 요청하며, 브라우저 자체의 전체화면 종료 안내는 앱이 표시 시간이나 숨김 여부를 제어할 수 없다.

## 인물 데이터 확장 현황

장별 JSON은 66권·1,189장이다. `people`에 등장하는 서로 다른 문자열은 2,261종이며 집단·신적 존재·동명이인·별칭이 포함된다. 따라서 2,261명의 고유 인물이 구축됐다는 뜻은 아니다. 족보 등을 포함한 성경 모든 개인의 완전한 목록 여부도 검증되지 않았다.

전용 외형 프로필은 20종에서 50종으로 확장했다. 기존 표기 중 51개는 전용 외형에 연결되고 나머지 2,210개 표기는 공통 외형에 이름별 옷색·머리·옷깃·옷자락의 작은 차이를 적용한다. 동명이인 구분용 영구 ID와 책/시대별 별칭 정규화는 아직 없다. 우선 신약 출처/역할의 요셉에게 창세기의 무늬옷이 적용되는 것을 방지했다. 다른 모호한 이름은 추정으로 전용 프로필에 연결하지 않는다.

`data/pixel-bible/people-catalog.json`은 기존 자료의 이름 표기, 역할, 등장 장과 외형 연결을 모은 정적 색인이다. 별도 서버 DB가 아니며 월드 입장에 전권 색인을 내려받지 않는다. `node tools/pixel-bible/catalog.mjs`로 재생성하고 `--check`로 원자료와 일치하는지 확인한다. 이 색인의 refs는 요약에 등장하는 장이며 외모 근거 절과는 구분한다.

외형 근거는 `appearance.js`에 절과 설명으로 기록했다. 의복/신체 기록(엘리야의 털옷·가죽띠, 세례 요한의 낙타털 옷, 삼손의 머리), 특정 사건의 소품/복식(미리암의 소고, 모르드개의 예복), 역할을 나타내는 창작(바울의 두루마리, 느헤미야의 조끼)을 설명에서 구분한다. 모든 시대의 실제 복식을 확정하거나 원문 주석을 전부 대조한 결과는 아니다. 같은 인물의 유년기·고난·왕위 등 시점별 스킨은 아직 없으며 특정 장면의 특징을 기본 상징에 사용한 경우 그 한계를 표시한다. 기록에 없는 머리·수염·색과 미세 무늬는 창작이다.

외형 50종을 실제 도안에 모두 표시한다. 미리암의 소고와 삼손의 긴 머리 렌더러를 추가했다. 기존 사건 조합식은 룻기 3개·열왕기상 1개로 총 4개이며 이번 변경으로 사건 장면이 자동 확장되지는 않는다. 다음 확장은 집단/개인 분류와 동명이인 ID 정리, 미연결 인물의 근거 검토, 본문별 사건 조합식 추가 순서로 진행한다.
