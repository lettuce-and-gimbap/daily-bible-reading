# 예레미야애가 대조 기록

2026-11-23 기준 1–5장의 기존 요약·사건·관계도·등록된 절별 주석을 개역개정 본문과 로컬 주석의 관련 대목에 대조하고 각 장 심화해설을 추가했다. 자료는 호크마 정리본과 스터디바이블·성경신학 복원본 및 매튜 헨리 추출본에서 확인 가능한 부분을 사용했다. 주석 전부를 원본 지면과 일대일로 대조한 전문 감수는 아니다.

스터디바이블·성경신학의 애가 해설은 절별 원주석 전체가 아닌 구간별 복원·편집 요약이고, 호크마도 재정리 자료다. 매튜 헨리 추출본은 OCR 오류와 누락 가능성이 있다. 3:22는 히브리어 본문을 직접 확인해 낱말 설명을 보강했으나 전체 원어와 교차 인용을 전수 검증하지는 않았다.

1장에 연결한 1931년 예루살렘 항공사진은 미국 의회도서관 소장 실제 장소 사진이다. 성경 시대의 모습이나 파괴 장면이 아니며, 소장기관의 출처와 이용 표시를 그림 설명에 함께 둔다. 본문과 주석 전문은 저장소에 넣지 않는다.
