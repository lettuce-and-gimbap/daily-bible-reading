# 잠언 자료 대조 기록

2026-11-22 기준, 잠언 1–31장의 기존 요약·사건·관계도·절별 문맥 주석과 장별 심화해설을 개역개정 본문에 대조하고, 로컬 주석의 관련 부분을 참고해 보강했다. 호크마 자료는 원주석을 재정리한 것이며 다른 주석의 OCR에는 판독이 어려운 부분이 있다. 주석 두 권의 모든 절별 해설, 원어와 외부 자료의 원문, 앱 화면까지 전수 검증한 기록은 아니다.

잠언 11장의 저울 그림은 창작 도해다. 연결된 박물관 자료는 시대와 지역이 다른 비교 유물이며 본문 속 저울 자체를 증명하지 않는다. 저작권이 있는 본문과 주석 자료는 저장소에 넣지 않는다.
