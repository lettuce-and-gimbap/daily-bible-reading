# 전도서·아가 자료 대조 기록

2026-11-23 기준, 전도서 1–12장과 아가 1–8장의 장별 심화해설을 추가하고 기존 요약·사건·관계도·절별 주석의 확인된 오류를 수정했다. 개역개정 본문과 로컬 주석 자료의 관련 대목을 참고했다. 모든 항목을 두 주석의 절별 원문과 일대일로 대조한 전문 감수는 아니다.

- 전도서 1–6장의 성경신학 로컬 파일은 손상된 원문 대신 호크마를 바탕으로 쓴 편집 대체문이다. 스터디바이블도 OCR 손상이 있다.
- 전도서 7–12장은 로컬 매튜 헨리 자료에서 7:11–9:18과 10:1–3이 빠져 해당 부분을 그 자료와 대조하지 못했다. 본문과 이용 가능한 주석에 근거한 설명을 남겼다.
- 아가의 호크마·스터디바이블·성경신학 로컬 자료는 정리·복원본이며 일부 내용이 겹친다. 독립된 원전 두 권의 일치로 단정하지 않는다. 화자의 정체나 장면의 배경은 본문과 가능한 해석을 구분했다.
- 원어는 확인 가능한 항목에 한해 표기했다. 이 책들의 모든 원어·음역과 교차 인용을 전수 검증한 것은 아니다.

전도서 3장과 아가 4장의 그림은 시적 이미지를 설명하는 창작 도해이며 역사적 장소나 유물의 복원이 아니다. 아가 그림의 비교 유물은 다른 시대·지역에 속한다. 본문과 주석 전문은 저장소에 포함하지 않는다.
