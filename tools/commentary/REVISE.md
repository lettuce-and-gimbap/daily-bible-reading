# 장별 요약 검증·보강 안내 (작업 도우미용)

목표: `data/summary/<책>.json`의 각 장을 주석 두 권(성경신학·스터디바이블)과 대조해 **틀린 내용을 고치고**, 설명을 **1.5배 정도 쉽고 자세하게** 보강한다. 사무엘하(`2sa`)가 완성 견본이니 먼저 `node tools/commentary/show.cjs 2sa 3 11` 로 말투·분량을 확인할 것.

## 도구 (저장소 루트에서)
- `node tools/commentary/notes.mjs <책> <장-장> --strict | awk 'length($0)>25' | grep -v "니라\|더라\|하되\|이르되\|하시니\|하리라\|이니이다\|나이다" | head -c 22000`
  : 그 장들의 주석 해설만(본문 줄 제외). OCR이라 글자가 깨져 있으니 뜻만 읽는다. 4~6장씩 묶어 읽으면 겹치는 쪽이 줄어 토큰이 절약된다. 짧은 장(시편·서신)은 더 많이 묶어도 된다.
- `node tools/commentary/show.cjs <책> <장> [<장>...]` : 현재 데이터(LINE/STORY/E번호 사건/R 관계/P 장소)
- `node tools/commentary/patch.cjs <patch.json>` : 고친 내용 적용(형식 정리 포함, 동시 작업 잠금 있음)
- `node tools/commentary/check.mjs <책>` : 오류 0이어야 함

## patch.json 형식
```json
{ "gen 3": { "line": "(필요할 때만)", "story": "…", "events": { "0": "새 설명", "2": "…" },
  "rels": [["뱀", "하와", "새 풀이"], ["하나님", "아담", "새 풀이", "이름표(같은 두 사람 관계가 여럿일 때만)"]],
  "places": { "0": "새 설명" } } }
```
rels의 from/to는 show.cjs의 `R 앞>뒤` 그대로. 바꿀 것만 넣는다(그대로 둘 항목은 빼도 됨). patch 파일은 자기 스크래치패드에 둔다(저장소에 두지 않음).

## 쓰는 기준
- **오류 교정 우선**: 주석·본문과 어긋나는 사실(사람·숫자·장소·순서·누가 무엇을 했는지)을 고친다. 없으면 그대로 둔다.
- **분량(2026-10-17 변경): 상한도 하한도 없다.** 담을 수 있는 내용은 적절히 다 담는다(이야기 흐름, 사건의 이유·배경, 사람 관계, 주석이 알려 주는 해석·배경·구약/신약 연결). 화면 칩에 들어가는 짧은 이름(인물 role 24자, 관계 label 10자, 사건 title 18자, 장소 where 30자, why 40자)만 짧게 둔다. 시·지혜서·예언서·서신처럼 이야기가 아닌 장도 내용 흐름을 풀어 준다.
- **보강할 것**: ① 왜 그랬는지(동기·이유) ② 당시 배경(문화·지리·관습)을 한 줄 ③ 앞뒤 사건과의 연결 ④ 신앙적 의미를 한 문장. 주석에서 얻은 정보를 **자기 말로** 쉽게.
- **말투**: 초등 고학년도 이해할 쉬운 말, "~해요/~했어요/~래요" 체. 어려운 한자어는 풀어 쓴다(예: 번제→태워 드리는 제물).
- **저작권**: 개역개정·새번역 문장이나 주석 문장을 그대로 옮기지 않는다. 짧은 이름·용어 말고는 모두 풀어 쓴다. 따옴표 인용도 자기 말로 바꾼다.
- 신학 관점: 장로교 합동(개혁주의). 비평학적 의심(역사성 부정 등)은 넣지 않는다.
- 인물 이름은 그 장 본문이 부르는 대로(아브람/아브라함 등). 사람·관계·장소 항목을 새로 만들거나 지우지 말고 **문구만** 고친다.

## 끝나면
`check.mjs <책>` 오류 0 확인. 커밋하지 말 것(관리자가 모아서 커밋). 보고는 짧게: 권마다 "고친 오류 목록(한 줄씩, 없으면 없음)" + "보강한 장 수"만.

## 꼭 지킬 것 (2026-10-15 추가)
- **모든 장을 주석과 대조할 것.** 주석을 건너뛰고 본문 지식만으로 쓰지 않는다. 토큰을 아끼려면 `notes.mjs` 범위를 넓게(4~8장) 잡고 `head -c`로 자르되, 장마다 최소한 해설 줄은 훑는다.
- **길이 상한·하한 모두 없다(2026-10-17).** 다만 길이를 채우려고 빈 맺음말("말씀대로 됐어요" 등)을 덧붙이지 말고, 새 정보(이유·배경·연결·해석)로 채운다.
- 길이를 맞추려고 "말씀대로 됐어요" 같은 **빈 맺음말을 덧붙이지 말 것.** 늘릴 때는 이유·배경·앞뒤 연결 같은 새 정보를 넣는다. 정보가 없으면 짧게 둬도 된다.
