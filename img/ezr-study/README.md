# 에스라 장별 그림 목록

## 고고학 자료

- 바벨론에서 발견된 비문으로 고레스의 신전 복구 정책을 살펴볼 수 있다. 예루살렘이나 유다 귀환을 명시하지 않는다. [고레스 원통][cyrus]
- 바사 시대 금화의 비교 자료다. 본문에 기록된 헌물의 실물이나 화폐 단위를 확정하는 근거로 쓰지 않았다. [아케메네스 금화 다릭][daric]
- 페니키아 항구 도시 두로의 해상 교역 배경을 보여 준다. 현존 유구는 주로 로마 시대에 속한다. [두로 항구 유적][tyre]
- 애굽 엘레판티네에서 유다 총독에게 보낸 별개의 성전 재건 청원으로, 바사 시대 아람어 공문서의 비교 자료다. [엘레판티네 아람어 청원서][aramaic]
- 기바티 발굴팀이 보고한 바사 시대 예루살렘의 물질 자료다. 본문 속 개별 건물이나 집회의 위치를 확정하기에는 근거가 부족하다. [예루살렘 남동쪽 구릉 발굴][jerusalem]
- 바사 시대 행정 거점으로 알려진 악메다의 유적 자료다. 유적에서 확인된 도시 계획과 건축 유구는 주로 파르티아 시대에 속한다. [악메다(헤그마타네) 유적][ecbatana]
- 바사 궁정 은기의 비교 자료다. 에스라가 옮긴 성전 기물의 재질이나 모양을 복원하는 데 사용하지 않았다. [아닥사스다 명문이 있는 은제 그릇][bowl]
