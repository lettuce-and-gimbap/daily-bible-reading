# 역대하 장별 그림 목록

로컬 개역개정 4판·개역한글의 장과 절 번호를 대조하고, 로컬 호크마 정리본을 해석 보조로 사용했습니다. 사건 설명은 해당 장의 내용을 새로 요약했습니다.
장소·기물은 본문을 따라 선별했습니다. 움직임과 배치를 나타낸 도식은 축척이 없으며, 본문이 특정하지 않는 현대 좌표와 형태는 추정하지 않았습니다.

## 본문을 읽을 때 참고할 점

- 3장 기둥 높이와 세부 배치는 평행 본문과 함께 비교할 필요가 있음.
- 4장 놋 바다의 치수는 이 장의 기록을 따르며, 열왕기상과 용량 표기가 다름.
- 8장 다드몰과 오빌의 정확한 위치는 도해에서 특정하지 않음.
- 9장 스바·오빌·다시스의 현대 위치를 도해에서 특정하지 않음.
- 13장 스마라임산의 정확한 위치는 도해에서 특정하지 않음.
- 22장 2절의 즉위 나이는 열왕기하 8:26과 차이가 있어 생략함.
- 26장 15절 전투 장치의 형태와 작동 방식은 본문만으로 확정하기 어려움.
- 32장 이 장은 물길의 전체 경로와 공사 방법을 상세히 밝히지 않음.
- 36장 고레스 원통 비문과 이 장의 예루살렘 재건 조서는 구분해 읽을 필요가 있음.
