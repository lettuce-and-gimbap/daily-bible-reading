# 역대상 장별 그림 목록

로컬 개역개정 4판·개역한글의 장과 절 번호를 대조하고, 로컬 호크마 정리본을 해석 보조로 사용했습니다. 사건 설명은 해당 장의 내용을 새로 요약했습니다.
장소·기물은 본문을 따라 선별했습니다. 움직임과 배치를 나타낸 도식은 축척이 없으며, 본문이 특정하지 않는 현대 좌표와 형태는 추정하지 않았습니다.

## 본문을 읽을 때 참고할 점

- 4장 그돌 어귀의 현대 위치는 확정하기 어려움.
- 7장 가드의 정확한 지점은 이 장에서 특정하지 않음.
- 13장 기돈 타작마당과 오벧에돔 집의 좌표는 제시하지 않음.
- 14장 14–15절의 나무 이름과 실제 수종은 구분해 읽을 필요가 있음.
- 20장 본문은 3절의 철제 도구가 사용된 방식을 상세히 설명하지 않음.
