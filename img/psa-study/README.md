# 시편 그림 작업 목록 — 진행 중

그림은 본문의 장면을 이해하기 위한 창작 도해이며 유물 사진이나 현장 복원도가 아니다. 아래는 처음 제작한 3편의 목록이며, 추가 그림은 아래에 별도로 정리했다.

| 시편 | 장소 | 장면 | 기물·표지 | 그림 |
|---|---|---|---|---|
| 1:3–4 | 시냇가: 특정 지명이 아닌 비유 | 심긴 나무와 흩날리는 겨의 대조 | 나무·열매·겨 | [나무와 겨](tree-and-chaff.svg) |
| 23:1–4 | 풀밭·물가·어두운 골짜기: 특정 장소를 지목하지 않는 비유 | 목자의 인도와 돌봄 | 지팡이·막대기 | [목자와 골짜기](shepherd-valley.svg) |
| 137:1–4 | 바벨론의 여러 강변, 시온: 바벨론 지역의 강변이지만 정확한 위치 미상 | 강변에서 시온을 기억하고 수금을 나무에 검 | 수금·나무 | [바벨론 강변](babylon-rivers.svg) |

137편의 그림은 강변의 정확한 지점이나 수금의 고증 복원이 아니다. 영국박물관의 [바벨론 교육 자료](https://www.britishmuseum.org/sites/default/files/2019-10/Babylon_Teachers_Resource.pdf)는 바벨론 도시와 유프라테스강의 관계를 설명하지만 시편의 강변 위치를 특정하지 않는다. 수금과 관련된 비교 유물로 [메트로폴리탄 미술관의 수금 장식](https://www.metmuseum.org/art/collection/search/324023)이 있으나 시대와 문화가 달라 시편 악기의 실물 증거는 아니다.

자료 검토: 저장소 밖 개역개정 4판·개역한글 시편 1, 23, 137편과 호크마 시편 해당 편. 호크마의 강변을 수로로 보는 해석은 본문이 특정한 사실과 구분한다.

## 추가 창작 도해 8점

아래 그림은 두 역본(개역개정 4판, 개역한글)의 해당 절과 `호크마_md`의 해당 편을 대조한 뒤 새로 그렸다. 본문 표현과 주석의 해석을 구분하며, 모두 시적 이미지이지 사진이나 유물·건축물의 고증 복원이 아니다. 그림 연결은 `data/summary/psa-study-*.json`에 기록한다.

| 시편 | 대상과 표현 | 주석과 역사적 한계 |
|---|---|---|
| 18:2 | [반석·요새·방패](rock-fortress.svg) | 하나님의 보호를 나타내는 비유. 요새와 방패의 형태는 창작이다. |
| 42:1 | [사슴과 시냇물](deer-stream.svg) | 하나님을 향한 갈망의 비유. 주석의 사슴 성별 해석은 그림의 확정 사실로 쓰지 않았다. |
| 46:2–4 | [흔들리는 산과 시내](mountains-river.svg) | 호크마는 시내를 하나님의 공급을 상징하는 이미지로 읽는다. 도시와 물길은 실제 예루살렘의 복원도가 아니다. |
| 84:3 | [새와 보금자리](birds-nest.svg) | 성소를 향한 그리움을 드러내는 시. 건물의 구조와 둥지 위치는 알 수 없다. [메트로폴리탄 미술관 이집트 잔](https://www.metmuseum.org/art/collection/search/550779)의 새와 둥지는 다른 문화의 비교 사례이지 시편의 성소를 증명하지 않는다. |
| 91:4 | [날개와 방패](wings-shelter.svg) | 보호와 피난을 나타내는 비유. 새의 종류와 방패 형상은 특정하지 않는다. |
| 119:105 | [등과 길](lamp-path.svg) | 말씀의 인도를 빛에 빗댄 표현. [메트로폴리탄 미술관 레반트 등잔](https://www.metmuseum.org/art/collection/search/325342)은 기원전 약 1900년의 비교 유물이며, 해당 시의 등잔을 확인해 주지 않는다. |
| 121:1–2 | [산을 바라보는 사람](hills-help.svg) | 호크마는 산을 시온으로 읽는 해석을 소개한다. 본문은 이 그림 속 산의 위치를 특정하지 않으며 인물은 창작이다. |
| 126:5–6 | [씨 뿌림과 수확](sowing-harvest.svg) | 눈물과 기쁨의 대비를 농경에 빗댄 표현. 옷과 곡식 단의 모양은 도식화했다. |

두 역본은 위 범위의 주요 대상과 관계가 일치한다. 46:4의 개역한글은 거룩한 장막의 성소, 개역개정은 거룩한 처소라고 표현한다. 121:1의 산을 시온으로 특정하는 것은 본문에 적힌 지명이 아니라 주석의 해석이다. 126편의 수확은 위로의 시적 표현으로 그렸고 특정 사건의 재현이라고 주장하지 않는다.
