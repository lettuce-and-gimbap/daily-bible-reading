## 판본과 고고학 자료

- 로컬 개역개정 4판과 개역한글의 민수기 1–36장 절 번호를 대조했습니다. 호크마 민수기 정리본은 소재와 해석을 확인할 때 참고했습니다. 주석의 지명 비정은 현대 좌표로 표시하지 않았습니다.
- 4:9, 11의 등잔대·금제단은 개역한글에서 등대·금단으로 표기합니다. 16:38의 철판·편철은 16:39의 향로 재질인 놋과 함께 읽어 향로를 펴서 제단을 입힌 것으로 표시했습니다.
- 35:4는 로컬 개역개정에서 천 규빗, 로컬 개역한글 추출본에서 이천 규빗으로 읽힙니다. 두 파일의 35:5는 이천 규빗입니다. 도식에서는 목초지의 수치를 생략했습니다.
- 가나안 토기 사진은 메트로폴리탄 미술관이 퍼블릭 도메인으로 공개한 비교 유물입니다. 이 항아리로 민수기 5장의 질그릇의 형태나 용도를 특정할 수 없습니다. 투탕카멘 은 나팔은 박물관 기록으로, 데이르 알라 비문은 발굴 연구서로 연결했습니다. ## 그림에서 생략한 범위

- 모든 장의 요약 사건과 등록 지명을 목록으로 남겼습니다. 그림은 주요 장면과 물건을 묶었습니다. 지파별 계수표, 제물 수량 전체, 성읍별 목록, 개별 인명과 족보는 독립 그림으로 만들지 않았습니다.
- 33장에 열거된 진영은 순서대로 표시했습니다. 21장의 인용 노래에 나오는 부수 지명과 32장의 성읍 전체는 지도에 옮기지 않았습니다. 34장 경계 도식은 본문의 지명 순서를 보여 주며 논쟁 중인 지점을 현대 지형에 찍지 않았습니다.
- 성막 기구는 설명용 표기로, 놋뱀과 아론의 지팡이 등은 상징적인 선 그림으로 제시했습니다. 유물 사진이 있는 자료는 박물관 소장 정보와 이미지 이용 조건을 별도로 표시했습니다.
