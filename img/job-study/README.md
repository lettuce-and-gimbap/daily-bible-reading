## 출처와 한계

- 비공개 로컬 자료: 개역개정 4판과 새번역 욥기 1–42장, 호크마 욥기 주석 정리 1–42장. 세 파일의 42장 존재와 1장 일부를 확인하고, 장별 내용은 기존 저장소의 욥기 학습 해설을 참고했습니다. 두 번역과 주석의 전 장 내용을 직접 대조하는 검토는 아직 완료하지 않았습니다. 원문은 이 폴더에 수록하지 않았습니다.
- 우스의 실제 위치는 확정하지 않았습니다. 40–41장의 베헤못과 리워야단은 특정 동물로 확정하지 않았습니다. 묘사상 하마·악어를 연상시키더라도 시적 표현을 실제 종과 동일시할 수 없습니다.
