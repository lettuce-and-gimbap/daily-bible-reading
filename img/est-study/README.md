## 외부 자료의 범위

- [유네스코 수산 유적](https://whc.unesco.org/en/list/1455/): 아케메네스 시대의 다리우스 궁전과 도시 유적을 설명한다. 특정 실내 공간이나 에스더 이야기 속 개별 사건을 입증하지 않는다.
- [메트로폴리탄 미술관, 키루스 원통과 고대 페르시아](https://www.metmuseum.org/exhibitions/listings/2013/cyrus-cylinder): 페르시아의 인장·언어·궁정 물품에 관한 비교 자료다. 본문의 반지나 문서가 발견되었다는 뜻은 아니다.

## 본문을 읽을 때

- 6장의 왕관은 하만이 제안한 물품이다(6:8). 6:11은 왕복과 말만 명시한다.
- 9장에서 수산은 아달월 13일과 14일에, 다른 지방은 13일에 대적과 싸운다. 수산은 15일, 지방은 14일에 쉰다(9:15–19).
- 10장의 공은 왕이 부과한 것으로, 구체적인 품목이나 방식을 단정하지 않았다.

호크마 파일은 로컬에 제공된 주석 정리본이며 본문 원문이나 고고학 자료와 구별한다.
